# Filing Forensics — glance glossary (R7)

One plain sentence per glance stat on `fundamental_forensics.html`, English
then Chinese. The first sentence of every entry names no kernel, dataset or
internal identifier; technical names live one layer down, in the drawer or
the details rows, never at glance. A missing value stays missing: an absence
is shown as an absence, never as a zero.

## What changed

The most important change this filing shows when set against the one before
it. / 这份财报与上一期相比最重要的一项变化。

## Why it matters

The plain reason this change deserves a review before the rest of the
filing. / 这项变化值得优先复核的通俗理由。

## Need attention

How many changes in this filing were ranked as wanting your attention first.
/ 本期财报中被排为需要优先关注的变化数量。

## Metrics compared

The share of the expected figures the comparison could actually make this
run. / 本次对比实际可计算的预期指标占比。

## Original reported

The number exactly as it was first published for that period. / 该期间首次披露时的原始数值。

## Latest as of cutoff

The newest value known by the chosen cutoff day, including anything learned
before that moment. / 截至所选截止日已知的最新数值，含该时点前的一切更新。

## Restated

The value after the company later corrected or reclassified the original
figure. / 公司此后更正或重分类原始数字后的数值。

## Source span

The exact passage of the SEC filing a number was read from, opened in place.
/ 该数值读取自 SEC 财报的确切原文片段，可就地打开。

## Compact vs exact

Compact is the rounded, quick-to-read form; exact is the filing's own digits
shown unchanged. / 简写是便于速读的取整形式；精确数值是披露原文的数字，原样显示。

## Peers in/out

Which comparable companies count toward a rank, and which are left out with
the reason stated. / 哪些可比公司计入排名，哪些被排除并附原因。
