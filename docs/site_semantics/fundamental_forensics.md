# Filing Forensics — glance glossary (R7)

One plain sentence per glance stat on `fundamental_forensics.html`, English
then Chinese. The first sentence of every entry names no kernel, dataset or
internal identifier; technical names live one layer down, in the drawer or
the details rows, never at glance. A missing value stays missing: an absence
is shown as an absence, never as a zero.

## What changed

The most important change this filing shows when set against the one before
it. / 这份财报与上一期相比最重要的一项变化。

## Why it matters

The plain reason this change deserves a review before the rest of the
filing. / 这项变化值得优先复核的通俗理由。

## Need attention

How many changes in this filing were ranked as wanting your attention first.
/ 本期财报中被排为需要优先关注的变化数量。

## Metrics compared

The share of the expected figures the comparison could actually make this
run. / 本次对比实际可计算的预期指标占比。

## Original reported

The number exactly as it was first published for that period. / 该期间首次披露时的原始数值。

## Latest as of cutoff

The newest value known by the chosen cutoff day, including anything learned
before that moment. / 截至所选截止日已知的最新数值，含该时点前的一切更新。

## Restated

The value after the company later corrected or reclassified the original
figure. / 公司此后更正或重分类原始数字后的数值。

## Source span

The exact passage of the SEC filing a number was read from, opened in place.
/ 该数值读取自 SEC 财报的确切原文片段，可就地打开。

## Compact vs exact

Compact is the rounded, quick-to-read form; exact is the filing's own digits
shown unchanged. / 简写是便于速读的取整形式；精确数值是披露原文的数字，原样显示。

## Peers in/out

Which comparable companies count toward a rank, and which are left out with
the reason stated. / 哪些可比公司计入排名，哪些被排除并附原因。

## Saved views

A view keeps this company, cutoff, policy and peer settings so the desk can
reopen exactly that question; saved views live on this device only.
/ 已存视图保留当前公司、截止日、策略与同业设置，便于原样重开这个问题；视图仅保存在本设备。

## Pinned / latest

A pinned view always reads the filings known by its saved cutoff day; a
latest view re-reads whatever the newest run admits today.
/ 固定视图始终读取其截止日已知的数据；最新视图读取当前最新一轮纳入的数据。

## Newer filing generation

When newer filings have landed since a pinned view was saved, the view stays
on its cutoff until you ask for the latest, and never changes on its own.
/ 固定视图保存后若有更新的财报数据，它会保持原截止日，直到你主动选择最新，绝不自行改动。

## Saved view unavailable

A view saved by an older version of this desk, or for a company the current
run does not cover, cannot be opened here; it can still be deleted.
/ 由旧版工作台保存、或当前更新未覆盖其公司的视图无法在此打开；仍可将其删除。

## Saved view missing

A view that was on this device but is gone now — it may have been deleted in
another tab — is simply not there anymore; the rest of the desk is unchanged.
/ 此前保存在本设备的视图现已不在——可能已在其他标签页中删除；工作台其余状态不变。

## Saved views paused

When this device's saved views cannot be read, they are left untouched and
saving is paused here; nothing is overwritten to make the list readable again.
/ 无法读取本设备的已存视图时，将保持原样不作改动并暂停保存；绝不为了恢复显示而覆盖任何内容。

## Change not saved

When this browser refuses to store a change (for example, its storage is full), that change is not saved and
nothing else is changed; your saved views stay exactly as they were.
/ 浏览器拒绝保存更改时（例如存储空间已满），该更改不会被保存，其他内容也不变；已存视图保持原样。
