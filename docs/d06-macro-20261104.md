## What changed

### Market Structure

The page leads with dealer exposure history, then the weekly range, systematic flows, correlation and volatility. Snapshot details, recent changes and assumptions remain available in disclosures beneath the primary chart. All independent ranges and saved range choices remain.

Missing observations preserve their original chart slots and break lines and filled areas. True zero, isolated points, constant series and healthy sibling series remain visible. An all-missing chart does not invent a zero baseline. The supplied 1σ and 2σ bands validate independently; a missing outer band is never synthesized. A genuine zero-width band remains visible.

Producer correlation classification remains authoritative. A missing modeled flow is unavailable rather than an observed pause. CTA changes keep their existing score/change units. Artifact and build dates, weekly lock dates and chart-observation dates are distinguished; unavailable observation dates are disclosed. The page makes no empirical 95% coverage claim for a modeled 2σ band.

Range controls retain native keyboard behavior, visible focus and a 44-pixel minimum target, including the 641–720-pixel interval.

### Stage Analysis

All six tasks remain: Screener, Stage Board, Industries, Earnings Calls, Alternative Data and Research. Their 12 existing JSON readers have independent loading, ready and error states within the existing owners. Pending reads are deduplicated; an explicit retry touches only the failed file. Filters, search and local watchlist survive recovery, and a late weekly response cannot replace the selected daily board.

The status DOM remains stable through filter blur, so the first Retry click is not lost to an unchanged error repaint. Empty data, filtered-out results, a failed read, stale data and unavailable classification counts have distinct states. Valid producer null cells remain missing heatmap observations and do not invalidate healthy cells. Nonempty stale/degraded earnings season and comparison files retain visible qualifications and their own dates.

Screener, industry-flow and earnings-call sorting use native buttons with announced sort direction and focus restoration. The earnings reader supports keyboard opening, focus containment, Escape and return to the opener. Its existing transition timers are reconciled during close/reopen. Tooltips stay within the phone viewport; research cards reflow at 320 pixels. Real four-digit population counts use a two-column phone grid.

CSV retains the complete filtered view beyond the on-screen 600-row cap. It exports 25 bilingual columns with raw weekly-ATR multiples, raw ATR/price fractions, row source, tri-state currentness, row and target weeks, source date, data session, artifact date and build time. True zero is preserved and missing values stay blank.

The population arc uses typed supplied counts. Missing, partial or no-target populations are neutral, without invented proportions; a known all-zero population remains a distinct empty state. The arc remains an idealized classification sketch.

The existing publisher revokes an old public copy when that file's current source is absent, unreadable, invalid JSON or an unusable envelope. Failure to revoke stops publication. Valid nonempty stale objects keep the existing atomic-copy path. This does not add a second reader, publisher, retry service or state store.

### S&P Vector

One primary mechanical S&P/T-bill allocation leads the page, followed by the existing three-panel price/risk/allocation study. Score, allocation, breakdown, cap and put readings retain their own contributing dates. Missing readings remain unavailable; a real numeric zero or boolean false remains valid. Alignment never assigns a later/future date to an earlier contributing score.

Recorded shadow research is explicitly not applied to the mechanical allocation. A 66% recorded shadow weight does not replace a 100% mechanical hero. Rationale is escaped, and missing shadow content has a neutral unavailable state.

The four study ranges have native keyboard controls. All three time panels synchronize and the selected price y-range is applied. Logarithmic growth, drawdown, model-change markers, model breakdown, scorecard/resampling detail, rule book, bear ledger and methods remain available. The page retains next-bar execution, 3-basis-point turnover cost, calendar-day cash carry and the 35% before-final-liquidation tax scenario, with sampling disclosure.

The builder has a page-only mode. Page-only rendering and missing-current-score builds suppress auxiliary evaluation/log/snapshot effects; a missing score cannot restamp or overwrite the last good hub output. No allocation, risk, carry, tax or backtest engine was changed.

## Scope of the proof

A successful read means the selected pinned file settled through the real renderer without a loading/error state. It does not certify freshness or complete coverage. Source accuracy, prediction quality, point-in-time backtests, upstream classification policy and trading authority are outside this UI proof.

No physical device, native WKWebView, cross-browser suite, screen-reader speech output, live ingestion, external Terminal destination, deployed route or production acceptance is claimed here. Existing Terminal handoff links are preserved. Browser viewport emulation is not physical-device proof.

This work adds bounded implementation credit to the twelve Macro migration cases. Original full-case expectations and their domain owners remain explicit in the canonical D06 ledger. Historical captures are retained as historical evidence, not relabeled as this design.
