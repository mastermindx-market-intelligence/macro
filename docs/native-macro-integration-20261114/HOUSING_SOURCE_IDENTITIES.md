## Problem and change

Ten of Housing's eighteen metrics named their source with prose instead of an exact published source identity. The native evidence resolver deliberately accepts only an exact source ID, or a bare FRED token that identifies one unique published artifact. Those ten metric actions therefore could not reach their existing source disclosures.

This change normalizes only those ten `source_refs` values at the existing Housing composer:

- Mortgage level uses `FRED:MORTGAGE30US`, matching the existing 13-week measure.
- The two ZORI measures use `national_rent_zori`.
- Existing-home sales, new-home sales and completions use their existing NAR/Census disclosure IDs.
- Four Redfin measures use the existing `redfin_high_frequency` disclosure ID.

No fuzzy client alias map is added. Old publications remain honestly unlinked until an ordinary owner publication contains the corrected identities.
