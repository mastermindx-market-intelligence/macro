# Exact Options selection questions — source adapter

This adapter prepares bounded source context for the existing Brain integration. It does not install a route, create a runtime reader, grant source use or invoke a model.

## Input and output

`engine.neuralweb.options_selection_context.resolve_options_question(reference, *, access_token, expected_user_id, captured, vendor, source_use_decision, clock=None)` accepts the closed `options.selection_question/v1` envelope. `evidence` is the incumbent six-field pinned Investigation reference; `selection` is the canonical `options_matrix_selection.v1` string. The object ID is the Terminal mint's `v1/root/session/primary/comparisons/view` format. Unknown sessions refuse even when both reference tokens agree.

`OptionsQuestionCapture` carries the existing four `IdentityArtifactRead` values: matrix, aliases, security master and root evidence. The adapter delegates exact bytes/identity/membership and fresh authentication/product entitlement to their incumbent implementations. It forces `action=export`, validates the expected principal and exact reference, and requires the source-use callback on every call.

The result contains an ephemeral `prompt_block` and bounded metadata receipt: exact root/session/version/fingerprint/byte length, selection digest, underlying ID, observed clocks, selected coordinates, hidden flags and view. It explicitly establishes membership only. Matrix metric values, quotes, greeks, valuations and Save authorization are unavailable. Tokens, principal identity, policy nonce and Matrix bodies are excluded.

## Required integration boundary

The callback seam is not a real rights backend. The trusted Brain caller must bind the actual chat/stream endpoint, selected processor/destination and exact payload for each attempted disclosure. Fallback destinations require their own binding. Existing customer display permission is not external model-use permission. The original retained capture must be reused; no additional reader/store or browser-supplied grant is introduced.

Neither the installed runtime factory, the actual processor-bound source-use policy nor the Brain transport/widget composition is supplied by this change. Original Macro #10126 and #10634 custody, held review/publication effects and production authorization remain separate. This source seam cannot clear those effects.
