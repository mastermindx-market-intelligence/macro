## Contract and integration
Add render_inline_visual to the existing Brain tool catalog, budgets and dispatcher. Normalize a version-1 spec with template enum bar/line/area/scatter/donut/table/metrics/status/scenarios/timeline/flow. One title, optional subtitle/takeaway/unit, columns, rectangular rows of plain string/finite number/null, basis source or illustrative, and value-cell bindings {row,column,tool,pointer,call_id}. Maximum 64KiB/spec, 80 rows, 6 columns, 500 characters/cell, 4 visuals/turn. Reject arbitrary markup, URLs, CSS, unknown fields, booleans, nonfinite/unbounded numbers, malformed cardinality and unsupported versions. Each chart has one unit, no dual/log/3D axes. Bar/area include zero; line/scatter padded finite domains; nulls break lines, not zero-fill; no sorting of user observations.

In source mode every numeric or text value cell must equal an authorized, completed prior-turn-step tool result selected by its existing tool-use call_id and RFC6901 pointer. A bare tool name is accepted only when that tool has exactly one prior result; repeated tools require call_id. Parallel siblings cannot bind each other. Every non-null cell of status/scenarios/timeline/flow requires a binding, so actual dates/events retain source status instead of being mislabeled hypothetical. For numeric/table/metric templates, non-numeric first-column display labels remain explicitly model-authored. Text values, including formatted currency, must match a source string exactly; no currency-detection heuristic can exempt a value. Failed/missing sources, duplicate bindings, type mismatches and missing numeric bindings reject the visual. This proves scalar value equality only, not AI headings, labels, units, freshness, causal explanations or financial advice. Provenance records numeric and text counts separately; the prior numeric-only v1 display subset remains readable. Provenance disclosures must state that distinction. Illustrative numeric mode requires explicit user teaching intent and rejects observed/historical/time-qualified requests; it visibly says example / not verified market data; never presents itself as an empirical chart. No arbitrary source URLs. No new grounding database, source fetch, credential or permission. Existing output guards also screen all visual text; visuals are released as complete chart events only after final answer screening, not before a potentially rejected answer.

Use the existing chart event and charts response array, with visual and host-derived stable id. Extend mountChart with a typed-template branch; legacy ticker/candlestick behavior stays intact. Done carries a bounded visual subset for idempotent recovery. Save only normalized visuals in existing assistant-message meta; authenticated get_thread selects visuals:meta->visuals directly from PostgREST and exposes only the separately validated visual subset, NEVER full metadata. Model history remains text-only. Stop/retract and terminal degraded/filtered responses clear visuals. No new stream or history owner.

## Presentation freeze
All templates live within the existing answer bubble, after its answer text. Chart frame: semantic figure, concise heading and subtitle, 260px measured SVG plot, thin grid, restrained signal-blue line/bars, alternate series differentiated by dash/marker plus legend. Accessible native data table disclosure and CSV export on every quantitative visual. CSV quotes every cell and prefixes formula-leading text. No arbitrary SVG/HTML from the model. Table/scenarios/status/timeline use semantic HTML and progressive disclosure. Flow is a bounded labeled relation diagram, not an unconstrained graph engine.
Dark: transparent graphite reading plane within existing bubble, restrained luminance separators. Light: paper-like inset frame, hairline and subtle shadow; no dark fill transplanted. Reuse --mmb-* and host --font-ui/--font-mono tokens, no global token changes. Chrome switches EN/ZH with host language; AI content retains its original response language. At 1440/820/390px no document overflow; tables alone scroll when needed. Keyboard-focusable disclosure/export, SVG title/description plus full table, no color-only meaning or mandatory animation.

## Scope exclusions
No new market scores, execution sizing, broker action, image-generation service, free-form code execution, maps/geocoding, 3D simulations, editable apps or calculators in this first template extension. These are distinct documented ChatGPT capabilities, not implied parity claims. No new price-chart engine or Terminal Chart Bus. Real model/provider qualification, source rights and release protections remain existing owners.
