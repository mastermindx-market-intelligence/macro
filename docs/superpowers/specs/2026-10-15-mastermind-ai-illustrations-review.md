## Independent contract review
Retained Fabric return: `mastermind-ai-illustrations-contract-review-20261015-c1`, same original root `mastermind-ai-illustrations-20261015-c1`, terminal rc0. This review examined a proposed contract, not production code or release acceptance.

| Finding or counterexample | Adjudication and evidence |
|---|---|
| Multiple symbols from repeated get_quote calls cannot bind by last tool name. | Fixed. Existing tool-use IDs disambiguate every repeated call. Tests require exact call-A/call-B binding, reject wrong IDs and ambiguous bare tool names. Same parallel batch cannot self-bind. |
| Illustrative mode could launder missing live data into invented numbers. | Fixed. Numeric examples require explicit teaching intent in the user's own request and are rejected when actual/current/live/historical observations are requested. Real-data examples cannot bypass that rule. |
| Numeric strings and vacuous source claims can evade numeric bindings. | Fixed. Source mode requires actual numeric data and rejects numeric-looking non-label strings; each numeric cell binds exactly once. |
| Equal numbers do not verify entity, unit, freshness or interpretation. | Accepted limitation, not concealed certification. Visible source note says only numeric values match retrieved data and labels/interpretation are AI-generated. Details explicitly disclaim freshness/units/conclusions and call the response a saved snapshot. There is no generic 'verified' badge or new source authority. |
| Nulls, constant/negative values, tiny marks and precision can mislead. | Tested. Gaps remain gaps, bar/area axes include actual labeled zero, data tables/CSV preserve exact values, tiny nonzero marks have explicit scale disclosure, donut missing categories say known values only. |
| Retained/replayed/aborted visuals can duplicate or expose private state. | Tested through real widget and gateway paths. Stable IDs deduplicate stream/done/history; exact-thread recovery restores visuals; stop/retract/account switch clear pending mounts; history projects validated assistant display fields only after the existing owner check. |
| Quoting CSV cells alone prevents spreadsheet formula execution. | Rejected as technically insufficient. Formula-leading STRING cells are prefixed with an apostrophe in addition to RFC4180 quoting; UTF-8 BOM, exact numeric cells and null blanks are tested through an actual browser download. |
