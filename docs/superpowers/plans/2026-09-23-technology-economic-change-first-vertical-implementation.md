## 9. Task 3 — Implement the pure owner calculator, including restatements

**Files:** `engine/company_intelligence/management_outlook.py`, `tests/test_company_management_outlook.py`.

**Interface:** `compare_management_outlook(inputs: ComparableRevenueInput) -> dict`. It takes only validated, sealed typed inputs and returns a closed derived object. It performs no I/O, model call, price lookup, publication, identity allocation or rights decision.

**Formula:**

```python
from decimal import Decimal, localcontext

def midpoint(low: Decimal, high: Decimal) -> Decimal:
    return (low + high) / Decimal(2)

def decompose(fa, fb, pa, pb, ga_n, xb_n):
    # The native adapter, not this arithmetic kernel, proves completeness and units.
    with localcontext() as context:
        context.prec = 34
        annual = fb - fa
        new_period = xb_n - ga_n
        prior_revision = pb - pa
        earlier_remaining = fa - pa - ga_n
        later_remaining = fb - pb - xb_n
        remaining = annual - new_period - prior_revision
        if remaining != later_remaining - earlier_remaining:
            raise ArithmeticError('decomposition identity failed')
        return annual, new_period, prior_revision, earlier_remaining, later_remaining, remaining
```
