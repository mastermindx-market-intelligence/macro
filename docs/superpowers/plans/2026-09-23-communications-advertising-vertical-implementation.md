### Pure numerical adapters — proposed in-memory types, not a new store

The following combines the baseline types and numerical amendment. Each instance is constructed only after owner validation; public requests never supply it. A missing rule is rejected before calling arithmetic, and the panel can independently report comparison-unavailable. Unavailable results with an existing candidate rule preserve its exact revision without implying acceptance.

```python
from dataclasses import dataclass
from decimal import Decimal
from typing import Literal

@dataclass(frozen=True)
class Interval:
    lower: Decimal
    upper: Decimal
    lower_inclusive: bool
    upper_inclusive: bool

@dataclass(frozen=True)
class Measure:
    ref: str
    metric: str
    population: str
    period: tuple[str, str]
    currency: str | None
    scale: Decimal
    basis: str
    value: Decimal | None
    domain: str
    definition_ref: str
    unit: str
    support: Interval | None
    support_basis: Literal['exact', 'source_interval', 'reviewed_nearest', 'unknown']
    support_ref: str | None

@dataclass(frozen=True)
class Guidance:
    ref: str
    metric: str
    population: str
    period: tuple[str, str]
    currency: str | None
    scale: Decimal
    basis: str
    lower: Decimal | None
    upper: Decimal | None
    lower_inclusive: bool | None
    upper_inclusive: bool | None
    published: str
    vintage: str
    definition_ref: str
    unit: str
    bounds_basis: Literal['stated_threshold', 'approximate', 'unknown']

@dataclass(frozen=True)
class InputBinding:
    role: str
    ref: str
    definition_ref: str
    population: str
    period: tuple[str, str]
    unit: str
    currency: str | None
    scale: Decimal
    domain: str

@dataclass(frozen=True)
class CashRole:
    component_key: str
    binding_role: str
    orientation: Literal['signed_flow', 'positive_magnitude']
    coefficient: Literal[-1, 1]

@dataclass(frozen=True)
class ComparisonRule:
    revision: str
    operation: Literal['period_absolute', 'period_pct', 'guidance', 'cash']
    bindings: tuple[InputBinding, ...]
    relation_ref: str
    review_ref: str
    interpretation_basis: Literal['underlying_interval', 'published_figures']
    cash_roles: tuple[CashRole, ...]

@dataclass(frozen=True)
class CashComponent:
    component_key: str
    measure_ref: str
    orientation: Literal['signed_flow', 'positive_magnitude']
    coefficient: Literal[-1, 1]

@dataclass(frozen=True)
class Result:
    status: Literal['COMPARABLE', 'QUALIFIED', 'INCOMPATIBLE', 'UNAVAILABLE']
    value: Decimal | None
    label: str
    refs: tuple[str, ...]
    reason: str | None
    rule_revision: str
    formula: str
    interpretation_basis: str
```

**Required pure signatures:** `compare_period(current: Measure, prior: Measure, *, rule: ComparisonRule, mode='pct') -> Result`; `compare_guidance(actual: Measure, guide: Guidance, *, rule: ComparisonRule) -> Result`; `cash_bridge(*, measures: tuple[Measure, ...], components: tuple[CashComponent, ...], rule: ComparisonRule) -> Result`. The domain response validator is `validate_view(payload) -> None`. These are implementation specifications; no body or function is implemented by this document.

Match immutable input ref, definition, population, period, units, currency, scale and numeric domain against each role. The reviewed relation also binds the actual accounting/gross-net bases; two missing bases are not affirmative comparability. Different definition refs require the exact approved relation. A corrected ref invalidates the old binding. No synonym or approximate-duration matching; no A1 FX conversion. Bound input lengths/exponents before Decimal arithmetic; reject booleans, nonfinite values and nonpositive scale.

A known exact value supports [x,x]. A verified nearest-rounding method at quantum q supports conservative [x-q/2,x+q/2]. Unknown source precision creates NO underlying interval; published-figure arithmetic remains qualified documentary output. Convert bounds and value by the same approved scale. Finite source-interval actuals may have no point value. Empty/reversed intervals refuse. Approximate guidance is not an exact threshold.

Classify an underlying threshold only when every supported actual gives the same result. A straddle is `QUALIFIED / ROUNDING_INDETERMINATE`. Inclusive equality meets a threshold; exclusive equality is an excluded boundary, not a value below it. For guidance comparisons preserve original target, bounds and vintage. Repetition in a later report does not refresh original issuance. Final history/consensus requires its own qualification.

Cash roles are fixed by the reviewed rule, not by a request or the observed sign. CFO 100 plus signed outflow -60 yields 40; CFO 100 minus positive expenditure 60 also yields 40. The latter contract fed -60 refuses, not 160. Duplicate economic component keys, omitted required lease principal, overlapping net subtotals and repeated receipts refuse. Two Magnite partitions explain one outcome; derived TAC is not independent evidence. Repeated uncertain inputs retain dependence: x minus x is zero, not a spurious independent interval.
