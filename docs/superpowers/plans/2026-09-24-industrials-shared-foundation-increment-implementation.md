## 3. Planned interface vocabulary

The following functions are new task deliverables, not names claimed to exist. They are deliberately under incumbent owners and produce no new stored truth.

- `industrials_profiles.expo_profile()` / `pnr_profile()` return the native `IssuerProfile`. Separate `expo_issuer()` / `pnr_issuer()` factories return owner-admitted `IssuerIdentity` only after G2 evidence. No real IDs are pre-minted in this plan.
- `industrials_result_cash.qualify_operands(purpose, cells, *, comparison_receipt)` returns a closed qualification result. `derive_result_cash(formula, cells, *, comparison_receipt)` returns a versioned, exact-decimal derivation or typed limitation. Allowed formulas are `growth_pct`, `margin_pct`, `paired_remeasurement`, `cash_after_capital_payments`, `cash_rollforward`, `segment_change_bridge`, and `final_vs_preview`.
- `financial_dossier.select_editions(documents, *, mode, source_cutoff, recorded_cutoff)` returns owner-native document references and exclusions, never a new event ID. `validate_financial_dossier(payload)` refuses unregistered role/extra fields. `compose_financial_dossier(inputs)` returns one in-memory projection with dependency identities and reviewed narrative; it does not fetch or publish.
- `industrials_theme_research.compose_industrials_research(query, bundle)` adapts an authenticated owner bundle to the accepted shared component. `query` selects an admitted research entry, case/event, edition and time mode; it is not arbitrary filesystem path or URL input.
- The existing private publisher and route dispatch keep their owner-approved signatures. A role-aware extension is tested in T07; no plan-authored function pretends to be an enrolled storage accessor.

A financial operand carries its owner reference/revision/digest and semantic selector, decimal-text value or typed absence, metric, unit and scale, currency, stock/flow, full period, business dimensions, accounting/recast basis, source mode and quality. Native adapters verify these before projection. Missing, nil, ambiguous and zero remain different. Permission and identity do not become trusted merely because fields are populated.

A comparison receipt identifies purpose and operand references, what dimensions were checked, unknowns and valid transformations. Equal nulls never certify required meaning. Year-over-year dates differ intentionally, but durations and business perimeter need an explicit comparability basis. A unit conversion has exact factor and input lineage. A financial loss retains its sign; a zero/negative growth base yields an absolute change plus a refused ordinary percentage, not infinity or misleading growth.

The closed dossier groups are those in revision 2: `schema`, `subject`, `selection`, `dependencies`, `sections`, `derivations`, `narrative`, `policy_refs`, `navigation`, `lineage`, `authority`. Every nested group is closed and bounded under the accepted role. Material sentences point to the source facts and derivations that support them. A generation pins that dependency set and interpretation version, not an invented simultaneous observation clock. No speculative trading confidence appears.
