Parent: existing Macro #6819 / F05 + Rates & Inflation Command. Current Chairman
continuation authorizes delivery; no new umbrella, provider, store or runtime.

## Capability and bounded implementation

Preserve official auction terms through the existing event calendar and display
useful bilingual reference context for every existing calendar family, including
dates with no numerical forecast. Compose with, not replace, Release Radar.
No claim of an LLM assessment, live auction results, calibrated effect or trade.

1. RED: source attribution, announcement fields, missing/invalid amounts,
   distinct same-date securities, reopening identity and type-specific context.
2. Pure calendar projection + source metadata; no network inside projection.
3. RED: real JavaScript renderer and selector; date join, escaped text/URLs,
   partial terms, revision signature, models retained, same-date no-op/races.
4. Jinja inclusion on the actual dashboard; shared tokens/native disclosures.
5. Full production-template render, source-to-browser proof and review of null,
   stale, malformed and no-model behavior. Record exact limits of proof.
6. Register focused tests in the existing CI path, exact-head review, PR and
   governed release. Do not call an open PR or local browser proof production.

## Acceptance

A non-forecast event has useful reference context; supplied official auction
terms are displayed with explicit missing fields. Every event for the selected
date appears, alongside all forecast cards. Corrections to context change the
render signature. No HTML/URL injection, synthesized known-at, fake result,
missing benchmark treated as alpha, or rank/size/trade authority.
