## Review Focus

1. **Late response after logout or account switch:** clear the private view immediately, discard the previous request even if it finishes, and do not let a stale request's cleanup cancel a newer request. T10 tests this race.
2. **Owner correction between pagination requests:** refuse the obsolete generation instead of mixing old prose and new numbers. T08/T09 test both next-page and evidence-drawer requests.
3. **Rights removed after a warm cache has been filled:** deny the next prohibited emission, including counts, pointer labels and errors, without restarting the server. T03/T09 test this.
