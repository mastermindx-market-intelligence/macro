# US candidate source-date browser proof

This is an isolated **browser fixture** from the candidate template, not a deployed production page. It proves that an older or missing board date cannot borrow freshness from the page render time, in English and Chinese at 390px and 1440px widths, with JavaScript disabled. No live signals, orders, provider sessions or customer state are touched.

The five regression cases in `tests/test_p0_prophet_candidate_board.py::test_candidate_heading_discloses_source_date_without_tonight_claim` render the actual `templates/dashboard.html.j2` with old/current/missing/null/empty board dates. To reproduce these screenshots, render the same helper with one live fixture card, `us_prophet_book=_prophet_book(plans=[])`, and `us_standouts.as_of` set to `2026-09-11` or `None`; save the HTML as `.pytest_cache/US-candidate-stale.html` and `.pytest_cache/US-candidate-undated.html`. Then run `node docs/pr-crops/us-prophet-source-date-20260916/probe.cjs /absolute/path/to/chromium` using the existing Playwright installation.

The probe serves only the current template assets locally and performs an explicit static HTML locale/theme-attribute transform. It asserts the selected language is visible, the source date or unavailable state is present, no “tonight” promise remains in the candidate section, and the header wraps inside its viewport. `receipt.json` binds source files, probe, rendered HTML hashes, and the eight actual screenshots. All eight cases passed on Chromium 153.0.8010.48. The stale-English and unknown-date-Chinese mobile screenshots were visually inspected.
