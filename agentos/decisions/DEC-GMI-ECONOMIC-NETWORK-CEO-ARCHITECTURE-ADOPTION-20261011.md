# CEO architecture adoption and execution boundaries

This decision **adopts the architecture for planning and implementation sequencing**,
not individual source/fact admission, owner consent to another writer, release
of held ThemeState/K3-D work, or live product/forecast authority. Accepted
research and previously merged code are **DO_NOT_REDO** absent changed evidence.
Retain all existing exact operation carriers and effect-unknown fences.

## Required first real end-to-end acceptance

The next user/machine capability is **one actual source-backed, identity- and
purpose-qualified, native economic relationship served by the incumbent private
product with an equally real refusal**. The existing source inspector, review set
and private observation are useful accepted predecessors, not proof of that result.

1. Source-owner receipt: original permissible filing/document/span, digest,
   actual availability/edition, corrections and a source-purpose decision.
2. Native fact-owner decision: company/legal-party identity valid for the
   relevant cutoff, role/direction/scope/lifecycle, source-versus-estimate
   distinction, explicit unknown/anonymous party and null magnitude.
3. Data OS gate: registered dataset/profile, immutable identity/version
   references, time eligibility and purpose-specific consumer permissions.
4. GMI read projection: deterministic fixed-input reconstruction, original
   provenance preserved, distinct thematic/comarket edges, mapping refusal
   where a scope cannot be expressed; no guessed weight.
5. Existing K3-D/Economic Propagation: optional conditional *qualitative*
   hypothesis with variable, direction, horizon, alternatives and falsifier.
   Quantitative composition refuses incompatible units, periods and
   denominators. Held mechanisms remain held.
6. F04/Company Intelligence: one real private source-backed positive, one
   real unavailable/identity/time/rights/correction refusal on the actual route,
   same canonical user/machine artifact, generation and entitlement proof;
   desktop/mobile, keyboard, EN/ZH and light/dark checks.
7. Empirical program: freeze sources, events, labels, prospective horizon,
   independent sample clusters, baselines, rewired/layer/direction nulls,
   uncertainty and practical lift. A failed model does not revoke the useful
   evidence product or promote any decision authority.

No issuer's observed stock-price comovement is evidence of a supplier contract;
no commercial contract alone proves stock-price predictability.
