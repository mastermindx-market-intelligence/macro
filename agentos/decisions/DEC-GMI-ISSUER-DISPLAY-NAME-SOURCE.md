  Where does the GMI explorer get an issuer's human display name (G-UI-7), given

answer: >
  Read-side only, inside the explorer projection. The display name is the
  point-in-time symbol directory security_name (newest snapshot on or before the
  package as-of), looked up by the issuer's listing code in its normalised, dash
  and dot spellings (engine.theme_graph.identity.symbol_variants), reduced to a
  plain company name (instrument tail such as "Common Stock", "Ordinary Shares",
  "American Depositary Shares ..." removed; "X (The)" rendered "The X"; one legal
  suffix removed). When no directory row matches, or the reduced name is empty,
  the existing ticker fallback is kept and labelled source "ticker". No name
  column is added to identity_resolution or security_master.
rationale: >
  The symbol directory is the only dated, point-in-time carrier of a security
  name in the repo; identity_resolution.parquet and security_master.parquet have
  no name column (checked). Adding one would create a second name authority next
  to the directory and would have to resolve the master's current-symbol
  disagreement first (build_security_master _current_symbol yields FI where the
  directory lists FISV). engine/theme_graph/identity_resolution.py is a protected
  path for this commission. Keeping the change read-side in
  scripts/gmi_explorer/model.py fixes the user-visible defect (raw instrument
  strings as company names) and a latent wrong-company defect: _ticker_of took
  the text after the last dash, so co:us:BRK-B displayed the directory name of

## Known residual

ISS listing ids carry the INCEPTION code (ISS:US-XNYS-BRK.B). An issuer that was
re-tickered, whose old code was later reassigned to another company, would be
looked up under the old code and could show the other company's name. No GMI id
is affected today. The missing contract is a sanctioned reader from
security_id to the current listing symbol as of a date; until it exists, the
inception code is the lookup key. Suffix stripping removes one suffix from the
existing NAME_SUFFIXES list, so period-less forms ("Corp", "Inc") survive
("B2Gold Corp"); this is cosmetic, not identity.
