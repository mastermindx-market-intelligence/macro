## Material findings for future sessions

**Availability is not continuous inference.** Deterministic services retain health
checks, scheduling, deduplication and ordinary lifecycle recovery. Grok wakes for an
applicable judgment. Its vendor routines can pause; core autonomy cannot depend on
the Bot remaining awake.

**The account is the trust boundary.** Bots within one user share cloud filesystem
and sign-ins; a named Bot has no independent vendor identity. Account authentication
is not run-specific attestation. Initial outputs remain candidates; no trusted Wake
ACK or action-authoritative parent is fabricated from a Bot label.

**Plans are not interchangeable.** Cursor/SuperGrok grants do not stack. Grok on-demand
limits need not stop an in-flight run at the exact cap. Z.AI limits Coding Plan use to
supported tools/products. Alibaba subscription documentation excludes custom automated
backend calls while allowing named classes of coding/agent clients. MiniMax documents
broader API/agent use but also automatic purchased-Credits overflow. Those statements
are public contract observations, not this organization's account qualification.

**A helper must deliver useful evidence.** Validate exact artifact identity, scope,
citations, format and meaning. A successful process exit or a provider-completed state
is not an accepted result. An uncertain effect remains bound to the original carrier.

**Operational judgment can become autonomous.** Once explicitly qualified and admitted
under #612's existing envelope and current binding, a foreman may own permitted repair
or continuation classes without requiring a Web Sol turn for every return. Initial
read/candidate scope must not be confused with that later authority.
