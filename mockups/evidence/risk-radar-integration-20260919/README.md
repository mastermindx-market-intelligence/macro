# Risk Radar integration — browser evidence

The canonical page-evidence tool captured the production-shaped rendered page from
an isolated local HTTP server. No credentials were read or synthesized.

Rest cells use the canonical driver. `radar_open` and `radar_focus` use the
committed `capture_adapter.py` to apply the existing modal presentation classes.
They are **forced local presentation**, not authenticated production witnesses.
Focus captures use real keyboard focus and Enter to open/close native Evidence.
The manifest names both capture-module digests, with each cell attributed.

Matrix: desktop/tablet/mobile × EN/ZH × dark/light; 12 rest cells and 24
forced interaction cells. Every forced cell confirmed the context is inside
Risk Radar, with no page-level horizontal overflow. Desktop context height is
164.6875 px; the standalone dashboard block is absent.

Visual review: light desktop/mobile, dark desktop and Chinese dark mobile were
opened for review. The inset preserves separate trend direction and stress
severity; the rest dashboard retains the original hero and market tiles.

`partial-render-receipt.json` describes the exact source-bundle render and full
builder limitation. Whitespace-only lines in the owned inserted section were
normalized after capture; no rendered text, geometry, style or behavior changed.

Only manifest-referenced PNGs are part of this evidence receipt. Convenient
human-readable screenshot copies and older capture leftovers are not committed.
