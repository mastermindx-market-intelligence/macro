# Phased implementation roadmap

**This is an implementation plan for a later authorized commission.** No production work, source purchase, deployment or new authority is included in this research delivery.

## 1. Smallest high-value slice

Build one **research-only SPX/SPXW-to-ES information-value experiment** through incumbent owners. Compare existing OI assumptions, public eligible flow reconstruction and a scoped participant-informed benchmark, all repriced through the same current Greek machinery, against the same price/liquidity baseline and exact future outcomes.

The first new primary target is the fifteen-minute ES excursion-distribution pinball score specified in report16. Remaining-session LOD/HOD and the 16:00 ES mark/actual SPX close are separately registered secondary targets. Venue-specific share auctions are an adjacent experiment. This preserves the accepted P5 SPY/QQQ/IWM next-ten-minute variance registration and its B2-RI/B1-RI comparison. [I01] [I03] [I05]

The slice answers two questions in order: **does better inventory information help at all, and how much survives realistic availability?** It can stop before a sophisticated public filter, broad product aggregation or new UI.

## 3. Phase 0: concrete source request

Ask existing owners for a bounded source-admission packet, not a new service:

1. Prior and next-available OI vintages and reference contracts for a prespecified session set, with inception/history limits.
2. The uncapped, condition-preserving trade/preceding-quote representation and original source/receipt/consumer clocks where retained; identify any aggregate-only paths.
3. A qualified ES contract/time series and, if available, quote/depth events through the current futures/quote owner. A volume-only denominator is explicitly a first-stage proxy.
4. Existing GEX, Daytrade and Radar outputs/candidate identities at genuine historical availability, or a declared inability to reconstruct them.
5. Legally usable C1 ten-minute participant files or a source-qualified sample, if separately approved; complete release/correction semantics and initial-book limits.

No absence should be repaired by silently replacing a source, borrowing a cohort or introducing a second store. If only final history is available, do the measurement study at that grade and schedule captured-PIT evidence through the incumbent owner before promotion.

## 4. Minimum model block

Reuse the accepted OIF stress definitions and existing pricing kernels. The minimal new output needs starting book assumptions; net participant/public trading increments; separate adjustment state; exact endpoint delta differences; native/ES-equivalent units; 0DTE/1–7D/8+D contributions; signed and gross risk; input/scenario uncertainty; an expected-volume participation proxy; and all source/consumer clocks.

Start with M0 OI scenarios and M1 transparent public signing. A broad M2 feasible scenario set is useful when capacity is unidentified. Use M5 participant-informed increments as the scoped higher-information comparator. A calibrated M3 state filter earns implementation only if that comparison indicates meaningful recoverable information. Particle filtering, high-dimensional neural models and rich execution-policy estimation are not first-slice prerequisites.

Use fixed-IV/sticky-strike as labeled diagnostics first. Add learned surface behavior and minimum-variance hedging only as budgeted ablations. If actual depth is absent, do not implement a synthetic “executable liquidity” figure; report a volume participation proxy and its limits.

## 5. Closing work can proceed as a separate adjacent slice

Choose one venue/security class with admitted auction history. SPY implies Arca's clock; Nasdaq and NYSE require separate phase adapters. Establish public-state persistence and historical auction elasticity before adding dealer pressure. A pre-publication study must use venue- and channel-specific first disclosure, including early manual/broker observations actually known.

This lane can yield useful close forecasts even if dealer inventory has no incremental value. Conversely, a dealer-pressure experiment can answer its primary question without an early broker feed. Avoid making the whole roadmap depend on the least observable proprietary input.

## 6. Cost and sample sequencing

Public C1 ten-minute versus one-minute prices make cadence a meaningful research decision. First audit existing rights/history and any legally eligible sample. A small historical sample is for feasibility, schema and latency sensitivity; the formal result still needs adequate independent sessions. Sample eligibility is not assumed, and this commission requested none. [A29] [A33]

Use the source matrix's essential-representation versus optional-vendor distinction. Every proposed paid increment needs its own measured information gain or a clearly identified remaining measurement uncertainty. A display subscription, a public replay or a vendor API does not automatically permit training, retention or incorporation into a competing commercial terminal.

Engineering duration is deliberately not stated as a fixed promise. It depends primarily on whether atomic history, original receipts, ES data and participant usage rights already exist. The phase0 admission packet makes a realistic later implementation estimate possible.

This package also includes machine-readable feature/data/source registers, a consequential-claim ledger and a rerunnable synthetic witness. A fresh implementation session should recheck the bounded active carriers and source permissions, then begin phase0 without repeating this domain research.
