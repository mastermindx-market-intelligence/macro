# Evidence snapshots

This directory contains selected JSON receipts/diffs and, in the downloadable bundle, fetched source/procedure text snapshots. The curated evidence register links each important claim to its canonical pinned source or original owner receipt.

The source text is supporting context. Prefer canonical Git blob identities for exact byte comparisons; connector or text-patch newline normalization may differ.

No raw paid provider dataset, credential or new production measurement is included. Source code and owner-reported test counts are not evidence that this audit executed those product tests.
