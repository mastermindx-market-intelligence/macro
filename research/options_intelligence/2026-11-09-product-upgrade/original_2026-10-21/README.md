## Intended adoption

Fable should reconcile the exact next original carrier, accept the initial product/source/scientific contracts, and commission ready bounded work under actual runtime capacity. It should continue useful R1/R2, Lab, Exposure, Flow, OA, AD1 and Institutional Options work, with documented custody for any transfer.

The first useful release connects Brief → investigation → exact risk comparison → save/watch → monitor → outcome review for a declared cohort. Predictive families qualify independently. The whole programme remains accountable for all retained product and competitor obligations; a scientific negative result cannot silently remove a promised capability.

No external tickets, implementation dispatch, takeover, purchase, deployment, customer recommendation authority or brokerage execution was performed by this audit.
