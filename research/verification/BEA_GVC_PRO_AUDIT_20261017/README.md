# BEA/GMI Pro audit — visual verification

These images were captured from the actual local Chromium renderer using the committed HTML/CSS/JavaScript implementation and hermetic test inputs. They are **not production screenshots or native BEA source proof**.

- `before.png`: initial source-unavailable design, before this audit.
- `after-unavailable-desktop.png`: new desktop UI with an empty test Registry; no industry values.
- `after-unavailable-mobile-dark.png`: new 390-pixel dark-mode UI with the same unavailable source state.
- `after-SYNTHETIC-research-component.png`: a visibly watermarked, unpublished component preview generated from synthetic test rows. The browser network controller never enters this mode. No real BEA figures or publication authority are represented.

The screenshots can be regenerated by `MMX_GMI_SCREENSHOT_DIR=<local-directory> python -m pytest tests/test_bea_gvc_browser.py`. The tests require physical Chromium through Playwright; they do not silently skip if it is missing. See the main audit report and PR #9494 for source and test identities.
