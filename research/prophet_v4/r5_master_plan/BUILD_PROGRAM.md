# Prophet US — implementation and acceptance program

This is a source-bound program plan. No unit is dispatched, no writer is assigned, and no future test is marked passed. Every unit requires fresh canonical source/custody and admission at execution. Code-level plans and exact source signatures are frozen against the admitted head rather than invented for interfaces whose owner decisions remain open.

## Common execution contract

Consume the exact accepted input/specification; preserve existing source owners; write a discriminating failing regression for the named negative cases; verify the failure on the relevant base; implement the smallest owner-compatible change; run the focused and registered integration checks; commit and qualify the exact head; obtain independent review; prove the real consumer and ordinary refresh where owed. Never bypass a missing owner contract or retry an unknown effect. Steps use current repository commands, not guessed test names.
