# 1. Findings that must survive into R6

## F1 — Detection and action are separate

NVDA was useful to the system before the formal plan existed.

The stack exposed:

1. unresolved importance;
2. technical acceptance;
3. Entry Availability;
4. formal plan publication.

These clocks must remain separate.

## F2 — Emergence is not an H5 return predictor

The early NVDA state existed about 11 observed board sessions before the T1 `buy_now` state.

The emergence job is:

> keep an important unresolved candidate visible and researched while entry is closed.

## F3 — Ignition is a separate interaction

The strongest historical discovery is not “news”.

It is:

> **fresh T2 acceptance × convergence of multiple independent evidence families**

This is prospectively preregistered and has zero authority.

## F4 — Persistence has two meanings

- research persistence: keep the candidate alive before entry;
- leadership persistence: after ignition, estimate survival of relative leadership.

Do not merge them.

## F5 — Freshness can consume the edge

On Sep-25 the plan intake admitted NVDA but correctly rejected plan construction because the source board was stale/mixed-vintage.

The formal plan arrived only after a clean source plane existed.

The provenance validator was correct.

The upstream freshness/publication path cost time.

## F6 — Current evidence semantics are not yet sufficient

Examples:

- `news_burst` is attention/information arrival, not bullish sentiment;
- legacy `sue_fresh` does not guarantee positive direction;
- `sue_fresh_days` is not a lawful earnings event clock;
- 13F smart-money evidence is directional but stale;
- options/GEX can disagree and should remain a confirmer/caution layer.

# Final program ruling

The NVDA episode does **not** call for a new Prophet.

It calls for completing the architecture R6 already intended:

> **lossless candidate visibility (B03)  
> + typed evidence dossier (B04/D5)  
> + existing Research Priority where lawful (RP1)  
> + separate prospective emergence / ignition science (Conditional Fusion + Eval)  
> + deterministic Entry Availability (B4)  
> + provenance-clean low-latency publication  
> + conditional post-ignition durability**

The major new insight is that the system should preserve **importance before actionability** and measure whether that early attention converts later, rather than forcing every useful observation to become a trade signal immediately.
