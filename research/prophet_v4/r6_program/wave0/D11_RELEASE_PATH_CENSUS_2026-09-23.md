**How a served page/policy is withdrawn today (OBSERVED):**

An `engine/**` revert goes through `engine-render.yml`.

- (e) **Caddy config.** Installed only after `caddy validate` (`update.sh:372-376`), so a bad config cannot be rolled out; withdrawal = revert + next pull.
- (f) **R2 objects.** `stockdata` republished by every covering render (`render.yml:1238`); `prophet/health.json` nightly (`daily.yml:2384-2400`). No object-version rollback command exists in this repo — a stale object is healed FORWARD by the next publish, or withdrawn locally by (d). **What a rollback would NOT roll back:**
- Forward-accountability ledgers — `data/prophet/ledger.jsonl` is append-only, the nightly is the SOLE advancer, idempotent per plan ID (`daily.yml:2321-2326`; `build_prophet.py:122-123`); the express lanes discard every `data/` write by design (`render.yml:28-30`; `engine-render.yml:12-18`), so a revert cannot un-advance a ledger.
- Grades and board snapshots — `data/us_board_ledger/retro_grades.parquet` + `snapshots.jsonl` are FOSSILS: "the ledger is deliberately NOT rewritten when copy changes in live code" (`build_prophet.py:284-292`). A revert can only change what a NEW card built from an old snapshot says (`:305-330`).
- Origination receipts / provenance — the checkpoint publishes a closed allowlist, forbids deletions, aborts on a same-path change on main (`daily.yml:2376-2382`, `:2682-2706`).
- User state — Supabase accounts and `user_entitlements` rows (`app/paywall.py:330-347`), analytics events already inserted (`app/main.py:582-591`), browser-local watchlist/portfolio state (`templates/watchstore.js`, `portfolio_state.js`, public per `Caddyfile:344`) — untouched by a `site/` revert.
- The public R2 health receipt keeps its old `checkpoint`/`index_sha256` until the next nightly republishes it (`build_prophet.py:216-247`).
- Asset bytes pinned by the immutable year — `?v=`-stamped reviewed-public assets serve `public, max-age=31536000, immutable` (`Caddyfile:549-553`). A body rollback that does NOT move the stamp leaves returning browsers on the old bytes for a year — the `#3617/#3624` class the render lane warns about (`render.yml:1268-1272`). Because the stamp is a content hash (`optimize_assets.py:57-59`), a true revert moves it.

**The "never restore a cached old ENTRY_OPEN" hazard.**
