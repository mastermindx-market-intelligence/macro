## CONTRACT

### (a) Completed-session binding

The exact producer predicate is `_normalise_us_equity_universe`: it normalizes the observation to UTC, calls `expected_last_session(observed)`, and invokes `_clip_daily_to_completed_session` on every non-crypto close and high (`scripts/build_stock_library.py:1974-2015`); per-name raw OHLCV is likewise clipped before technical reads (main path around `3780-3787`). `_clip_daily_to_completed_session` rejects every index date after the completed session (`scripts/build_stock_library.py:1963-1971`).

The origination gate independently resolves the expected session: timestamp observations use `expected_last_session`; legacy date-only replay uses `last_session_on_or_before`; any mismatch is a clock error (`engine/prophet_bridge.py:898-932`). Mixed-vintage, unknown, delayed, or wrong-basis boards add explicit refusals (`engine/prophet_bridge.py:933-950`). Arena passes the same `observed_at_utc` to the bridge resolvers (`engine/prophet_arena.py:1856-1870`). Therefore a pre-close 2026-09-15 equity daily bar cannot satisfy the producer predicate at 15:09 UTC: it is physically after expected session 2026-09-14 and is masked out, while raw reach still discloses it. This is the enforcement required by `DSC:PROPHET-PRECLOSE-DAILY-BARS-ARE-NOT-COMPLETED-SESSIONS`; M1 proves the guard can fail.

### (b) Exact-source frozen object and hash

`_freeze_origination_source_board` reads raw bytes once, parses them into `_standouts_doc`, computes `sha256(raw)`, writes deterministic gzip to `data/prophet/origination_sources/<sha256>.json.gz`, and refuses symlinks, parse failures, and hash-path collisions (`scripts/build_prophet.py:130-208`). The same parsed object is passed to live origination (`2064-2071`), deep-copied to Arena (`2101-2105`), deep-copied to legacy shadow (`2150-2159`), and used for index `gate_go` (`2624`). `originate_plans` deep-copies the supplied object and never opens the mutable path when it is present (`engine/prophet_bridge.py:4082-4139`). Index publication carries `source_board_sha256`, snapshot path, and gzip encoding (`scripts/build_prophet.py:2603-2617`). Because the frozen object and frozen bytes leave the freeze site together and consumers receive object copies, a later mutable-path rewrite cannot silently change consumer input; nightly independently rehashes live bytes, captured bytes, and decompressed durable bytes and withholds publication on mismatch (`scripts/ci/daily_engine_prophet_nightly.sh:165-214`). Any byte change changes the SHA/name; M2 proves a post-freeze reopen is detectable.
