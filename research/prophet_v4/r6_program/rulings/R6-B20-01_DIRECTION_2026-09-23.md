### R-A — Availability state → stance → color → row anatomy (resolves B1, M1, M2; critique R2)

The state set is the closed `AVAILABILITY_STATES` in `engine/prophet_entry_availability.py` (seven states). Stances are the doctrine's six words (`docs/DESIGN_DOCTRINE.md` Law 1). **Green is `ENTRY_OPEN` only, in both themes.** This table is binding.

| `availability_state` | Stance EN / ZH | Action-column label EN / ZH | Color role |
|---|---|---|---|
| `ENTRY_OPEN` | Act / 可行动 | Entry open / 入场窗口开启 | the only green (`--ink-ok`) |
| `APPROACHING_ENTRY` | Get ready / 准备 | Approaching / 接近入场 | neutral accent ink, never green |
| `NOT_READY` | Watch — don't chase / 观察，勿追 | Not ready / 尚未就绪 | muted ink |
| `WAIT_PULLBACK` | Watch — don't chase / 观察，勿追 | Wait for pullback / 等待回调 | muted ink |
| `RAN_DONT_CHASE` | Stand aside / 观望 | Ran — don't chase / 已启动，勿追 | muted ink |
| `INVALIDATED` | Ignore / 忽略 | Invalidated / 已失效 | struck stance, muted ink, no red alarm |
| `UNAVAILABLE_DATA` or no producer row | (no stance) No read yet / 暂无判断 | No read yet / 暂无判断 | muted ink, dashed leading rule |

- "Protect gains" is unused in v2 (no held-position surface, see R-D) and must not appear.

- No template consumes `availability_state` today (critique receipt: `git grep` finds `engine/` only). v2 therefore shows the `UNAVAILABLE_DATA` / "No read yet" anatomy as the **default composition** of every list, not as an edge case; the `ENTRY_OPEN` row is the exception composition.
- The glance row is NOT `.mx-chg-row`. v2 specifies a Prophet row anatomy: name · one-line change (≤14 words) · stance verb · action-column label · chevron; the six-field detail moves into the expanded row body (R-B).
