## 5. Independence rule — who fills the review slot (stated as it is, not as intended)
1. Inside a lane the review round is a separate engine process in a separate worktree (`lane2.py:447`, `rev_wt`) with its own transcript (`r{n}_review.out.md`, `VERDICT_LINE` + BLOCKERS/MAJORS/MINORS). Two limits: the review prompt injects the fixer's own report (`{fix_out[:6000]}`, `lane2.py:352-355`), so the reviewer is anchored on the author's account; and the executor guard (`lane_bin`) applies only to non-review steps (`lane2.py:219`), so the reviewer's read-only-ness is enforced by prompt alone. Consequence: **the seat ratifies from the diff and the artifact, never from the review summary.**
2. In practice every program lane used `glm-codex`/`glm-5.3` for BOTH fix and review — including judgment-bearing units (`pu_w2_cycle_a_diag_prereg`, `pu_w2_b16a_matrix`, `pu_w2_rule4_era`, `pu_w2_b04_census`, `pu_w2_dspr0a`, `pu_w2_b20_1_spec`).
