## Reproduce the bounded contracts

Run the commands in the named directory. Read each design first. The scripts use retained data or immutable Git objects and their declared temporary outputs; they are not production installation scripts. A rerun may overwrite result files. Copy the retained study tree with its original relative dependency layout to a new temporary directory; copying only one package can break suites that resolve earlier empirical inputs or sibling fixtures. Preserve the reviewed originals and their manifests.
