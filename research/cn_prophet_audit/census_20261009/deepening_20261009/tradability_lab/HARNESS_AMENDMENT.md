# Harness correction before acceptance

The first unsealed metadata census omitted the `numbers` global required by the native `_last_session` helper. Its broad native exception handler returned `None`, so the research adapter suppressed deep-price upgrades. This is a harness defect, not a demonstrated production defect. The original attempt (script, output and process receipt) is preserved in `harness_attempt_missing_numbers/` and must not support the accepted census.

The corrected adapter imports and injects `numbers`, asserts a known valid native last-session result before loading data, and executes the exact nightly stock-set assignment instead of assuming the pack's filter is equivalent. It asserts the two sets coincide on this frozen input; it makes no claim of universal equivalence for arbitrary future universes. All production source and data bytes remain unchanged.

The corrected run also records whether the unversioned breadth cache exists on the host without reading its content, and checks versioned breadth constituents against the current stock set. This clarifies the immutable replay's coverage limitation. No outcome labels, formula, screen threshold or fixture category is changed.
