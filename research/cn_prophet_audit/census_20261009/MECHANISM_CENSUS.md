## Mathematical score, intelligence and qualification supplement

All source links in this supplement name the same immutable Macro commit. Let `clip01(x) = min(1, max(0, x))`; `round` below means the source's Python rounding, in the stated order. These are distinct score, ordering, and admission mechanisms.

### A. The six-term Prophet score retained by v4

For each component, the engine first computes `points_j = round(weight_j × value_j, 4)`, then **`Prophet = round(min(100, max(0, sum(points_j))), 2)`**. It serializes component values to six decimals; those rounded display values are not the inputs to the original point calculation. The weights sum to 100 and are frozen definition inputs. [Weights](https://github.com/mastermindx-market-intelligence/macro/blob/3d90aad6d83152dfeeaf8345bc995826ac9d3139/engine/china_board_rank.py#L114-L160); [calculation and serialization](https://github.com/mastermindx-market-intelligence/macro/blob/3d90aad6d83152dfeeaf8345bc995826ac9d3139/engine/china_board_rank.py#L883-L947).

| Component | Maximum points | Exact normalized value |
|---|---:|---|
| Signal | 30 | Base T2 = 1, T1 = 0.9, T3 = 0.7, other/missing = 0. Subtract 0.1 for a provisional verdict, floored at zero; multiply by 0.85 when `ticks == 2`; additionally for T3 multiply by 0.70 when finite `bars_to_cross >= 2`, or 0.85 when it equals 1. Clip to [0,1]. These are board-score coefficients, distinct from the raw cascade weights. |
| Entry | 20 | `bounce_wait` 1; `wait_pullback` 0.95; `hold` 0.8; `buy_now` 0.7; `partial` 0.6; `later` 0.5; `await`/`await_confluence` 0.45; `watch` 0.4; `buy_soon` 0.35; `extended` 0.3; `topping`/`blocked`/`exit`/`avoid` and unknown status 0. ### B. Board-independent intelligence interest and global ordering

The interest formula is **`I = round(clip(100 × C × F × E × G, 0, 100), 2)`**, provided both a leading-desk record and at least one edge component exist. The core `C` uses an unrounded internal value; its serialized three-decimal value is explanatory. The edge `E` is rounded to three decimals **before** multiplication. [Definition and output](https://github.com/mastermindx-market-intelligence/macro/blob/3d90aad6d83152dfeeaf8345bc995826ac9d3139/engine/china_intel_interest.py#L284-L338).

**Core `C`:** if an altdata row exists, use `clip01(0.85 × max(max(convergence, 0), accumulate_conviction100 / 100))`, where `accumulate_conviction100` is the conviction value only when `side == 'accumulate'`, otherwise zero. Missing/unparseable numeric fields contribute zero. Altdata presence takes precedence even when its result is zero; the function does not substitute a stronger radar reading. Only when altdata is absent does a radar record supply `clip01(0.60 × strength)` for `sign == 'positive'`, otherwise zero. If both desks are absent, the result is unavailable. [Core and precedence](https://github.com/mastermindx-market-intelligence/macro/blob/3d90aad6d83152dfeeaf8345bc995826ac9d3139/engine/china_intel_interest.py#L113-L156).

**Edge `E`:** take the weighted mean of the components that actually exist, clip to [0,1], then round to three decimals. An empty component list returns `None`; it does not receive the Hub's default 0.4. Returns, relative strength and off-high values below are percentage points. [Exact components](https://github.com/mastermindx-market-intelligence/macro/blob/3d90aad6d83152dfeeaf8345bc995826ac9d3139/engine/china_intel_interest.py#L161-L224).

| Available evidence | Weight | Component value |
|---|---:|---|
| Finite `off_high_pct` | 0.6 | 0.1 when rolling over; otherwise `clip01(0.15 − off_high_pct / 22)` |
| Finite `rs_20d` | 0.7 | 1 when RS ≤ 0; otherwise `clip01(1 − rs_20d / 35)` |
| Finite `ret_20d > 12` | 0.6 | `clip01(1 − ret_20d / 30)`; no component is added at or below 12 |
| Large unlock; else ordinary unlock | 0.8; else 0.5 | 0.15; else 0.30. The two unlock components are mutually exclusive. |
| Pledge stress | 0.6 | 0.10 |
| Any altdata flag containing “crowd”, case-insensitive | 0.7 | 0.15 |

The actual price reader requires at least 21 prices. Its off-high calculation uses the maximum of `tail(252)` once at least 120 observations exist, despite a shorter-window docstring. Relative strength subtracts CSI300 returns on shared, non-null dates. Rolling-over is a 20-session return below −8% plus either `rs_20d < rs_60d` when both exist, or `rs_20d < −10`. These are deterministic price descriptors feeding the table, not forward-return estimates. [Trajectory code](https://github.com/mastermindx-market-intelligence/macro/blob/3d90aad6d83152dfeeaf8345bc995826ac9d3139/engine/china_intel_hub.py#L642-L766); [−8% constant](https://github.com/mastermindx-market-intelligence/macro/blob/3d90aad6d83152dfeeaf8345bc995826ac9d3139/engine/china_intel_hub.py#L43-L49).

**Gap `G`:** `1 + 0.15 × clip(gap, −2, 2)`. `lead_up` counts an accumulating altdata desk and a positive radar desk. `lag_up` is hardcoded zero, so the current gap is 0, 1 or 2 and `G` is 1, 1.15 or 1.30. **Falsifier `F`:** 0.85 once if any condition holds, otherwise 1: rolling-over; accumulating altdata with finite convergence below 0.4; radar reliability basis `unproven`; large unlock; or pledge stress. Multiple conditions do not compound the haircut. [Gap and falsifiers](https://github.com/mastermindx-market-intelligence/macro/blob/3d90aad6d83152dfeeaf8345bc995826ac9d3139/engine/china_intel_interest.py#L229-L279).

No desk produces `no_desk_evidence`; no edge produces `no_edge_evidence`; both yield `fallback_v3` with a null score. At the board attachment boundary, a record must be a mapping with basis `measured` and a finite numeric score; it is then clamped to [0,100] and rounded to two decimals. The reviewed controls confirm that missing records, NaN and unparseable text fall back, while measured zero preserves intelligence mode. This is not a comprehensive schema validator: the board float parser accepts numeric strings and booleans, whereas the interest producer's `_f` rejects booleans, lists and dictionaries. A measured basis denotes computability under this definition, not verified age or calibrated predictive value. [Attachment](https://github.com/mastermindx-market-intelligence/macro/blob/3d90aad6d83152dfeeaf8345bc995826ac9d3139/engine/china_board_rank.py#L225-L241); [record validation and coverage](https://github.com/mastermindx-market-intelligence/macro/blob/3d90aad6d83152dfeeaf8345bc995826ac9d3139/engine/china_board_rank.py#L471-L560); [reviewed controls](ordering_diagnostics.json).

### C. Altdata normalization and the reachable learned-weight feedback

Altdata is not wholly static. Its signed prior weights are **value +0.24, margin +0.20, flow +0.18, comment +0.15, LHB −0.10, block −0.05, analyst +0.08**. Raw analyst score is clipped `(buy − sell)/(buy + hold + sell)`; value is clipped `(50 − mean available PE/PB/PS historical percentile)/50`; margin is clipped `chg_pct/20`. These raw clips are [−1,1]. Comment, LHB, block and flow supply their producer scores. Within each feed's available cross-section, tied raw values receive their average zero-based rank divided by `N−1`; a single observation receives percentile 0.5. The signed input is `x_j = 2 × percentile_j − 1`. [Priors and loader](https://github.com/mastermindx-market-intelligence/macro/blob/3d90aad6d83152dfeeaf8345bc995826ac9d3139/engine/china_altdata.py#L40-L68); [raw transforms and tie ranks](https://github.com/mastermindx-market-intelligence/macro/blob/3d90aad6d83152dfeeaf8345bc995826ac9d3139/engine/china_altdata.py#L89-L139).

For each name with at least two present feeds and a nonzero weight denominator, **`convergence = sum(w_j × x_j) / sum(abs(w_j))`**, summed only over its present feeds. Side is accumulate above +0.05, distribute below −0.05, otherwise neutral. Using the unrounded convergence, `conviction100 = int(round(100 × clip01(abs(convergence) × min(1, n_present/3))))`; convergence is subsequently stored to three decimals, per-feed signed values to two, and its final cross-sectional rank percentile to one. Interest therefore consumes the stored three-decimal convergence and integer conviction. Presence count includes available feeds whose current weight is zero. If analyst, valuation and margin are all absent, the producer returns no rows before considering the other feeds; missing individual feeds otherwise drop out. `full_rows()` exposes this full result to interest, not the display top/bottom 30. [Combination and output](https://github.com/mastermindx-market-intelligence/macro/blob/3d90aad6d83152dfeeaf8345bc995826ac9d3139/engine/china_altdata.py#L142-L236); [integer rescaling](https://github.com/mastermindx-market-intelligence/macro/blob/3d90aad6d83152dfeeaf8345bc995826ac9d3139/engine/china_conviction.py#L23-L34).

`_leg_weights()` calls `china_signal_lab.leg_weights_for('altdata')`; missing/error results fall back to priors. The reachable updater reads the last-written `data/china_validation/scorecard.json`, preferring its `families` map (legacy `results` accepted). Value maps to valuation, margin to margin, and flow to fundflow; the other four altdata legs retain priors in this updater. For each mapped family:

- When `proven` and `sign_ok` are true, multiply its prior by `min(1.5, 1 + 5 × abs(mean_ic))` (`ic` is a legacy fallback; missing IC contributes zero boost).
- Otherwise, when `sign_ok is False`, `abs(t_hac) >= 2`, and `n_obs >= 25`, set its weight to zero. **25 is the pinned imported constant and the exception fallback**, not the stale docstring's 120 observations. This demotion branch does not require `proven`.
- Otherwise retain its prior. Normalize the resulting weights by their **signed sum**, round each to four decimals, and return original priors if that sum is nonpositive. Altdata then applies its separate absolute-weight denominator over the feeds present for each stock.

[Updater, mappings and normalization](https://github.com/mastermindx-market-intelligence/macro/blob/3d90aad6d83152dfeeaf8345bc995826ac9d3139/engine/china_signal_lab.py#L27-L95); [imported threshold](https://github.com/mastermindx-market-intelligence/macro/blob/3d90aad6d83152dfeeaf8345bc995826ac9d3139/engine/china_validation.py#L97-L104); [last-written reader](https://github.com/mastermindx-market-intelligence/macro/blob/3d90aad6d83152dfeeaf8345bc995826ac9d3139/engine/china_validation.py#L744-L752).

The scorecard's producer prefers the 21-session headline horizon. Its `proven` flag requires the family's distinct-week minimum, at least eight non-overlapping windows, `abs(t_hac) >= 2`, and the expected IC sign; its cross-sectional/time-series minima are 40/25 weeks. The consumer trusts that saved flag; it does not re-run this validation or inspect `is_context_only`. This is a rule-driven, outcome-informed feedback path, separate from the frozen six score weights. It establishes neither which families actually earned changed weights on October 9 nor a trained, calibrated end-to-end stock-return model. That would require the exact consumed scorecard and independent validation of its evidence. [Promotion producer](https://github.com/mastermindx-market-intelligence/macro/blob/3d90aad6d83152dfeeaf8345bc995826ac9d3139/engine/china_validation.py#L602-L635).

### D. Two-stage qualification and how the caps bind
