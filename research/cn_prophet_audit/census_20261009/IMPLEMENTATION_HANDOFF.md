6. **Consider adaptation after simpler alternatives earn it.** W7 follows qualified data and enough distinct temporal evidence. W8 should make every accepted change legible to users and the existing weekly/forward diagnostic processes; it does not create a new orchestration system.

## 5. Boundaries that future implementation must preserve

- **No second candidate store, outcome grader, theme graph, tactical engine, publication owner or orchestration queue.** The conceptual V2 responsibilities in the report are mapped to existing modules.
- **No direct board feedback into intelligence features.** Prophet membership, rank, score and entry state may be evaluation controls, not evidence that creates the same rank.
- **No silent authority escalation of CIE metadata.** A source-backed company observation is not automatically an earnings surprise, a catalyst or a tradable recommendation.
- **No resurrection of killed constructions.** Preserve the particular A-share subsector-state reversal gate, price-only supply-absorption construction, adjusted-tape legal-limit inference and the broad unqualified fused-composite prohibition. A genuinely different experiment must name the old construction and explain the distinction; a renamed version is not new evidence.
- **No private TuShare paperwork request.** `DEC-CNLI-TUSHARE-COMPLIANCE-IS-CHAIRMAN-VERIFIED-PRIVATE` records compliance as `CHAIRMAN_VERIFIED_PRIVATE / SATISFIED`. Technical endpoint entitlement, quota, schema, timing and coverage checks remain; settled contractual approval is not reopened.
- **No daily Northbound directional factor from discontinued public daily holdings.** The current official publication is quarterly. Preserve the existing exclusion. No supply-chain terminal purchase or Beijing expansion is proposed here.
- **No performance guarantee, model-originated sizing or trading.** A priority score is not expected return; expected return is not confidence; confidence is not suitability or access.

## 6. Verification and production observability

The smallest useful verification set should fail on the observed bad behavior. Add the real canonical board document to existing pack/reconcile tests; a fixture invented in the loader's preferred schema will miss the present defect. Test frozen score/rank projection, actual scheduled arguments, source-time rejection, complete/missing/zero coverage, rounding/ties, no outcome-driven replacement, idempotent event consumption and T+1 exit restrictions. Keep tests in the owning, already registered suites; if a new suite is genuinely required, register it through the existing CI owner. Do not run an unrelated full suite on a partial source copy.

For natural bakes, record counts through every funnel stage, coverage by feature, effective-order reason, stale source counts, selected definition/generation, delayed publication, original versus corrected-fill differences, unresolved outcomes and live confirmation counts. Make the record useful for an operator: “four non-competing intelligence records forced v3 order,” “no feature-qualified opportunities,” “data could not be evaluated,” and “no new live events consumed” are different states. Reuse current telemetry and ledgers; do not add a new lifecycle authority.

Production acceptance must bind exact source/release and actual consumer behavior. This commission verified public server-rendered membership/order at one timestamp. It did not execute page JavaScript, observe authenticated JSON, prove installed intraday service identity or confirm a natural live-event write. These are precise W2/W8 proof obligations, not a claim that all production access is unavailable.
