## Applied change 1 — MarketOntology: separate the path assessment from internal state language

**Targets:** file `01M3P1X4FR6BRTB13KA736Y1HT`, page `p-1-0`; desktop `44L-0`, mobile `4F5-0`.

The old hero said “Not running,” elevated a repeated 2/4 fraction, and mixed the market reading with implementation terms such as owner episode, receipts and downstream contradiction. A reader could interpret this as a failed application, a progress score or causal proof.

The revised hierarchy leads with **Oil condition unmet**, then **Inactive**, the dated snapshot and **Source verification unavailable** beside the assessment. The dominant repeated fraction became a status summary; a single concise count remains contextual. The sequence remains an ordered set of four conditions, not a score.

| Before | After / resulting job |
|---|---|
| Not running | Oil condition unmet; Inactive |
| Inspect first blocker | Inspect oil condition |
| Owner episode | Path status |
| Current path · four owner reads | Four required conditions |
| Selected leg · exact receipts | Selected condition · evidence |
| The answer is not the same as the latest reading | What this reading means |
| No accepted prior transition to compare | Earlier comparison unavailable |
| True downstream legs do not prove oil causality | Oil link not established |
| What would move this chain out of dormant? | What must change next |
| Return to first blocker | Return to oil condition |

The interpretation now states that rates and duration meet their tests while the oil and inflation-expectation conditions do not. It does not infer independent causation. Later readings cannot fill missing earlier conditions or establish the oil-led path.

## Architecture decisions from the broader audit

### Keep executive and investor jobs distinct

OS Today → project → work/review → receipt is an executive workflow. Investor Today → research/object → evidence → follow-up is a research workflow. They may reuse visual primitives, but their project, decision and market-data meanings should not be collapsed into one global navigation.

### Expose depth in its existing context

OS already contains plan, evidence, journal, decision and receipt screens. Improve the route from the project workroom to those capabilities instead of adding parallel global pages. Similarly, AI Sources, research depth, Save review and context handover are different jobs with different effects; a generic “Investigate” destination obscured that distinction.

### State must tell the reader what is known

Unavailable evidence, unmet model conditions, stale assessments, conflicting sources, unconfirmed writes and an inactive process have different meanings. Preserve those distinctions in the primary view. Counts and progress-like graphics must not imply a validated signal, activation probability or completed causal path.

### Preserve the original object and the return path

An evidence overlay remains bound to its answer or selected condition. Page navigation must not silently change a saved case's subject. Closing a review restores the original answer, draft, selected reading and focus. A research choice must not silently create a case or turn on monitoring.
