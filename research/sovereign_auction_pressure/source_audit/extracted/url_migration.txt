    To support implementation of the Debt Financing System, TreasuryDirect auction pages are being
reorganized, and many URLs will undergo minor changes. Application Programing Interface (API), xml,
and pdf file URLs will remain unchanged. A high-level overview of the revised structure appears below,
while Table 1 provides a detailed comparison of the current and new structures. These changes will
tentatively take effect on Monday, October 19, 2026.


   •   Auction Announcements
        o Recent Auction Announcements
        o Treasury CUSIP Release
        o Tentative Auction Schedule
        o New Cash Paydown
        o Upcoming Auctions table - The Results tab on the Upcoming table was removed
   •   Auction Results
        o Today’s Competitive Results
        o Auction Results by Security Type table
   •   Previous Announcements, Results, & Historical Data
        o Announcements and Results by Auction Year table
        o Record Setting
   •   Auction Query
        o CUSIP Hyperlink - Interest Payment Dates & STRIPS (New Page)
   •   TIPS/CPI
   •   FRN Indexes
   •   Buyback Announcements & Results
