Upcoming Upgrade to Treasury Automated Auction Processing System (TAAPS®)
In September 2025, the U.S. Department of the Treasury announced plans to upgrade TAAPS. To ensure a
smooth transition, Treasury is providing advance information about the upcoming changes that may impact users
who rely on Treasury auction files or Marketable Securities Application Programming Interface (API) data from
TreasuryDirect.

Changes to Auction Files and API Fields
Auction files published on TreasuryDirect will feature a revised structure and will include additional fields. The
Marketable Securities Application Programming Interface (API) will also be updated, incorporating new fields
and renaming many of the existing fields. The updated auction XML specifications are linked below and available
for review to help users understand these changes. Additionally, the tables on pages 2 - 9 contains a crosswalk
of fields between the current TAAPS XML files and API fields and the new XML & API specifications.

Most fields present in the TAAPS XML files and TreasuryDirect API can be mapped directly to new fields or
derived from multiple new XML and API fields. However, it is important to note that, following
the implementation of these changes, the “Series” element will no longer be produced.

Preparation and Next Steps
Although the exact implementation date has not been finalized, consumers of auction files or API data are
encouraged to review the updated specifications by the end of August 2026 and begin planning for necessary
changes to their internal systems. This preparation will help ensure the capability of processing auction files or
API data after implementation. Further details regarding the timeline will be provided at a later date.
