# Mount-table declaration parser

`mountinfo_contract.py` is a pure, bounded parser for caller-supplied Linux mountinfo bytes. It selects exactly `/sys/fs/cgroup`, requires the caller's mount ID and major/minor device to match, rejects duplicate IDs, ambiguous target mounts and nested mounts, and returns a closed redacted declaration. It performs no filesystem, process, network or runtime operation and is excluded from the fixed v4 canary capsule.

The supported input is the complete supplied mountinfo payload within an ASCII-only profile: each record must contain printable ASCII (plus the required LF terminator). Legal kernel mountinfo containing raw non-ASCII path bytes, more than2048records or a record longer than4096bytes is refused even when that record concerns an unrelated mount. Long overlay lowerdir options can therefore make a real payload unsupported. Callers must preserve that refusal; they must not pre-filter records to pass these checks, because doing so can hide duplicate or nested declarations. This parser does not claim universal mountinfo support.

The source permits the four standard path escapes and unknown optional fields. It bounds the whole input to262144bytes,2048lines and4096bytes per line, rejects noncanonical numeric fields and rejects foreign objects before caller hooks can run. The supported profile is deliberately narrow; a refused record is not host or enforcement evidence.

Matching mount IDs, devices and a mounted root of `/` does not authenticate the collector or prove the initial host namespace. The kernel documents mount IDs as reusable and cgroup namespace views as relative to their namespace root. A later admitted observer must establish descriptor and namespace custody, observation timing and container association. All namespace, full-host-hierarchy, enforcement and candidate-admission flags stay false. [Kernel mountinfo format](https://docs.kernel.org/filesystems/proc.html#proc-pid-mountinfo-information-about-mounts); [cgroup namespaces](https://docs.kernel.org/admin-guide/cgroup-v2.html#namespace).
