## 3. A content update is not a source refresh or a stock signal

The proposed reader considers separate questions, using revisions and history supplied by existing owners:

**Is the evidence usable?** Review, source rights, representation, processor permission, identity scope and actual supported reader must be established. A fixture boolean is not a production receipt.

**Is it new for the requested information set?** Separate source publication/availability from recording, build and delivery clocks. Date-only availability is an interval, not midnight invented as a known timestamp. Missing timing stays missing. A source first discovered today but published weeks ago can improve context without becoming today's economic news.

**What kind of change is it?** New comparable observation, new standalone report, separate proposition, correction, hypothesis, target, repeat or historical context. These are proposed presentation distinctions, not new persisted lifecycle states or global event enums.

**What does the economics support?** Preserve business role, process/material specification, units, product/segment/perimeter, ownership and horizon. A cost quote is not consumed cost; a forecast is not an actual; a contract's delivery is not another mine's supply. Reuse the R12/R14/R15 economic checks rather than reimplementing financial truth here.

**What was expected?** Prior observation, prior management guidance, externally measured consensus and an accepted house forecast are different baselines. A consensus-surprise claim requires an actual earlier consensus reference on a comparable basis. Missing comparison data cannot pass through a generic new-report fallback while retaining surprise language. **R17 qualification:** apply this requirement before every text-bearing output, including historical background and correction notices, not only new reports. A missing, non-prior or incompatible comparison must not become publishable merely by changing its presentation label. A separately reviewed noncomparative statement may still be used; do not automatically relabel unsupported comparative text as a plain fact.

**What is the appropriate next action?** For this release, inspect the dossier or follow a specific evidence condition. Do not generate Buy, Short, trim, portfolio size or a more aggressive global stance from a Materials explanation.

The independently important horizons remain visible: when the information became available, the operating period it describes, when its economic effect may appear, and any existing stock-entry horizon. A quarter-scale cost thesis is not an intraday entry trigger. An expected target date passing does not prove completion and does not independently create a new source observation.

## 4. Novelty, correction and dependence

An unchanged native revision should not become another economic development because the brief is regenerated. The existing run identity can still change; source novelty and run identity answer different questions. Repeated publications referring to the same event must not manufacture independent confirmations. Production dependence must come from supported lineage, not fuzzy company-name matching or an LLM's confident assertion of independence.

A correction identifies its exact predecessor and proposition. It changes what the system should believe about that statement, not necessarily the underlying business during a new period. An unrelated statement from the same issuer remains separate. A correction can deserve a visible correction note even if its economic magnitude is small; whether an existing delivery owner notifies a user is a separate accepted policy, not this module's authority.

History for the comparison is an explicit read input. R16 creates no current-state cache, acknowledgement ledger or per-user last-seen table. Existing curation, publication and delivery owners retain revision and delivery state. When a required historical slice is unavailable, do not reconstruct it from today's latest values and call it a system replay.

R13's actual Nutrien contrast remains a useful acceptance case: the historical-name resolver using newer master inputs resolved an earlier date, while the contemporaneously stored bridge did not. R16 does not rerun that discovery or change the identity owner. Any later discovery/return evaluation must use the intended information-set mode.

## 5. Private dossier, public brief and processor use

These boundaries are deliberately independent.

### Private dossier

The shared paid route must authenticate, enforce entitlement, obtain current source permissions and use the actual accepted private reader before composition. It must preserve the exact source/identity/definition generations and recheck the relevant permission at release. The private view can show fuller reviewed evidence and a verified company link within its allowed representation. A generic refusal must not expose hidden source existence to an unauthorized caller.

### Public or static AI Brief

The inspected brief builder loads shared static artifacts. It is therefore not the destination for full-fidelity private assertion bodies, private evidence URLs, user holdings, private search terms or per-user relevance information. A login-shaped user experience elsewhere does not make these outputs private.

The default Materials behavior is to omit the private payload from this path. An existing owner may later approve a minimal public summary with its own scope, attribution and source-date qualification. The public summary is a separately reviewed representation, not a string produced by deleting a few fields from a private object. It needs its own release tests against site output, raw JSON, URLs, caches and source maps.

### External LLM

Permission to display privately is not permission to send the same bytes to a processor. Public readability also does not settle processor use or redistribution. If the accepted provider/representation route is absent, use deterministic approved copy or omit that model contribution. Do not select another provider, obtain keys, enable an endpoint or send a trial payload from this research task.

The existing master-brain stance line remains sourced from its deterministic posture. A Materials opportunity may differ by region, business and horizon from the global stance; show that distinction rather than silently overturning the global decision. A global caution label should likewise not erase a genuinely improving subtheme explanation.

### Company and Prophet context

The Company Theme Exposure sidecar is a membership projection. It is not a place to insert inferred revenue percentages or economic rankings. Any later stock-page context uses accepted issuer/security identity and the approved shared research consumer. Unresolved NOVONIX/Wheaton routes and Canadian Nutrien remain unproved. This research does not fill them with plausible tickers or retry R13's denied query batch.

Existing Prophet outputs are preserved byte-for-byte in the eventual integration test.
