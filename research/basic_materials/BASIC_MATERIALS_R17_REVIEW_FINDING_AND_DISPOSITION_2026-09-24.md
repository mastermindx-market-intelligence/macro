## 4. Repair: qualify the claim before selecting its presentation

The existing helper is amended in place. The order is now:

1. Apply the existing shape, authority, permission and source-clock rules.
2. Reconcile the existing predecessor and no-output repeat cases.
3. Require the applicable comparison prerequisites: reported evidence and actual consensus reference for a declared consensus surprise; a compatible declared comparison; a baseline reference; and qualified time preceding the source.
4. Only then choose background, correction, target, hypothesis or current-observation presentation and emit its supplied text.

The repair creates no new source format, event store, review authority or native validator. It moves the already specified checks to the correct common boundary. Existing permission refusals retain precedence so an unauthorized caller does not receive details about a comparison. Exact repeats still emit no text. A factual noncomparative correction does not need a fabricated consensus just to be visible.

If a comparison is unsupported but an underlying fact is still useful, the product may use a separately reviewed noncomparative statement. It must not erase the tag and retain the same unsupported comparative language. The helper does not parse natural-language truth or authenticate source provenance. A falsely labelled sentence remains a source-review issue; the repair makes no broader guarantee.
