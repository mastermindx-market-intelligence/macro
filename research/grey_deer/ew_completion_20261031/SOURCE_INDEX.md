## Primary external research and technical law

| Primary source | Role in design | Caveat |
|---|---|---|
| [Gneiting and Raftery, *Strictly Proper Scoring Rules* (JASA 2007)](https://www.tandfonline.com/doi/abs/10.1198/016214506000001437) | Scoring proper probabilistic forecasts if one is ever qualified | Scoring rule is not proof this model is calibrated |
| [White, *A Reality Check for Data Snooping* (Econometrica 2000)](https://onlinelibrary.wiley.com/doi/10.1111/1468-0262.00152) | Multiple-testing and selection discipline | Does not prescribe the one valid test for this context |
| [Howard et al., *Time-uniform Chernoff bounds*](https://arxiv.org/html/1810.08240v9) | Anytime-valid inference alternatives for sequential observation | Assumptions and actual unit of analysis must be proven |
| [AWS Prescriptive Guidance — transactional outbox](https://docs.aws.amazon.com/prescriptive-guidance/latest/cloud-design-patterns/transactional-outbox.html) | Failure/duplicate-delivery pattern | Not a license to send without consent or to add a second outbox |
| [PostgreSQL transaction isolation](https://www.postgresql.org/docs/current/transaction-iso.html) | Concurrency reasoning for revoke/send admission | Schema, RLS and real race tests still required |
| [IETF RFC 5321](https://datatracker.ietf.org/doc/html/rfc5321) | SMTP accepted/attempted/delivered distinction | Mailbox arrival is not implied by provider acceptance |
| [W3C WCAG 2.2](https://www.w3.org/TR/WCAG22/) | Accessible status, readable semantics and keyboard path | Automated checks alone are incomplete |

## Minimal refresh protocol

1. Record audit time and the three repository pin changes, if any.
2. Pull #10219, #10221, #10104, #10079 exact-head SHA, CI, mergeability, review/owner changes.
3. Recompare public/durable source session and provenance; determine actual *served* response from the deployed path.
4. Check natural original daily run and failed push recovery without republishing partial/false freshness.
5. Revalidate consent/policy/outbox/drain through authorized live read-only observation before enabling effects.
6. Change only claims invalidated by new evidence. Maintain a dated amendment rather than overwriting the Oct31 evidence snapshot.

Never expose access tokens, inbox addresses, subscriber identities or proprietary source payloads in public review receipts. Credentials, policies, production sending and release switches remain under authorized operators.
