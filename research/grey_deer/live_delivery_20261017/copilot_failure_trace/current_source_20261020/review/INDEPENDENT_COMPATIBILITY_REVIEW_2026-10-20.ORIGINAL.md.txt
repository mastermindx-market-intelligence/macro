## Visual-content boundary

The new visual path does not invalidate the defect for a turn with no qualified visual. It does make a prose-only repair predicate unsafe as a universal response contract.

Current stream admission of `_public_visuals` at 12161–12163 requires the screen to remain clear and the turn not to be filtered, stubbed or retracted. Consequently, an empty-prose turn currently takes the stub path before those visual blocks are admitted, unless other nonempty text prevents the stub. This source inspection does not establish that standalone visual-only success is already an accepted product capability.

The root contract correctly preserves qualified visual content and leaves its existing acceptance with the current producer. During implementation, the explicit distinction should be:

- A useful substantive answer can be qualified prose, or a separately admitted visual response under the existing response contract.
- A raw `charts` list, an unvalidated visual object, a citation, an evidence caveat, or a suggestion block is insufficient by itself to establish success.
- A legitimate visual must still satisfy source binding and the advice, leak, filtering, retraction and Stop rules. An empty-prose correction must not expose a visual that those rules withheld.
- Preserve the accepted handling of genuine supported prose with a visual and any separately validated standalone visual response. Do not use this defect repair to invent visual-only policy.

This is a concrete implementation and verification refinement, not a blocking defect in the reviewed note. The note already makes the necessary distinction between useful answer content and metadata and explicitly requires valid visual cases to retain their semantics.

## Minimal acceptance contract

The proposed sequence is appropriately bounded: repair the existing producer, demonstrate the actual changed paths with deterministic fixtures, qualify its served source, then obtain one useful authenticated answer to the original question. It does not require a provider replay to establish the source defect.

The decisive fixture outcomes should remain behavior-based in both public entry points: blank or whitespace synthesis without an issued repair cannot become caveat-only success; suggestion-only output cannot become success after splitting; supported prose remains intact; genuine issued-repair failure retains its truthful wording; and refused, screened or stopped output retains the existing authority. Persistence and response logging must retain the distinction between failed synthesis and a useful answer. A new flag is useful only if the public display and persistence semantics consume it consistently.

For the visual boundary, distinguish at least a qualified visual with useful prose, any explicitly accepted standalone visual case, and an invalid or withheld visual with empty prose. Existing tests may supply these controls where their exact source and scope remain applicable. No new generic test campaign or provider spend is implied.

The intent and contradiction repairs remain separate concerns. Preserve affirmative private-portfolio questions that also forbid allocation instructions. Do not infer positive private-portfolio intent from an exclusion alone. Retain genuine conflicts while binding them to the actual evidence family or labeling them unscoped. None of these changes confers numerical allocation or execution authority.
