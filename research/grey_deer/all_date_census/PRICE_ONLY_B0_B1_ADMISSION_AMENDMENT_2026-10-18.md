## 4. Smallest estimator specification proposed for a later executable freeze

Use the immutable `v1/origins.csv.gz` artifact as the estimation input after purpose admission; do not reopen the provider price files or regenerate census labels/features. Its executed `write_csv_gz` uses `float_format="%.8g"`: numeric values are rounded to **eight significant digits, not eight decimal places**. Parse them as float64 decimal fractions. A value representing a 5% return is 0.05, not 5; drawdowns and SMA gaps use the same ratio-minus-one convention. Preserve nullable Boolean fields separately; empty is not false. The proposed model is therefore bound to these saved artifact values, not claimed to reproduce full-precision source-price estimation.

| Order | Estimator field | Exact saved input / proposed calculation | Required support |
|---|---|---|---|
| 1 | Five-session return | `obs_tr_return_5` | Executed `strict_return` requires six consecutive valid total-return closes through the origin. |
| 2 | 20-session return | `obs_tr_return_20` | Executed `strict_return` requires 21 consecutive valid total-return closes through the origin. |
| 3 | 63-session drawdown | `obs_price_dd_63` | Current price divided by the maximum of 63 complete trailing price closes, minus one. |
| 4 | 20-session annualized log volatility | `sqrt(252) * sample_sd(L_s, ddof=1)`, where `L_s = log1p(obs_tr_return_1[s])` for `s = t-19, ..., t` | Exactly 20 consecutive saved one-session returns on the unchanged reference lattice; every value finite and greater than -1. |
| 5 | SMA200 gap | `obs_price_sma_gap_200` | Current price divided by the mean of 200 complete trailing price closes, minus one. |

Volatility is the only newly derived feature in this amendment and has **not been computed**. Its first return at index `t-19` encodes the move from `t-20` to `t-19`; the complete window therefore covers 21 underlying total-return closes. The frozen source's one-session `strict_return` emits a value only when both adjacent closes are valid. Compute the rolling window on each exposure's full ordered reference lattice before filtering scoring/training rows. Do not skip null rows or compress across gaps, years or sample boundaries. Use the 20 log returns' arithmetic mean and squared-deviation sum divided by 19; multiply the resulting standard deviation by `sqrt(252)`. A missing/non-finite return, incomplete window or nonpositive saved gross return makes this feature unavailable with an explicit reason. This is a derivation from rounded saved returns, not exact full-precision source volatility; no precision restoration or substitution is implied.

An eligible feature row requires `origin_status == "OBSERVED"` and all five finite features. Returns/volatility use total-return basis; drawdown/SMA gap use price basis. Keep those bases separate. No imputation, winsorization, interaction, sign search, exposure dummy or discretionary feature subset is included.

For year `y`, let `T[e,y]` be exposure `e`'s common eligible training rows and `n[e,y]` their count. **B0** is the empirical positive fraction on exactly `T[e,y]`. A count of zero refuses that exposure-year B0 estimate. A positive count with no positive events gives probability zero; all-positive training gives probability one. Neither case is silently discarded or smoothed. Small counts are disclosed, not converted to independent sample sizes or treated as evidence of calibration.

The additional **pooled B0** is `p_pool[y] = mean_e(p_B0[e,y])` over exactly the `m[y]` exposures with nonempty `T[e,y]`. It is a deterministic equal-exposure pooled frequency, with no smoothing, tuning or optimized parameter. Its estimation unit is nevertheless counted. Apply that same scalar to the supported outer rows for the year. If there are no supported training exposures, refuse the pooled estimate. To keep the comparison population identical, an exposure with no supported exposure-B0 estimate has no three-model scored prediction; do not silently treat pooled extrapolation as a successful paired comparison.

For **B1**, pool all exposures with nonempty `T[e,y]`. With `m[y]` supported exposures, each row of exposure `e` has training weight `w = 1 / (m[y] * n[e,y])`; total training weight is one. Estimate every feature's weighted mean and weighted population variance on these training rows only, then apply the frozen transform to test rows. A zero-variance training column retains its slot with scale one; it does not trigger feature selection. Test data cannot influence centering, scaling, eligibility thresholds or penalty selection.

The proposed fixed objective is weighted mean logistic loss plus ridge penalty:

`sum_i w_i * [log(1 + exp(eta_i)) - y_i * eta_i] + (1/2) * sum_j beta_j^2`, with `eta_i = intercept + z_i · beta`.

This defines **lambda = 1**, loss normalized to total weight one, and an unpenalized intercept. It does not mean a library's unspecified default `C=1`. There is one pooled coefficient vector per year. The pooled training set must contain both outcome classes; otherwise the unpenalized-intercept fit refuses. This is a mathematical existence condition, not an invented minimum crisis-count gate.

Use one deterministic float64 optimizer implementation, fixed starting values, convergence tolerance and iteration limit, all pinned with the executable source and runtime versions before the first fit. No existing baseline runtime/runner has yet been supplied or accepted. Non-convergence or non-finite coefficients/probabilities produce an explicit failed attempt; no alternative solver, penalty, feature removal or hidden retry enters this slice. Mathematical specification alone is not executable source acceptance.

The exposure-specific B0 and pooled B1 remain **non-nested**; their difference can reflect pooling and the features together. The now-explicit pooled-B0 control holds the pooled population and equal-exposure weighting fixed, allowing the additional feature specification to be assessed separately. Report B1 against both baselines on identical scored rows. Superiority over the pooled constant alone can reflect cross-exposure differences as well as changing risk through time; it does not establish within-exposure turning-point timing, causal information or a useful warning policy.
