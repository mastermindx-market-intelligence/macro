## One primary incremental comparison

Compare a fixed baseline with the same baseline plus implied VVIX MA slope.
The baseline contains VIX level/direction and the frozen cohort controls; the
augmented model adds one continuous implied VVIX slope term. Both signs are
eligible; no one-sided “fear is bullish” premise is encoded.

Use the incumbent low-capacity modeling and chronological validation seam.
Before execution, the owning programme must record the exact baseline variables,
transformations, regularization setting, fold boundaries and primary score in
its existing registry. Do not select them by SCREEN-label results, sweep multiple
penalties or run alternate formulations until a favorable one appears.

The intended primary assessment is the change in an out-of-fold proper predictive
score at equal date weight, with the same eligible entries in both models.
Each market date is the common information unit; thousands of stock events on
one date do not constitute independent market-state observations. Native
time/episode blocking and the 63-session outcome overlap must govern inference
and any training/validation purge. An insufficient fold count or power estimate
is a stop result, not a reason to relax the native floors.

This document deliberately does not claim that a proposed score/model is now
registered: the currently active programme and trial budget must be reconciled
before completing that registration. If an existing view-2/VOL comparison already
owns the same question, amend or consume that original carrier rather than
creating a duplicate experiment.
