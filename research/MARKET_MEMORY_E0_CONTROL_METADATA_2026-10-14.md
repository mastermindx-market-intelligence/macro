# E0 control metadata grammar and identity joins

Program #6528, original root 01a1333c-a475-7052-95a8-72c623fb12e1. This is an outcome-blind, pure metadata boundary in Research Factory. It implements the five control envelopes from the reviewed L0 Packet B architecture; it does not install a study, publish an owner record or issue a label-reading capability.

The closed schemas cover registration, independent prelabel closure, publication, installed binding and current access state. The registration preserves the original 109-member corpus and the complete 256-bit allocation seed. Refs bind complete canonical bytes with schema, object ID, digest and length. Installation epochs are bounded opaque owner-issued IDs. Access sequence counters are exact integers with an explicit predecessor rule, and budgets reject overcommitment. Clock strings are real round-tripped microsecond UTC times; identifier/path confusion, duplicate JSON keys, non-finite values, non-exact Python types, oversized/deep trees and noncanonical byte representations are rejected.

The pure join verifies repeated study/owner/namespace/installation/access identities, exact registration/closure/publication references and chronological/expiry ordering. Its result always states `operational_admission: false`. An unfavorable access state remains inspectable metadata and cannot authorize use. Syntactically valid fake owner records deliberately pass only this consistency check; the tests pin their lack of admission. No owner identity, independence declaration, exposure history or domain manifest becomes authentic by appearing in a JSON object.

Operational Packet B remains open. It must resolve and fully validate the original task/coverage/interval/split/method/allocation/reviewer/metric manifests, authenticate publication and installation against the current real owner, establish independent prelabel closure and original exposure state, and enforce current access history plus exact durable reservations. The future owner adapter must apply those checks before private reads and again before label use/disclosure. This module has no private-store reader, publisher, label callback or placeholder capability API, so it cannot silently grant an incomplete registration.

Research Factory's existing authority job runs these checks with its existing state/schema/Market Memory/code-generation suites. Existing W2A/W6A proposed-only contracts, historical ABSTAINED objects and immutable N2 trial records are unchanged. A future operational E0 registration must bind the entire new runtime closure rather than restamp an earlier trial.

All test control records are synthetic. No actual subsequent price/outcome labels, ratings or scores were accessed. Exact validation results and original source custody are retained in the program evidence directory under science/l0/reconcile-01a1383c/source-packet-1.
