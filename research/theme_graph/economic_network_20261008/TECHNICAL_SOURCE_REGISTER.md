## Version and access controls

Preserve canonical URL, retrieved date, inspected version and locator. A working paper, publisher abstract, current documentation page and native code at an immutable commit have different evidential scope. Do not silently upgrade abstract-only inspection into a full-method review.

An old Micron prepared-remarks link redirected to the current investor overview. Its search snippet is excluded as proof of a numerical wafer-intensity claim. Direct FASB and some current HKEX rule content remained unavailable. Final Barrot–Sauvagnat numerical estimates and Baqaee–Farhi calibration magnitudes remain held under the version/erratum limitations in the economic report.

The package's proposed models and store choices are reasoned design judgments informed by these sources. No new public-source ingestion benchmark, graph-database benchmark, model fitting or return backtest was performed.
