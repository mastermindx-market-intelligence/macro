## Executable evidence

From this directory:

~~~bash
python witnesses/temporal_compatibility.py
python witnesses/composition_invariants.py
~~~

Both passed in the research environment. These results are helper/logic evidence; no economic forecasting model was fitted or validated.

The bundled source snapshots are the exact inputs needed for reproducibility. Their native ownership and immutable source versions remain unchanged. ThemeState and held K3-D are source-traced by the temporal witness, not executed.
