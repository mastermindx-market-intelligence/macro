## 5. R3 — one narrow remaining P2: signed additive action domain

**Location:** S1 line 357, `/capitalization/numeric_rule`, versus line 397, `/capitalization/assertion_resolution/component_keys/CORPORATE_ACTION_DELTA`, and `/share_count/bridge`. S2 §6.1 expressly describes signed corporate-action effects.

The generic rule currently says to parse finite **positive** decimal inputs. That is correct for price, FX, denomination scales and multiplicative conversion/split ratios used in a positive capitalization product. It is not the domain of a signed additive retirement, cancellation or treasury-share change. An implementation following the generic rule literally would refuse valid negative deltas; erasing the sign would be economically wrong.

**Synthetic counterexample:** 100 million shares plus a disclosed retirement of −10 million shares, at price20, gives a reference value of USD1.8 billion. Substituting the absolute delta gives USD2.2 billion and crosses the unchanged absolute USD2 billion boundary. This is an artificial arithmetic example, not a discovered issuer or actual cap error. The independent check reproduces both exact rational results.

**Minimal correction before numeric-schema freeze:** distinguish numeric roles explicitly:

- Prices, FX, quote-unit scales and multiplicative ratios/factors used in the cap product must be finite and strictly positive.
- Additive corporate-action changes must be finite signed values in source-proved class/share units, with economic event identity and effective order. Negative is a meaningful reduction. A zero delta may be retained only as an explicitly evidenced no-change value; it cannot stand for missing evidence.
- Resulting shares for an included positive-valued class and the computed issuer capitalization must satisfy the adopted positive-value rule. An invalid result must hold the value, never use absolute values, clipping, omission or imputation to pass it. Evidence about a zero class or ceased class, if supported, must remain a typed fact rather than silently becoming a missing numerical factor.
- Do not allow a negative price, FX rate or ratio by generalizing the action exception to every numeric field. Nonfinite values and booleans remain invalid.

No quota, jurisdiction, activity definition, date, seed, band or economic measure needs to change. This can be an exact separately hashed principal clarification with an implementation regression, or a new policy version. A later source verdict must cite that clarified composite contract; this review does not silently rewrite S1 or label the unclarified numeric contract fully passed.
