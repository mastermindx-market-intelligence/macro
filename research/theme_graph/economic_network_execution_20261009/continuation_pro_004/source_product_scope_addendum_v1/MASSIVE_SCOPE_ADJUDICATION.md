## Practical correction to the sourcing route

The accepted grant should remove unnecessary global entitlement friction for an actually matching Massive dataset. It should not motivate an API call to a product whose documented coverage cannot satisfy the target population. For Canada, retain the bounded TSX/TSXV master-pair route and separate CSE/Cboe assessment already researched; an established suitable global product could replace those routes. For Japan, retain the explicit national venue perimeter rather than an ETF or ADR population. These are coverage choices, not new acquisition or purchase approvals.

For any candidate historical-reference source, the next useful source-owner return is concrete: product and operative permitted-use binding, exact population definition at D, original and correcting version identifiers, defensible public-availability upper bounds by K, actual acquisition F, permitted retained bytes, and source-backed totals/event closure. An all-true approval object, a successful request, a list of tickers or a digest cannot stand in for those witnesses. The structural kernel remains outside this admission decision.

The adopted D is 2026-09-30 and K is 2026-10-09T00:00:00Z. Today's documentation retrieval is later research evidence about a potential source route. It is not a retrospectively manufactured source receipt at K. Actual F for the diagnostic cohort remains null, and the real 120-issuer cohort and all 42 real pool denominators remain unestablished.

## Scope and falsifiers

A source-owner return showing a suitable already licensed Canadian/Japanese product, its actual D files and K-version evidence would change the route assessment. A roadmap item alone would not prove possession, completeness or permitted use. Conversely, an empty query, sparse index list or failed website retrieval would not prove an empty eligible population or absence of a private contract.

The existing census is bounded to 35 pinned repository files at its stated HEAD. It is not an organization-wide account or contract search. No private contract, provider account, credential, runtime store, paid order or external message was accessed or changed. Public webpage representations were read through the research tool; raw HTTP payload hashes and publisher authenticity beyond the observed official source attribution are not claimed. The source register preserves that representation distinction.
