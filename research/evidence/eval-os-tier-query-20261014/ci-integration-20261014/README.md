# CI integration evidence

The manifest binds every retained record to its original bytes and the qualified source revision. Failed JUnit reports contain significant raw traceback formatting, including trailing whitespace. They are stored as lossless `.xml.gz` archives; the manifest records both archive and decoded original hashes. No failure text, test result or original evidence bytes were normalized or discarded. Other XML/JSON records remain directly readable.

Start with `followon-scope-final-adjudication.json`, then `followon-final-scope-validation.json` and `qledger-ci-command-validation.json`. These qualify local source only. Hosted CI, protected merge, installed/served behavior and real adoption remain separate gates.
