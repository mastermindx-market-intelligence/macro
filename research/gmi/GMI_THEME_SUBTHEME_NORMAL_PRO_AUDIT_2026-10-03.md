**Date:** 2026-10-03. **Carrier:** [Macro PR #8324](https://github.com/mastermindx-market-intelligence/macro/pull/8324). **Mode:** standard Pro source and primary-literature review; no new Deep Research run.

## Verdict

**The latest uploaded revision is directionally useful, but was not robust enough to serve as the unmodified end-to-end execution contract.** It correctly favors existing owners, a single thematic state authority, explicit local/canonical semantics and evidence-gated decision use. It also corrects some stale PR assumptions. However, it understates unfinished original GMI scope, misses concrete source defects and consumer incompatibilities, and supplies neither a portable bibliography nor complete experiment designs.

This audit replaces that execution contract with the [full audited Master Plan v3](../../docs/superpowers/plans/2026-10-03-gmi-theme-subtheme-end-to-end-completion.md), supported by the detailed evidence below. The original upload and prior repository blueprint remain historical inputs. The [Astra CEO handoff](ASTRA_CEO_GMI_HANDOFF_2026-10-03.md) commissions implementation after source/custody recovery; it is not a claim that a worker has picked up the project.

The principal architectural ruling is to **repair and complete the existing system**. There is no evidence-based reason to replace the graph, PIT owner, state lineage, Company Theme Exposure publisher, Terminal context interface, or Evaluation owner. There is substantial evidence that their current boundaries need repair and their integration acceptance needs to be more exact.

### Evidence levels used consistently

- **Contract/source present:** a file or implementation exists at the named revision.
- **Controlled behavior reproduced:** an isolated call demonstrates a particular source path with stated fixtures/mocks.
- **Committed artifact present:** inspected JSON or producer metadata demonstrates a recorded output; metadata-reported Parquet counts remain producer assertions.
- **Historical acceptance receipt:** retain a previous accepted run in its original scope; do not erase it because this audit did not rerun it.
- **Current natural production proof:** requires an ordinary source event, accepted owner run, publication and actual consumers. This audit does not claim that proof.
- **Predictive/decision usefulness:** requires its own prospective, use-specific evidence. None is established by compilation, merging or a useful dashboard.

## 3. Findings that change the execution order

### A01 — High: authoritative history can be replaced after an unreadable prior-state read

The graph append writer calls a permissive reader that turns an existing unreadable Parquet into an empty frame. The incumbent PIT append path has equivalent behavior. In a controlled probe, an injected decoder exception reached the replacement writer with only the new row and reported success; the strict graph reader refused the same exception. This is a demonstrated integrity hazard, **not an observed corruption incident**. [Graph read/write](https://github.com/mastermindx-market-intelligence/macro/blob/bebcb24db8707f93c3acca470590fead13e78dbd/engine/theme_graph/store.py#L211-L230), [append path](https://github.com/mastermindx-market-intelligence/macro/blob/bebcb24db8707f93c3acca470590fead13e78dbd/engine/theme_graph/store.py#L358-L379), [PIT append](https://github.com/mastermindx-market-intelligence/macro/blob/bebcb24db8707f93c3acca470590fead13e78dbd/engine/basket_membership_pit.py#L465-L489).

**Required response:** Packet B strictly validates existing ledgers before any replacement/publication, distinguishes first creation from unreadable state, preserves prior bytes/metadata on refusal, and reuses the existing owners. A strict consumer alone does not protect a permissive writer.

### A02 — High: owner and graph disagree on two negative-membership cases

The THS graph interval adapter loses a certified empty collection because it sees only positive member rows. A second complete document with basket A empty causes the owner to return no active members while the graph leaves the former member open. Separately, a retained historical row explicitly removed before the snapshot is excluded by the owner but minted as an open graph interval. [Owner active rule](https://github.com/mastermindx-market-intelligence/macro/blob/bebcb24db8707f93c3acca470590fead13e78dbd/engine/basket_membership_pit.py#L616-L627), [graph interval transform](https://github.com/mastermindx-market-intelligence/macro/blob/bebcb24db8707f93c3acca470590fead13e78dbd/engine/theme_graph/local_sources.py#L343-L402).

**Required response:** extend the incumbent collection receipt with scope, completeness and observed-empty/retired outcomes; consume active-at-observation semantics and separate clocks. Complete-empty must close the intended interval; partial, failed or uncollected inputs must not manufacture removals. Mapping withdrawal/destination change is a separate ontology-lifecycle gate, not covered merely by member-removal tests.

The publication-boundary site refresh preserves this shape and null result. [Narrative reader](https://github.com/mastermindx-market-intelligence/macro/blob/bebcb24db8707f93c3acca470590fead13e78dbd/engine/neuralweb/thematic_state.py#L229-L251), [membership lookup](https://github.com/mastermindx-market-intelligence/macro/blob/bebcb24db8707f93c3acca470590fead13e78dbd/engine/neuralweb/thematic_state.py#L502-L514).

Broadening parsing until a value appears would not establish correct meaning.

### A09 — High research gap: the proposed intelligence is not operationally or statistically specified

The report's portable evidence, outcome definitions, strong baselines, temporal dependencies, trial accounting, practical improvement margins, power and stop rules are insufficient for an executable research claim. Its prioritized transitions/disagreements are hypotheses, not established higher-value signals. Price acceleration, persistence, breadth and several news/options observations can share data or event ancestry; they are not independent votes. See findings R01–R17 in the [scientific review](GMI_RESEARCH_AND_EVALUATION_AUDIT_V3_2026-10-03.md#findings-that-should-change-the-master-plan).

**Required response:** distinguish descriptive measurement from prediction, development capture from untouched confirmation, and product acceptance from per-use authority. The plan supplies five explicit experiments and requires the Evaluation owner to seal actual numeric margins/power from the consumer baseline before confirmation. Those values are not falsely presented as already preregistered.

### A10 — High measurement gap: economic exposure and child leadership need sharper definitions

Membership, vendor relevance, disclosed revenue, profit sensitivity, capex, supplier dependence and hypothetical role are different quantities. They need units, periods, denominators, uncertainty and scenario-conditioned direction. Flat prices do not prove economic information is unrecognized. Child strength can mechanically precede a diluted whole-parent threshold; test the future **parent portfolio excluding child constituents**, with normalized frozen starting weights, against child momentum and matched random child controls. This is not parent return minus child return. HHI is weight concentration, not independent sample size. [Measurement contract](GMI_RESEARCH_AND_EVALUATION_AUDIT_V3_2026-10-03.md#measurement-contract-that-should-precede-predictive-evaluation).

### A11 — Confirmed scientific erratum: common shrinkage preserves Spearman ranks

The incumbent W2 record is substantial prior work, not empty research territory. Retain its economic-share null, ex-self beta construction, reconstructed-membership limitation, refused attention proxies and historical adjudication. Its explanation that common beta shrinkage inflates rank stability is mathematically wrong: b' = 0.66 b + 0.34 mean(b) is a strictly increasing affine transform within a cross-section. It preserves ranks/ties, hence the same Spearman statistics on the same observations. The pinned function diagnostic returned raw and shrunk Spearman **0.9746794344808963**. Dispersion does shrink. [Pinned implementation](https://github.com/mastermindx-market-intelligence/macro/blob/bebcb24db8707f93c3acca470590fead13e78dbd/scripts/probe_theme_exposure_axes.py#L177-L205), [full errata](GMI_RESEARCH_AND_EVALUATION_AUDIT_V3_2026-10-03.md#corrections-to-w2s-interpretation).

**Required response:** append an erratum while preserving preregistration and results. Also correct full-sample attention-universe lookahead even in short panels; do not use expected famous-name rankings, beta medians or future calendar dates as evidence of readiness.

## 4. Claims deliberately not accepted

The audit rejected overstatements in both directions. D2D readers really exist and their dual-clock/unmapped/proposal-separation behavior passed isolated checks. The old daily phase history really does implement first-write-per-day behavior, but never promised a full intraday feature archive. A reversed-looking DAG array is not proof of runtime execution order without tracing its executor. An October graph build with June/August structure inputs is not proof that a collector failed. A merged publisher can retain historical accepted proof without establishing present freshness or a different dossier product. An open research compiler with all decision flags false is not a deployed trading engine.

These distinctions matter: overstating an audit finding can produce as much wasted work as understating it. The plan therefore repairs demonstrated seams, explicitly resolves remaining acceptance questions, and preserves accepted behavior under DO_NOT_REDO.
