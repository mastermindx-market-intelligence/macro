## 7. Candidate attribution-control ablation — superseded as a frozen shape by W1

The learned comparison must prevent redundant linear reparameterization from masquerading as structural skill. The 30/36/36 design below remains a useful **candidate ablation for the six-point necessary-outline atom**, but it is no longer a frozen full-method shape: W1's later controlling ruling requires a preregistered grammar, multiple-parse/abstain-under-ambiguity semantics, and equal-budget generic swing geometry. The final admitted design must restate the exact feature budget after that method is bound.

### 7.1 Common 30-column block

All primary learned models receive the same 30 common columns and identical preprocessing:

- 7 ordinary price, volatility, and drawdown context values;
- 5 normalized signed turn legs;
- 5 log leg durations;
- 5 log known confirmation delays;
- 1 running-extreme age;
- 1 current distance from the running extreme;
- 4 redundant linear structural margins, shared by every primary model;
- 2 source availability/kind masks.

For selected prices `p0 … p5` and frozen origin scale `a0`, the four shared margins are, in fixed order, `(p2-p0)/a0`, `(p3-p1)/a0`, `(p4-p1)/a0`, and `(p5-p3)/a0`. They are linear combinations of the signed legs. They are common precisely so their presence cannot change the challenger's effective L2 penalty and then be miscredited as Elliott information.

### 7.2 Necessary-outline 36-column diagnostic challenger

This diagnostic challenger adds exactly six columns to the common block, in this proposed semantic order:

1. `wave2_above_origin = 1[p2 > p0]`;
2. `wave3_above_wave1 = 1[p3 > p1]`;
3. `wave4_above_wave1 = 1[p4 > p1]`;
4. `current_above_wave3 = 1[p5 > p3]`;
5. the conjunction of those four flags;
6. `((p3-p2) - min(p1-p0, p5-p4)) / a0`, the third advancing leg minus the minimum of the other advancing legs, normalized by the frozen origin scale.

The alternating-kind fact is not added again if it is already implied by the common source-kind mask. Strict/weak comparison semantics above are part of this diagnostic proposal. They do not satisfy W1's full grammar/parse contract by themselves. Any change before admission must create a new reviewed version rather than an outcome-contingent reinterpretation.

### 7.3 Generic nonlinear 36-column comparator

An equal-column-budget generic nonlinear control adds exactly six non-Elliott columns to the same common block:

- the square of each of the five normalized signed legs;
- `leg1 × leg3`.

Equal column count does not prove equal effective complexity or exhaust all nonlinear nulls. It is a declared attribution control, not a post-result search axis.

### 7.4 Equal treatment

Any retained 30/36/36 diagnostic ablation must use bit-identical common preprocessing, the same mature training origins, the same label availability rule, the same model family, and the same declared tuning budget. An unavailable structural outline copies the registered baseline probability object exactly on that origin. Invalid common data is a data failure, not a challenger abstention.

The final W1-aligned grammar comparison may have a different declared feature count, but it must preserve equal-information origins, a generic causal swing-geometry comparator under the same effective feature/tuning budget, explicit parse-marginal or abstention semantics, and a trial-ledger entry for every declared ablation. A six-column outline win may only support the narrowed claim that this necessary-outline representation helped; it cannot be relabeled as full Elliott skill.

A gain reproduced by the generic nonlinear control, redundant margins, a different penalty geometry, different convergence, or different row selection is a representation/optimization effect. It is not evidence that economic wave phase was predicted.
