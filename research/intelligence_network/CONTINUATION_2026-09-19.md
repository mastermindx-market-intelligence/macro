## Changes that cannot be interpreted as demand without more work

At the feed cutoff, the comparison of Sep 16 and Sep 17 contains 255 ticker groups with comparable increasing counters, 486 unchanged groups, 51 groups with at least one declining app counter and 3 groups whose app cohort changed. At the later cutoff: 110 comparable increases, 669 unchanged, 14 counter-decrease groups, one changed cohort and one prior-only group.

A falling cumulative counter may reflect removals, corrections or measurement changes; it is not evidence that demand fell by the same amount. An absent app is unknown coverage, not zero demand. A per-issuer sum can conceal one app's decrease behind another's increase. The diagnostic preserves these distinctions and exports only aggregate state counts.

No duplicate retained snapshot key, conflicting retained value, missing provider label or invalid numeric value was found in these frozen inputs. ## Weighting, graph and neural-model design retained

Keep source reliability, factual confidence, economic materiality, novelty, dependence and predictive uncertainty distinct. A highly reliable observation may be immaterial; a material event may already be expected. A second description of the same event is not a second independent vote.

Use three views over canonical identity: business relationships (what is connected economically), evidence provenance (why a claim is supported/contradicted/superseded), and statistical dependence (which features overlap). The last is a model artifact, not a factual causal graph. Evidence links must remain traversable to source versions and availability clocks.

The first predictive challenger should be a regularized business-outcome model with horizon-specific features and partial pooling across thin groups. Compare it against the incumbent baseline using chronological holdouts, event/date clustering, matched counterfactuals where appropriate and a recorded trial inventory. Report predictive calibration and incremental utility, not feature-importance charts as proof.

Graph-aware retrieval can improve grounded synthesis before a graph predictor earns admission. Temporal neural and heterogeneous-graph models remain challengers: test a model with eligible edges against the same model without messages, on the same untouched temporal split. Attention weights are not evidence of economic causality. LLM extraction must return cited spans and typed unknowns; its summary cannot return as an independent source or an unvalidated ranking input.
