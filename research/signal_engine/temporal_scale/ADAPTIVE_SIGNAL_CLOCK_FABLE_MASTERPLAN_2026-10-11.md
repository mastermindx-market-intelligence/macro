## 7. Scientific core and non-negotiable controls

The hypothesis is that ex-ante structural information supports a useful scale band, not that every instrument has one true optimum. The adversarial null is no meaningful incremental benefit after A/K/D matching, equal information, coverage, signal-frequency and turnover controls.

For a linear recursion, retention r=1−alpha and half-life in equally spaced observations is ln(0.5)/ln(r). EMA and RMA have different alpha conventions. The existing continuous EMA uses exp(−delta_clock/tau); tau is an e-folding constant, not the half-life. Actual uneven sessions/activity increments matter. A single EMA mapping does NOT establish equal memory for nonlinear RSI/RSI-MACD/StochRSI stacks. Reuse full-stack signatures, deterministic perturbation/warmup and prefix/truncation tests.

Whitelist only owner-qualified past structural measurements: signed-return dependence, variance-ratio profiles, identified residual persistence, trend/volatility persistence, available activity durations, causally confirmed swings and issued regime state age. Preserve units, caps/non-identification, source versions and known-at time. Capped half-life, future-confirmed pivots, retrospectively smoothed regimes, full-sample spectral peaks and outcome-winner labels cannot route a current clock.

Prefer a band, supported modes or abstention. STABLE_BAND, MULTISCALE, UNSTABLE and UNRESOLVED are distinct; separated modes cannot be averaged into an unsupported center. Compression/expansion is not directional confidence. The first adaptive candidate should be an interpretable compatibility/memory family with fixed sampling unless a separately declared sampling intervention is justified.

Required comparison family: B0 global fixed; B1 incumbent; B2 asset-class fixed; B3 simple causal regime-fixed; **B4 fixed equal-weight multiscale**; **B5 same-covariate multiresolution no-selector**; B6 fixed consensus; B7 matched fixed kernel; B8 session-aware fixed bars; B9 adaptive memory/fixed sampling; B10 adaptive sampling/frozen memory policy; B11 abstain; B12 only preregistered shrinkage/activity controls.
