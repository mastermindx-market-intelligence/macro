# Official Army source in the public-capacity contract

The existing published D5 schemas 1.0.0 and 1.1.0 retain their exact publisher allowlist. The new, unreleased public-capacity schema 1.2.0 and its oversight-compatible 1.3.0 successor explicitly admit one additional source form: official_contract_announcement from an exact HTTPS www.army.mil URL, with no credentials, port, surrounding whitespace, alternate host or redirect alias. source_url and retrieved_from_url must match exactly. Nonempty claim scopes are limited to program_identity and public_capacity. The global legacy allowlist, issuer pin policy, NATO policy exception and all evidence/clock/capacity validation remain unchanged.

This supports the already-retained official Army publication at https://www.army.mil/article/291670, raw SHA256 17cc11b30b0aa388018eecbf090fc0e54d9d9cf444a500b93eef055de29318a2. Its completed retrieval is October14; neither publication date nor an earlier action date is used as known_at. Source-semantic review is separately retained. The amendment establishes publisher eligibility only, not acceptance of any particular claim, issuer role, workshare, financial forecast or operational-readiness inference.

The raw URL must also contain no ASCII controls, spaces or DEL. Python's URL parser removes embedded tabs and newlines before interpreting the hostname; testing only its normalized host would admit a different literal URL. Five adversarial cases exposed that defect in the preparation branch, and the raw-character guard closes it without changing any legacy publisher policy.

This is host-level eligibility, not an article-path allowlist: a non-article path on the same exact origin can qualify, subject to all evidence and claim review. Uppercase scheme or host, trailing-dot host and explicit port 443 are refused by the literal form. Source eligibility never establishes the contents of another page.

Schema 1.3.0 is the existing additive oversight preparation contract. Its accepted version and exact top-level key set include both public_capacity_assertions and public_oversight_assertions. allowed_claim_scopes, coverage_scopes_for and current_public_capacity_rows preserve 1.2.0 capacity semantics under 1.3.0; the evidence and capacity validators still run. The Army amendment does not introduce or alter that coupling. The independent Army review received only the narrow gate excerpt and an older 1.2.0 baseline, so its inability to verify the wider coupling is retained as a review limitation, not an assertion that current 1.3.0 wiring is missing.

The October14 PAC-3 worksheet first refused the old host contract against an unchanged copied canonical graph. That refusal is retained. The assigned programme principal makes this bounded contract amendment under the existing end-to-end commission; the ordinary source and independent code-review gates still apply. No production source access, canonical input write, new acquisition or excluded programme change follows merely from this amendment. Actual original capacity-code review remains on its existing unsettled carrier.
