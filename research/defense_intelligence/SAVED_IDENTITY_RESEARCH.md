# Saved international identity research

P16.T2.S1 implements the original P2/A38 international save → reload → reopen →
JSON/CSV export journey on the existing Government Revenue briefcase. It uses
only the selected source-identity row already loaded by the current atlas.
It performs no new fetch, authentication, publication or alert activation.

The `government_revenue_saved_identity.v1` variant is stored inside the existing
`government_procurement_local_state.v1` saved view under its existing authenticated
owner-scoped localStorage key. It is a device copy, not account sync or server
recovery. Existing event-cut and legacy filter-only formats remain compatible.
An identity snapshot is not an alertable procurement event. An alerted event view
cannot be overwritten with an identity snapshot; save a separate view instead.

The retained cut binds the selected subject, exact filters, public atlas content
ID, issuer/listing/ownership context, source evidence references and separate
observation, research-identity, combined context, source-build and device-copy
clocks. Native fractional clock precision survives. Summary knowledge clocks
must agree with the retained source cases. A later build of identical evidence
does not recertify or backdate the source knowledge.

BAE remains a source-identity context. The ordinary-share and ADR observations,
ratio, quote currency, CIK/ISIN and current-research qualification retain their
source meanings. They do not establish award coverage, reviewed recipient
attribution, global listing admission, price comparability or economic capture.
Unknown rights remain unknown; denied cases cannot be saved. No investment,
ranking, sizing, candidate or execution authority is created.

Capture uses a closed public-field projection. Internal mapping paths, raw bodies,
private annotations and credentials are excluded. Source URLs reject userinfo and
sensitive decoded query keys. The existing 256 KiB limit and bounded case/receipt
limits apply before mutation; invalid or oversized replacements preserve the prior
saved record. Stored malformed cuts are retained but refused, never repaired by
substituting current data. Local copies are not cryptographically signed claims.

Reopen restores the original selection/generation constraint before current-page
filtering. The saved drawer shows the original snapshot even if the current atlas
has changed, lost the subject or become unavailable. The current page separately
reports its pinned-source availability. JSON and CSV export the same retained
cut, including its original clocks and limitations; they never use today's
WORKSPACE or silently replace the selected subject. CSV uses the existing formula
neutralization. Owner switch/sign-out clears presentation and makes prior download
closures ineffective. Capture rechecks the owner before committing.

The implementation reuses the existing drawer/components and adds no stylesheet,
material system, navigation family or source acquisition. The atlas getter is
read-only over the already loaded generation. The first dossier factory, including
its per-call authentication and held c287 work, remains unchanged.

Qualification uses the real retained BAE atlas fixture with the actual atlas,
page, briefcase and export modules in the existing offline DOM harness, plus
negative corruption, owner-switch, encoded-secret, generation and alert-conversion
cases. These checks are not authenticated browser or two-tenant production
acceptance. The exact Chrome refusal and original A42 requirements remain open.

The original artifact-only `defense-p2-saved-workflow-o6-01a13300` operation remains
UNKNOWN, unresolved and unused. This candidate is independent canonical source
engineering under current custody. It neither recovers its unavailable proposal
nor clears its refused observation or any other original held effect.
