# Daily history research view — frozen implementation packet

Scope: private, offline Market Memory research artifact. This is not a new public
site shell, authentication system, retained-output authority, or deployed product.
Existing Data & Lab already exposes the derived Parquet through its research root.

Primary question: what happened on this date across the selected market proxies?
Action: choose a date, inspect the observed market, then explicitly reveal later
outcomes. No historical recommendation is generated. No future information enters
the default machine day reader. The portable education artifact may optionally
contain compressed future outcomes, so it is NOT an evaluation security sandbox.

Archetype: research workbench. Signature is the selected calendar date and horizontal
previous/next navigation, not a marketing hero or score-card grid. A single table
compares asset groups; source and missingness evidence live behind a details element.
No separate global navigation. Market Memory title and existing canonical .mm-retained,
.mmr-panel, .segbtn, .mmr-selector components provide the house vocabulary.

Layout: header (title, language/theme buttons); retrospective-only explanation;
calendar controls; strong selected-date heading; exact-day coverage; main table;
explicit later-outcome reveal; methodology/source disclosure. The table scrolls
inside its container on mobile, never pushes the viewport width. Controls wrap.

DARK TREATMENT: existing theme.css graphite command-center surfaces, panel2 controls,
text-grade up/down tokens, quiet line separation. No decorative glow or false live
animation. LIGHT TREATMENT: existing cool canvas and white panel surfaces, hairlines
and canonical card-shadow give separation; no dark material carried into light.
EN/ZH uses the existing data-lang convention and direction-token reversal. Only
canonical theme fonts/spacing/radii/colors; no new palette or root token family.

Controls: editable ISO date (no nearest fallback); previous/next observed date;
symbol selector; outcome reveal/hide (default hidden and undecoded); theme and
language toggles. Null displays em dash plus the missing reason in the evidence view.
Unknown date produces no observations, not the nearest or latest row. All observed
horizons explicitly mean rows in this series, not certified exchange sessions.

Browser artifacts are read-only, self-contained, no network, external font, tracking,
provider connection or source credentials. Data enters compressed canonical JSON,
verified before render, and dynamic content uses textContent rather than innerHTML.
A restrictive CSP blocks network/form/base navigation. Default export excludes
outcomes entirely; optional include_outcomes requires an explicit author argument.

Acceptance: real archive through hash-bound export -> browser date navigation,
correct 25-row 2020-03-16 view, exact missing-date empty state, source disclosure,
no outcomes before reveal, successful reveal and rehiding on date changes, corrupt
payload error, zero remote requests, keyboard focus, no page overflow, dark/light
x EN/ZH x1440/390 screenshots. Existing brand CSS is reused, no live site changed.
