## Composition and interaction

Reuse the existing panel, neutral selection surface, buttons, detail disclosure and typography tokens. Outcome inspection is a deeper view of the committed comparison. A back action returns to that exact comparison. One heading and two supporting sections: lens/cutoffs and observations. Never add another site header. On desktop each row presents case/session, unchanged distance, observation state/value and evidence action. At 390px these become a deliberate vertical reading sequence. Cases stay in the original match order in every lens; no winner ranking or independent-N claim.

Known then uses the comparison cutoff exactly. Observed later requires an explicit later cutoff and a separate owner-authorized read. Never preload later observations into a then-known response, auto-replace a chosen revision, change the selected generation or use a future outcome to rebuild selection. URL/back/reopen preserve lens, cutoff and exact observation reference through the existing intent owner. A newly selected case or lost entitlement clears the attached view. Late responses cannot overwrite newer intent.

Observed values use the label archived close ratio (later source close divided by case source close), with four-decimal presentation and exact q18 available in details. Prices are unadjusted archived marks; no RTH-close authentication or total/economic-return claim. Evidence details name original observation ID/digest, original revision and observation/publication/recording clocks. No generic source homepage or invented URL. Corrections preserve the original revision rather than silently replacing it.

## States and accessibility

Observed: display a qualified ratio and an inspect action. Proof pending: explain that no qualified observation is visible by this cutoff; neither missing nor future existence is disclosed. Censored: show the registered reason, separately from proof pending; never zero or failed forecast. Then-known with a future publication and then-known with no publication have the same public shape. Denied/error: redact outcome values and explain what remains usable; retry only after a user action. Loading keeps the row geometry. Empty selected comparison has an explanatory empty state. Corrected observation displays revision lineage with original evidence available. Buttons/touch targets >=40px; focus visible; details work with keyboard/touch; no hover-only evidence. EN/ZH meanings match, and no directional color is needed for the neutral ratio.
