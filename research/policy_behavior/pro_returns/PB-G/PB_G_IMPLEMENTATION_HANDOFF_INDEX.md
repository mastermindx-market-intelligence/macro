## Shared contract incorporated by every brief

**Original outcome.** Help the user inspect what occurred, what remains uncertain, and which observation would change the interpretation. A machine consumer receives exact source identity, qualified clocks, typed absence and explicit context-only authority. Better evidence is the current product outcome; prediction improvement remains an experimental question.

**Ownership.** Reuse the [existing owner map](PB_G_NO_DUPLICATION_MAP.md). Domain facts, canonical event identity, lifecycle, source retention, knowledge time, evaluation and publication remain with their existing owners. A proposed data element below is a semantic requirement, not permission to append an unsupported field to a closed schema. Version and admit the smallest extension with that owner. Do not launch a parallel source store, policy tracker, economic graph, clock service, cohort ledger or evaluation system.

**Timing and correction.** Preserve source publication/effective times, local first observation, ingestion and applicable served/input-cutoff clocks independently, with precision and provenance. Unknown is a valid result. A historical publication date does not establish system possession. Corrections append linked versions through the owner; never rewrite an earlier decision-time input, backdate a later observation or silently replace an enrolled label. Data OS's temporal profile decides PIT eligibility; DERIVED content has no PIT-readable known-at.

**Authority.** All new outputs remain context/research only. Preserve policy exclusion from Intel Hub scored voting and unchanged Prophet candidate selection, rank, entry, sizing, trading and live alerts. Compare actual decision fingerprints where a consumer annotation is added. No research label becomes a runtime lifecycle or universal hidden-intent score.

**Compatibility and proof.** Before writing, record exact base, paths, source contracts, dependencies and incumbent custody. Keep the existing consumer's design, language support, dark/light themes and responsive behavior. Tests must discriminate real mistakes: stale evidence hidden by fresh synthesis, echoes counted as independent, unsupported amounts summed, unknown treated as zero, or an annotation changing a decision. A fixture-only pass is insufficient for a claim that a real consumer works. Record one normal owner-source → producer → retained artifact → consumer path with exact identities, plus the relevant withheld/error paths. An authenticated or entitled receiving path must be verified under its existing access rules.

**Stop.** Stop at the named capability with bounded proof and truthful acceptance status. If an owner contract, exact path, lawful source, rights or real consumer is missing, return that specific unresolved dependency; do not compensate with a new owner. Do not expand into full UI redesign, model tuning, unrelated cleanup or production authority.

**Routing.** At future admission, select a qualified bounded builder under current routing law and a separate reviewer where needed. These briefs do not select a model/account/session, allocate capacity, originate an external child or arm a watcher. PB-G's in-session read-only analytical assistance was part of this synthesis, not execution of these briefs.
