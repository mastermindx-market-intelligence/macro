## P0.3b - bounded rule and counterexample census

Purpose: identify original author statements that materially change the pivot/leader/exit specification. This is a deliberately selected research sample, not the full account census. Use the available original X read interface only, with current source permissions and quota respected. No purchase, credential export, new session, worker, scheduler, scraper or collector. No source-code/PR edits by the evidence reader.

Budget: at most12 new read calls; stop sooner at an explicit denial, rate/quota restriction or sufficient evidence. Use supported small page sizes (up to20 posts per query when available). Do not recover from a denial through another account/interface. Do not run endless date bisection or pagination. No raw copyrighted corpus or media files are to be published to GitHub; return IDs/URLs, author/timestamp/source metadata and short paraphrased facts.

Candidate query families, adapting syntax only to the actual supported search contract:

1. Author + 30m / 30 min / 30 minute / pivot: entry geometry and temporal context.
2. Author + first green / all day / downtrend: rule definitions and boundaries.
3. Author + relative strength / RS leader / RS new high: selection and onset.
4. Author + group / industry / theme / sector with leadership: group conditioning versus isolated stocks.
5. Author + stopped / failed / loss with pivot or 30min: false starts, risk and negative examples.
6. Author + trim / exit / runner / profit / sell with pivot or risk: management and invalidation.

Include the author's own replies because clarifications may live there. Exclude pure reposts in the primary author-statement set; a quoted third-party statement must not be attributed to the author. Keep original, quote and reply identities distinct. Preserve the full query, exact start/end window, requested/returned counts, sort mode, has-next-token and retrieval time for every call. A selected latest/relevant page is not an exhaustive chronological population.

Where search exposes a useful source statement, retain exact original ID, returned author ID, created_at, canonical URL, parent/quoted ID, media locator if returned, a short paraphrase, evidence type (explicit rule/example/question/claimed result/negative case), and the narrow conclusion it supports. Record unanswered ambiguities instead of filling them. Do not claim a chart was inspected when only its URL is returned. Do not interpret a reported R multiple as audited profit.

Return at most40 unique decision-relevant posts, de-duplicated by original ID; fewer are acceptable if that is all the bounded reads support. Include contrary cases and rule exceptions, not only successful trades. Specifically seek whether all-day decline is necessary, whether earlier green candles can be ignored and why, whether high-touch or close-through triggers, whether the first RTH candle can qualify from an overnight decline, and what exact stop/exit/reentry instructions exist. Unknown is an acceptable finding.

Return one integrated table plus an explicit rule/exception/unknown synthesis and the acquisition ledger. Do not edit implementation or validate its code. Current one/two-red comparator definitions stay frozen pending an explicit later versioned decision. The result does not override source admission, model evaluation or entry authority.

## Full eligible-universe census - later separately bounded acquisition

A defensible target is **all retrievable public author posts in the chosen source and fixed query window**, with separate inventories for originals, replies, quoted posts and reposts. It is not every post that ever existed. An owner-side archive can add evidence if legitimately supplied, but must not be promised as a recovery of every deleted historical item.

Before wider acquisition, bind the actual source contract/rights, permitted retention and presentation, quota/budget, fixed end cutoff and intended item classes. Paginate each predeclared nonoverlapping UTC window to its actual exhausted cursor; record empty pages that still have a cursor and do not mistake them for completion. Dedupe IDs across windows/replies/quotes and preserve failures/retries under the existing source owner. A profile count is only a plausibility check with its different item definition, not a coverage guarantee. No new background collector is authorized by this document.

Classify coverage separately: ENUMERATED_QUERY_WINDOW, PARTIAL_PAGINATION, SOURCE_UNAVAILABLE, DELETED_OR_UNRESOLVED_REFERENCE and UNSEARCHED. Exhausted search proves only the queried surviving-source universe. Missing posts remain missing, and an absence of loss posts is not an absence of losses.

Strategy conclusions and efficacy remain separate: an exhaustive public-post census could still be selectively published, retrospectively explained or omit actual orders. Market efficacy requires the existing independent PIT/chronological/cost/prospective protocol, never follower counts or the fraction of tweeted charts that later rose.
