## 3. Lawful evidence needed to finish the comparison

Use only an authorized public display, user-provided export/screenshot, or vendor documentation supplied under applicable terms. Retain source URL, retrieval instant, selected factor, window, displayed units, available membership and methodology statements. Preserve access limits; a signed-in page is not permission to call hidden APIs or redistribute its data. Do not copy competitor source code, proprietary taxonomy, constituent lists or screen layouts into Mastermind.

Each observation should identify whether it is an actual product output, a stated method, a secondary description or an inference. Record null evidence instead of inventing details. A screenshot proves displayed values/layout at an instant, not the portfolio holdings or corporate-action implementation that produced them.

## 4. Pre-specified discrimination tests

Run these tests on lawfully obtained evidence only; they have **not** been run against LIQN in this commission.

| Test | Required observation | Models it can distinguish | Limitation |
|---|---|---|---|
| Within-month constituent round trip | Stable composition, daily factor values and sufficiently precise constituent returns | Monthly buy-and-hold versus daily target reset | Fees, omitted members or hidden corporate actions can mimic differences. |
| Rebalance boundary | Composition/weights immediately before and after stated boundary | Reference date versus effective holdings; daily/monthly/event rebalance | A dated composition page may report a publication date rather than effective membership. |
| Dividend/split event | Source-qualified endpoints, distributions and factor weights | Raw, split-adjusted and total-return basis | A missing dividend can be too small for rounded UI values to identify. |
| Membership insertion/removal | At least two retained composition revisions and historical-line revisions | Current-roster backprojection versus frozen historical membership | Unchanged historical line does not by itself prove original knowledge timestamps. |
| Monthly cell versus daily chain | Exact monthly endpoints and daily returns | Geometric linking versus arithmetic mean/snapshot aggregation | Rounding requires an explicit tolerance bound. |
| Missing listing/price | Known ineligible/unpriced member and disclosed weights | Renormalization, cash treatment, null or owner valuation | A flat quote may be an actual stale valuation; raw display alone may not distinguish it. |
| Rebase and window swap | Same line under two starts, with equal observations | Pure rebasing versus window-dependent reconstruction | Providers may legitimately select different total-return vintages. |
| Spread leg swap | A−B and B−A over the same interval | Difference versus relative ratio; leverage effects | Funding/borrow can break simple antisymmetry; no zero-cost inference. |
| Spread scale/reset | Two windows and stated exposure/capital convention | Daily-reset compounded NAV versus endpoint difference | A gross diagnostic spread is not a defective strategy merely because it lacks a financed NAV. |
| Ranking ties / absent factor | Equal displayed returns, differing histories and unavailable observations | Tie and missingness conventions | Equal rounded values need not be equal internal values. |

Use a predeclared model set and do not tune assumptions after viewing outputs merely to force a match. Calculate residuals under each candidate method with a tolerance derived from displayed precision and input uncertainty. Classify models **supported**, **contradicted**, or **underdetermined**. A single matching window does not identify an algorithm; multiple adversarial windows and explicit methodology evidence are needed.

## 5. Product implications that do not require competitor access

Mastermind should display the factor's actual cohort/basis/version, not only a name and attractive line. Preserve current/PIT labels, complete/partial/unknown states, exact windows, weights, costs, revision lineage and denominator coverage in comparisons and exports. Add useful monthly heatmaps and multi-factor comparison through the existing consumer only after the owner contract is accepted. These are original product requirements from this commission, not a claim to have reproduced LIQN's proprietary implementation.

**Remaining comparison gate:** first-party historical/composition/method evidence sufficient for the discrimination tests. The public landing/sign-in evidence is insufficient; there is no claimed complete competitor reverse engineering.
