## R2 evidence-integrity correction — 2026-10-11

A bounded adversarial check of the already published held-reader ABI revealed a **real evidence-fingerprint collision**: changing an already-decoded close or positive volume, while recomputing that row's self-consistent `receipt_sha256`, previously left the ABI `evidence_digest` identical because it hashed only the metadata-only source preflight. A separate set of deliberately self-sealed impossible OHLC values (e.g., `high < close`, `low > open`) also survived candidate decoding. The source preflight's metadata-only digest remains correct for its own defined purpose; the bug was the ABI's omission of the *actual decoded row receipt* from its separate consumer evidence identity.

The original `prototype/owner_reader_abi.py` now includes deterministic, input-order-independent row bindings `(security_id, event_start, revision_id, canonical_row_receipt_sha256)` in the **candidate ABI fingerprint**. The existing source owner supplied digest is treated as an untrusted **self-consistency check, not a signature or entitlement proof**. The decoder's originally selected source capture, page/row identity and basis/rights refusals are preserved. Structurally impossible or non-finite `open/high/low/close` values now fail closed *before* a local self-hash can legitimize them, with the prior `owner_close` refusal family maintained for source-client compatibility. Numeric bars are still never passed to a live measurement.

Eight distinct targeted red adversarial tests proved both defects before correction. After fixing only this ABI module, 35/35 ABI tests and the unchanged thirteen-suite selection **392/392 local tests** pass on M2 Python 3.12. [Integrity witness](evidence/owner_reader_abi_integrity_witness.json) binds three changed-row cases and four rejected synthetic OHLC cases; all retain `OWNER_BASIS_UNPROVEN`, `source_authenticated=false`, `rights_verified=false`, no WindowPressure and `market_pilot_admitted=false`. No raw Terminal capture was read, owner-code branch was modified, or source admission issued. The newer, separately denied S2-P4 read-model calculation patch remains untouched and uncommitted.
