## 1. Reuse and non-goals
Extend engine/neuralweb/market_memory* and lib/dataos. Existing Market Memory retained
history, lineage, actual-output playback, population, retrieval, and forward accrual
are not replaced. Rotation Time Machine remains a visualization consumer. Existing
Data & Lab owns private host transport and bounded source inspection. Existing runtime,
source registry, artifact storage and trial ledger retain their responsibilities.
No new memory/control plane, provider, scheduler, vector database, trading gate or
historical forward-ledger backfill. Do not touch the active Market Memory W2C/E0
preregistered experiment or claim custody of its sessions.

Rejected alternatives: a prose-only daily AI diary loses source precision; exhaustive
tick/options acquisition front-loads cost; a new historical platform duplicates owners.
Chosen approach: compact derived historical experience artifacts under existing Market
Memory, source selected by exact receipts, with declared research-only modes.

## 2. Three meanings remain separate
ACTUAL OUTPUT: only retained bytes from the existing playback owner.
RECONSTRUCTION: existing Data OS RECONSTRUCT with every required input's actual
availability clock, dependency version, and contemporaneous universe qualification.
RETROSPECTIVE_EXPLORATORY: current retained historical observations. Deterministic
causal feature formulas do NOT turn today's revised/adjusted history into PIT evidence.
Tiingo research readers already force PIT and redistribution false; this extension
preserves these flags. No unavailable source is made eligible by changing a local flag.
Market date, source capture cutoff, calculation version and execution time remain distinct.
FRED vintage dates alone are not intraday release timestamps. Corrections do happen.

## 3. First vertical slice
Read selected Tiingo eod-bars references using read_research_history, never raw Parquet
as a qualification shortcut. Select an explicit capture cutoff and price basis.
Keep vendor symbols as vendor IDs, not invented canonical security IDs. Start with
indices, sector ETFs and cross-asset proxies; denominators describe selected proxies,
never whole-market breadth or a survivorship-safe stock universe.
Build observed-session rows: close, 1/5/21/63-observation returns, 20/50/200-observation
moving-average distances, 21-observation realized volatility, 252-observation drawdown,
volume ratio and benchmark-relative returns. Every horizon is explicitly observed bars,
not promised exchange sessions; missing sessions are disclosed and not forward-filled.
Price basis applies consistently; no adjusted-price/raw-price mixing. Insufficient
warmup yields null plus a reason, not zero. Ratios are descriptive, not recommendations.
Store source references once; state rows carry lineage keys. No full duplicate system
snapshot for every date. Bounds: finite JSON, explicit dates, max symbols/rows/bytes,
no network during reconstruction, no writes to source archives, no symlink traversal.

A separate outcomes artifact contains forward returns/drawdowns only for matured
horizons, with end-of-sample censoring. The default historical state/consumer payload
never contains outcomes; browser reveal is explicit. UI reveals are education, not a
security boundary: a trained LLM may know famous historical outcomes independently.
Strict strategy evaluation uses isolated feature-only inputs and chronology-based
holdouts, not a prompt asking an LLM to forget history.

## 4. Chronology and richer evidence
Continuous daily coverage comes before cherry-picked crisis case studies. Event layer:
macro first-release/revision vintages; pre-release consensus; SEC acceptance and issuer
release times; earnings/guidance; contemporary licensed news; corporate actions;
point-in-time constituents, delistings and classifications; venue/session distinctions.
Unknown data stays absent with source/era denominator. No invented motives or synthetic
headlines. Causal narratives are hypotheses supported by linked contemporary evidence.
Calendar nontrading days may hold events but never synthetic equity price bars.
Old options/OI/BOATS history must be sourced; no backward manufacture from live state.

## 5. Storage and economics
Reuse external-volume archive and Parquet+compression. Partition derived data by
family/time, avoid per-symbol/day tiny files, and keep raw blobs immutable. Hash and
restore test artifacts; mounted space is not a backup. Measure bytes per observed
row/session before expanding. No new purchases or indefinite all-market tick capture.
Preserve forward captures now where existing admitted collectors already operate.
