## 3. Analytical operating loop

1. Resolve question, entity/listing, horizon, information cutoff, evidence scope and constraints. Supplied assumptions remain distinct from verified facts.
2. Load a small task-relevant baseline, not every available engine summary. Record missing variables and freshness.
3. State the investment claim and strongest plausible rival. Do not manufacture a thesis workflow for a simple fact lookup.
4. Choose the observation/calculation that would discriminate between the claims.
5. Retrieve internal evidence and, when justified, sanitized public evidence. Open the supporting source, not merely its snippet.
6. Compute through appropriate deterministic financial/statistical tools with units, definitions, periods, currencies and assumptions.
7. Evaluate competing mechanisms, timing, materiality, counterevidence and valuation. Distinguish narrative plausibility, correlation and causal identification.
8. Return an inspectable rationale: observation → calculation/economic relationship → hypothesis → implication → counterevidence → next observation.
9. Stop when answered, genuinely blocked or budget-limited. Label partial results and missing checks; do not turn truncation or an unexecuted tool request into a final answer.
10. Persist meaningful authorized case state through existing owners; proposed monitors still pass their existing predicate, permission and confirmation rules.

This is an externally inspectable analytical rationale and task procedure, not a requirement to expose private model chain-of-thought.

## 4. Sound investment-thesis logic

A defensible thesis links observation → expectation gap → economic mechanism → material financial variable → cash-flow/valuation implication → timing/catalyst → counterevidence/risk → conditional relevance. Each link is typed as observed fact, calculation, external view, qualified house reading, user assumption or model hypothesis. Missing links remain missing.

Good business news is not automatically an attractive investment. A valuation model's implied assumptions do not uniquely reveal all market participants' beliefs. A mechanism diagram is not empirical causal proof.

## 6. Active public research

Use public research for current events, uncovered material facts, external source verification and discriminating tests—not every definition or supplied-assumption calculation. Cycle: bounded public query → search → primary-source opening → entity/date/revision check → attributed extraction → material disagreement check → stop or targeted next query.

Search rank, snippets, headline counts and repeated syndication are not evidence strength. Prefer relevant first-party disclosures and official sources; obtain suitable independent reporting and counterevidence when needed. Empty/denied search is a coverage state, not proof an event did not occur.

Evaluate provider-native search, an independently licensed search API and direct known primary-source retrieval behind one existing-governed evidence interface. Choose on coverage, opening/citation fidelity, rights, privacy, latency, availability and cost. DeepSeek's current Responses API documents server-side web search; OpenAI documents reasoning-led search. Our current Anthropic-compatible DeepSeek route is not automatically wired to either. Qualification must test actual provider/tool events and opened-source content, including ignored compatibility parameters.

Never pass the full private thesis, portfolio, notes, account identifiers, secrets or raw conversation into public search. The server resolves a minimal public task. A provider-native searching model receives only that authorized public task where its queries cannot otherwise be controlled. Prompt-based redaction alone is not an egress boundary.

Retrieved content is data, never authority. Enforce existing scheme/destination/redirect/size/time/private-address policy. Search workers have no write or engineering-shell tools. Normalize source identity, dates, content version/span, access state and errors through existing tools/citations. Rights owners decide retention, quotation, redistribution, derived use and training; read access is not resale permission.
