**Blocking Findings**
- Receipt floor becomes satisfiable with zero source numbers. `check_receipts` builds its pool as `[val for val, tier in fact_tier_index(slot) if tier == "first_party"]` (`engine/press/validators.py:859`), and `check_our_value` scores only sentences anchoring a first-party value (`engine/press/validators.py:812`). Every fact this module emits for the White House source is `tier="third_party"`, so before this patch an external-only plan had an empty first-party pool and could never clear either check. `facts.extend(context_facts)` at `engine/press/external_candidate.py:263` is therefore not an optional enrichment — it is the only route by which an external candidate becomes validatable, and it opens that route without requiring a single external claim value in the draft. `tests/test_press_external_candidate.py:185` asserts exactly this: a draft citing only market-state numbers passes `check_receipts` at floor 5. `min_anchored_receipts` is untouched, but the floor no longer constrains the external story. `check_primary_source` still forces the source to be named and linked above the fold, so this is not silent attribution loss — it is a validation bar that can be met entirely with our own metrics. Needs an explicit parent decision plus a gate requiring ≥1 anchored source (`third_party`) value for external slots. Adding a gate is not lowering a floor.
- Non-`ValueError` escape from the extractor call. `engine/press/external_candidate.py:110` invokes `extractors[rel](payload, rel)` with no guard. These extractors are only fail-soft inside `engine_stat_facts`, which wraps them in `try/except Exception`. Called bare, hash-pinned-but-malformed bytes raise `TypeError`/`AttributeError`: `{"components": {...}}` hits `(obj.get("components") or [])[:4]` in `_market_state_facts`; `{"indices": [...]}` hits `.items()` in `_gex_facts`. Every other rejection in this module is a `ValueError`, and all 40-odd test cases assert `ValueError`, so a caller doing `except ValueError` leaks. Fix: wrap lines 107–110 and re-raise as `ValueError("reviewed context artifact is malformed") from exc`.
- `first_party_context: null` is a hard error while `derived_share: null` is meaningful. `engine/press/external_candidate.py:88` requires `isinstance(rows, list)`, and the schema gate at `engine/press/external_candidate.py:151` only admits the key's presence. This patch just established that explicit `null` means "reviewed, none" for `derived_share`; the sibling field now behaves oppositely. Either accept `null` as "no context" or document the asymmetry in the qualification contract. Untested either way.

**Hardening**
- Second JSONL reader. `engine/press/external_candidate.py:108` parses JSONL strictly and keeps non-dict rows; `desk_planner._read_jsonl` skips malformed lines and drops non-dicts. Same bytes, two payloads. Direction is fail-closed (strict raises where the engine would skip), but it means a reviewer can pin the live `data/risk_radar/forward_log.jsonl` digest and still get a hard rejection the engine itself would not produce. Share one parser over the already-hashed bytes. No test touches a `.jsonl` artifact, so `risk_radar` is entirely uncovered.
- Symlink rule is brittle and mis-described. `path.resolve() != path` at `engine/press/external_candidate.py:104` rejects any symlinked parent, so a deployment with `data/` or `site/` as a symlinked mount fails closed on legitimate artifacts — and two of the five allowlisted artifacts live under `site/basketdata/`, which is build output. Containment actually comes from the `rel not in extractors` allowlist at line 99, not from this check. Prefer an explicit `resolved.is_relative_to(root)` and document that symlinked artifact parents are unsupported.
- `context_relevance` bypasses the lexicon gate. `engine/press/external_candidate.py:127` applies `_press_safe` to `fact["text"]` but line 130 attaches up to 500 chars of unreviewed free text to a `first_party` fact. Mitigated today: `engine/press/writer.py:288` renders only `text` (through `sanitize_untrusted_prose`) and `source_name`, so the note never reaches the model prompt. Still the one unscreened field in the envelope; screen it for symmetry.
- `_press_safe` returns `True` when the copywriter lexicon import fails (`engine/press/desk_planner.py:448`). Preexisting, but line 127 is now the only content gate on artifact-derived text entering an external-slot envelope.
- `matches[0].get("tier") != "first_party"` at line 115 is unreachable: all five extractors hardcode `tier="first_party"`. Harmless defense, but see the mis-labelled test below.
- `len(matches) != 1` at line 115 also hard-rejects a legitimate artifact whose `components` contain a repeated `key`, since `_market_state_facts` derives ids as `market_state_{key or label}`. Fail-closed, worth a note in the qualification docs.
- Context facts may be dated up to `window_days` *after* the event (`as_of` Oct 11 vs event Oct 8 admits Oct 8–11). The "never establish the external event's effects" disclaimer at lines 82–84 is comment-only; no validator enforces temporal non-colocation in prose.
- TOCTOU assessment, as requested: benign. Lines 104→107 and `_read_bound`'s `is_symlink`/`is_file`/`stat`/`read_bytes` are four separate resolutions, so a race can redirect the final read. The digest, not the path, is the authority — bytes must hash to a reviewer-supplied value, so there is no content substitution and no disclosure the caller did not already commit to. Snapshot caching (line 106) correctly reads once per artifact and rejects a second digest at line 112 before any re-read. Duplicate-id binding via `seen` is global across artifacts, which false-rejects the same id from two artifacts; harmless.
- `**context_revisions` at `engine/press/external_candidate.py:281` puts volatile `artifact:…` refs into the same map `scripts/run_press.py:371` reconciles. Any ref absent from `earnings_call_revisions()` lands in `missing_refs` and marks a staged item `superseded`. Preexisting for `whitehouse:` refs and unreachable while `allow_stage` is false; the patch amplifies the noise and can mask a genuine source-revision change. Do not merge this map with source revisions without deciding the drift contract.
