## Reproduce the bounded checks

From the repository root, with Python, pytest, BeautifulSoup4, Playwright and an approved
installed Chromium available:

```sh
python -m pytest research/homepage_prophet_first/tests/test_product_contract.py -q
python research/homepage_prophet_first/tests/verify_mutations.py
python research/homepage_prophet_first/tests/verify_browser.py
```

`CHROMIUM_BIN` can name an existing approved Chromium/Chrome executable. Otherwise the
harness uses a discoverable Chromium/Chrome or Playwright's installed browser. It does
not install software, navigate to URLs, start a web server or change browser policy.
It renders the authored HTML in memory and blocks page network requests.

The initial attempt to navigate a loopback URL failed with
`ERR_BLOCKED_BY_ADMINISTRATOR`. It was not retried and no policy was changed. Subsequent
proof is explicitly offline document rendering, not a workaround claim that the URL or
production route became accessible. The two methods are not interchangeable evidence.
