**Blocking Defects**
- Zero client-clock tolerance empties the panel. `readIntradayView` sets `age=nowMs-end` from the producer's `source_asof` and returns null on `age<0`. A browser clock behind the source clock by one millisecond rejects every fresh observation, and `intradayPlainReason` then falls through to "Comparable observations are unavailable." — misattributing clock disagreement to missing data. The same reader already tolerates up to 60s of skew *between* member endpoints (`max_clock_skew_seconds`), so the asymmetry is internal to the frozen contract. Minimal fix: `age<-30000` instead of `age<0`. That keeps `test_stale_and_future_clock_remain_unavailable` green, because its `now-2*60000` case yields exactly `age=-60000`; a wider allowance needs that case moved (e.g. `now-5*60000`) plus an accepting `now-2000` case. Leave the 45m upper bound and the expiry math untouched (both remain correct for negative age).
- Automatic refresh can drop focus and re-announces everything. `window.focus` and `visibilitychange` both call `refreshPulse`, which ends in `host.innerHTML=html` inside `#si-intraday-body`, marked `aria-live="polite"`. Focus is restored only if the previously focused `summary` still exists as a `details` row: a row that flips to unverified renders `.si-intra-missing` (no summary), and any non-`ready` state replaces the body with one `<p>`. In both cases focus falls to `<body>` during a refresh the user did not request, and each refocus re-announces up to six rows of numbers even when nothing changed. Minimal fix: hold the built string in a module variable and return early when it equals the last emission (removes no-op churn, focus loss, and announcement bursts in the common case), plus `tabindex="-1"` on `host` and focus it when `focused` was set but no matching row survives.
- Heading contradicts the ordering rule. Rows sort by `Math.abs(relative)` descending, so the first row can be the largest *loser* versus SPY, while the H2 reads "Intraday leadership" / 盘中领涨变化 (领涨 = leads the rise). The panel's own subtitle ("Recent relative moves…", 近期相对强弱) is direction-neutral and accurate. Minimal fix, copy-only: make the H2 magnitude-neutral in both languages (e.g. "Intraday relative moves" / 盘中相对强弱变化) or split leaders from laggards. Do not re-sort directionally — that would assert rank authority this review does not grant.

**Non-Blocking Findings**
- The expiry timer calls `tryRender()`, so a timeout owned by the new panel also re-renders the incumbent `renderTapeBand`. Call `renderIntradayComparisons(pulse,pulseState)` to respect the additive boundary.
- Per-row rejection has no "present but failed verification" copy; the panel-level `invalid` string is unreachable per row, so a contract break reads as missing data.
- Tolerances are far tighter than the 2-decimal display: `3e-6` on `relative_change_pct`, `1e-6` minutes on `elapsed_minutes`, `1e-3` on `coverage_pct`, exact `settlement_tolerance_seconds!==90`. Any producer-side rounding silently voids all rows (see confirmations).
- `row.day` (`live_ew_chg_pct`) is the only unbounded rendered number: it skips the ±40 guard the comparison fields get, and `.si-intra-value` has no `overflow-wrap`, so an extreme value can overrun the `minmax(72px,96px)` track.
- `labels[state]` indexes an object literal; a state string such as `constructor` would print a function body. Use `Object.create(null)` or a switch.
- When no row verifies, the collapsed view prints up to six identical "unavailable" lines; prefer one panel-level line when `!rows.some(r=>r.view)`.
- `new Intl.DateTimeFormat(...)` is built per row per render; with the 1000-basket cap and staggered expiries the single timer can drive many full re-renders. Hoist one module-scope instance.
- "vs SPY" is a compounded ratio, not a difference; the detail discloses both components, but one defining clause would remove ambiguity.
- `#si-intraday-more` has `aria-expanded` but no `aria-controls`, and there is no `aria-busy` during an in-flight refresh.

**Verified Sound**
- Escaping: every untrusted value reaching `innerHTML` passes `esc` (display name, `data-group` key, clock string); all other interpolations are validated numbers or fixed `L()` literals, and no raw status enum is ever rendered. The escaped-write/decoded-read `data-group` round trip is self-consistent (`open[row.id]` and the focus match both use the raw id).
- Null/zero semantics: `pct(null)` → em dash with no sign class; `0` → unsigned `0.00%`; negatives use U+2212. A zero daily return does not suppress interval numbers.
- Arithmetic: `relative` is recomputed from `absolute`/`benchmark` and compared; `coverage_pct` rederived from `n/total`; `elapsed_minutes` from `end-start`; skew bounded by `min(60, interval/10)`; session date rederived in `America/New_York` via `en-CA`. The ±40 guard precludes division by zero. Zoned-timestamp regex rejects naive strings; `Number.isSafeInteger` and the finite check reject booleans, strings, NaN, and Infinity.
- Stale/duplicate/reordered: cached rows self-expire without a fetch (timer → re-validate against fresh `Date.now()` → null → "no longer current"); `clearTimeout` runs on every render including the early-return path, so timers cannot accumulate; ids dedupe first-wins on a null-prototype map; `pulseInFlight` makes out-of-order overwrite impossible. The region contains no `fetch(` and no `setInterval(`.
- Failure states overwrite prior numbers; `hidden` on the more button is not defeated by a `display` override; disclosure targets meet 40px/46px; reduced-motion and `:focus-visible` are handled; mobile grid minimum (~294px) fits a 320px viewport.
