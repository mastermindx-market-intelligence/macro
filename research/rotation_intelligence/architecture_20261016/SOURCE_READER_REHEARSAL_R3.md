### Availability and input rules exercised

A decision requires all eleven sector instruments plus SPY and BIL. Missing BIL is unavailable information, not an affirmative decision to hold cash. The primary all-policy comparison does not silently shrink to nine sectors or remove the failed boundary.

The latest whole snapshot received by the cutoff is selected. Later snapshots cannot rewrite an earlier decision. A latest eligible but incomplete/corrupt snapshot is not silently replaced with an older favorable one. Ambiguous same-time versions, price-basis changes, unsupported evidence modes and late receipts are refused by the reference cases. This is a **selected research policy for the new adapter**, not a claim that every incumbent consumer currently behaves this way.

A complete warmup has 252 prior observations plus the current anchor, or 253 prices. The 63-session return takes the last 64 prices. A missing interior session, one-month prefix, invalid price or unproven cache extension cannot manufacture completeness. A genuine zero return remains valid data.

Rows and decisions do not carry outcome labels, runtime paths or a permission to execute a candidate. These fixtures accept only evidence mode `invented`; they are not an untrusted-input security boundary, an authentication mechanism or an actual source-rights grant.

### Selection and economic path rules exercised

The five rules in TARGET_SCOPE_AND_BASELINES_R1 remain unchanged. B3 ranks trailing relative returns and selects three sectors. B4 puts only slots whose own trailing return strictly exceeds the BIL return into equities; equal returns fail the strict hurdle. Multiple BIL slots are combined before accounting. These are fixed research comparators, not account weights or optimized recommendations.

The reference separates the observation anchor from the next-session execution proxy. It maintains one fixed twenty-session schedule, values actual drifted holdings before each rebalance, and pays costs on security trades rather than settlement-cash bookkeeping. BIL remains a traded security, not cost-free settlement cash.

A missing decision or a missing required valuation mark makes the **continuous comparison unavailable**. It does not skip to the next convenient origin, restart with fresh capital, automatically liquidate at an invented price or claim the cash model was correct. A real operational outage policy is outside this reference and remains separately specified.

The drawdown calculation includes pre-entry capital, initial costs and final liquidation costs. Otherwise a flat-price portfolio could understate its actual loss by omitting its closing transaction. B0/B1 buy-and-hold examples independently match the direct endpoint formula with the stated entry/exit cost convention.

## 4. What the checks actually prove

The initial three tests failed against a deliberately empty implementation with **three assertion failures and no errors**. After implementation, the full suite passed **35 tests** locally and again from exact published bytes on M2.

The eight counterfactuals substitute: 62 for 63 return intervals; a late snapshot into an old decision; a silent rewind past an invalid latest image; equality for the strict cash hurdle; cost-free BIL trading; omission of liquidation from drawdown; ignoring an unavailable scheduled decision; or investment authority on a synthetic output. Each substitution caused the exact selected test to fail by assertion. This demonstrates discrimination for these examples; it is not a formal proof of all behaviors or independent review.

Two invented price histories, five comparators and four declared proportional-cost settings produce **40 complete synthetic paths**. With flat prices and zero cost, every terminal wealth is one. With flat prices and ten-basis-point one-way security costs, every comparator ends near `(1-c)/(1+c) = 0.998001998...`; no baseline creates a profit from bookkeeping.

### Preserve the adverse example

In the constructed leadership-then-reversal world, the long trailing-return rules retain the former leaders while their prices fall. B3 and B4 are identical over the supplied decisions and both finish near 0.85053 on unit capital at the ten-basis-point cost setting. The cash hurdle does **not** automatically make the selector an early regime detector.

This was deliberately generated data. It estimates neither market loss frequency nor the real strategy's performance and does not falsify the empirical momentum family. The useful conclusion is a **counterexample to sufficiency**: an absolute backward-looking hurdle alone does not guarantee rapid adaptation. Preserve this world as a later challenger test rather than choosing a faster lookback after seeing it and claiming new predictive skill.

### Numerical reproducibility is not artifact identity

All three new published source files matched their local hashes. The mutation-result bytes matched across Python 3.13.5 and M2 Python 3.14.7. The full synthetic-path JSON files were **not byte-identical** across platforms. Their recursive twelve-decimal numeric projection, fixed schedule and policy choices matched after omitting only synthetic-input prefix hashes. Both raw hashes and the matching semantic hash are recorded.

A content hash still identifies exact bytes. This numerical comparison is not permission to substitute a different real-source image, normalize away provenance differences or weaken a production identity gate. Numerical tolerances for eventual empirical work must be registered separately.

## 5. Real calendar and cutoff checks, kept separate from invented time

The reference runner intentionally uses ordinal fixture sessions and clock ticks. It does **not** implement exchange holidays, UTC provenance, actual order deadlines or early-close timestamps. Those belong to existing owners and must not be inferred from a passing synthetic trace.

Separately, the incumbent `lib/nyse_calendar.py` blob `0ece6439ffe4b081ee7a268fe99b69e1de1216a3` was exercised in twelve bounded assertions: five session/closure cases, three next-session boundaries and four 08:00 Eastern-to-UTC conversions around daylight-saving transitions. All passed. The official NYSE calendar was checked on October 17, 2026: https://www.nyse.com/trade/hours-calendars . It confirms July 3 and November 26 closures, and November 27/December 24 early-close sessions for 2026.

The inspected calendar owner explicitly does **not** model early-close times. It establishes whether a daily session exists and uses a conservative regular-close buffer for certain freshness queries. A valid session date is therefore not a certified 16:00 closing timestamp. The new adapter must obtain qualified actual close-time metadata through the existing calendar/source owner, or retain the date/interval uncertainty instead of inventing precise event times. Passing these twelve checks is not whole-calendar certification or production clock attestation.

A concrete **unscheduled example**, computed only from the incumbent calendar: for an October 16, 2026 price anchor, 252 prior sessions begin October 15, 2025, giving 253 price observations. The next-session 08:00 Eastern information cutoff is October 19 at 12:00 UTC; the next-close execution proxy is October 19, and twenty subsequent sessions end November 16. No collection, order or scheduled task was created for these dates.
