## Material review decisions

**B completion versus empty integration.** The design requires two positive real-data proof sets, each with a validated company link and a real management-guidance/actual/new-guidance sequence. Optional consensus and unsupported numerical estimates may degrade. If the financial paths are empty, the industrial layer can be partial progress but B cannot be accepted. This prevents a polished evidence-only page from being called the selected Approach B.

**C-compatible does not mean C prebuilt.** The release table separates 48 B obligations from eight later C1 migration gates. The eight future gates are not coding tasks for the B plan. Stable evidence and configuration/time/rights semantics serve B immediately; a global object registry, general query language and autonomous resolver are explicitly excluded from B.

**Cross-owner K1 composition.** Fresh K1 documentation says the current compiler lacks the validated cross-type bridge-object slot. The specification therefore permits separately typed native blocks and requires native identity proof for company navigation. It does not silently promote the page to a successful unified security recipe. Any extension of that compiler remains a K1 owner change, not a consumer shortcut.

**Historical identity and foreign coverage.** A resolved GMI security may lack issuer resolution, and its current issuer field does not prove historical ownership. The current financial packet also requires a CIK. These source facts became explicit section-9 and acceptance constraints. Foreign/private industrial evidence remains useful, but no fake CIK, current-to-historical attribution or guessed listing is allowed.

**Rights revocation.** The rights code caches the registry by path. The design requires warm-process revocation proof; it does not assert that changing a file instantly changes a running process. Existing private Earnings transport is a pattern, not authorization for GMI storage. Native GMI private binding and current rights remain required live-admission gates.

**Schema compatibility.** The draft was strengthened to say that an altered existing field meaning or native clock is not an additive change. Such changes follow the shared owner's major-version discipline. An optional industry payload cannot silently repurpose the legacy evidence envelope.

**Promotion without false equivalence.** The C1 section distinguishes exact identity from variant-of, part-of and broader/narrower family relationships. Identical labels do not make a facility campus and line, or two product generations, one entity. The later mapping is evidence with its own time and revision, not a replacement for the original assertion.

**Useful learning without rewritten history.** Migration parity has two modes: same inputs/mapping/definition preserve old answers; accepted new mappings may improve current answers with explained deltas. System historical replay excludes mappings learned later. Rollback changes the active projection and never erases original evidence or bypasses current rights.
