## How to read this crosswalk

This is a new migration ruling over the preserved R3A capability ledger. It does not modify that archived ledger, its fixtures or its frozen review. The August wave's prohibition on relocation governed that reference wave. The current commission explicitly authorizes reorganizing Sector Central; the new homes below apply to this migration. Source semantics, access restrictions, scientific qualifications, live source custody and actual refusal records remain binding.

Every original row has a destination. A destination is not evidence that the feature has migrated. All production rows remain pending integration and real-path acceptance. Rows 66 and 92 remain producer-dependent unless an accepted current source supplies the missing contract. The current 2026-10-18 source read outranks historical field/route/access assumptions where they differ.

The new working reference demonstrates selected measured, event, original-coordinate rotation, participation and Confluence presentations. It is explicitly incomplete for cycle history, Time Machine chunks, live heatmap/ETF-flow sources, gated action hydration and verified company-to-Prophet continuation. It uses the immutable R3 archive and a separate measured test fixture with visible different clocks; no mixed-date synthesis is implied.
