## Consolidation rule

Prefer a clear current entry point, written source contract and explicit reference label before removing useful history. For a future archive/replacement, first establish the current writer, original release/hold state, incoming links and content parity. Use only a qualified native operation. The oversized monolith is a specific no-write surface; the blocker does not prevent source documentation or safe edits in the separate product files.
