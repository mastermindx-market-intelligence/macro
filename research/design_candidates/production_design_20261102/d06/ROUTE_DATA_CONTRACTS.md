## State and identity ownership

TerminalShell owns pane symbols/TFs, active pane, workspace graph, tool intent, indicator parameters/visibility, comparisons, replay intent and per-symbol human drawings. ChartPane owns presentation/settings and transient timeframe-specific auto drawings. ChartPanel owns renderer, rendered data/viewport, reader-local selectedTime and its subscriptions. paneSync owns linked calendar ranges/crosshair; Brain/readout uses its existing lockedVLine/selection revision. This is a distributed ownership boundary to preserve, not a mandate to centralize all state.

Human drawings on two panes of the same symbol share the rightful owner's set. Auto drawings reset by symbol/TF. Auth changes hard-reset the renderer/owner boundary; symbol changes deliberately reuse it. Old chart may remain dimmed until new visual readiness with a four-second failsafe; the visible old generation must remain attributed.

A company, listing, exchange, chart token and user-selected region are different objects. Base daily/intraday envelopes do not guarantee all of them. Prefer an approved listing resolver and keep unsupported identity explicit. Do not relabel a US cached series after selecting China, or infer OHLC currency from language/region. Top-level ticker checks in useWorkspaceSource do not independently validate slice.indicator or backtest.universe.ticker; nested mismatch tests remain required.

## Clock and null rules for every builder

Use explicit field semantics, not one global “Live” label:
- observation: source quote print, bar/session date, model input cutoff;
- publication/known time: when evidence was available, e.g. signal known_ts; missing stays unknown;
- ingestion/assembly/build: pipeline events, never substituted for market observation;
- cache served time/age: which copy the user sees;
- capture time: screenshot/evidence device time;
- mutation revision: script/layout concurrency stamp, not a data clock.

True zero remains0 only when the producer means measured/computed zero. Unknown,null,missing,withheld,refused,stale,partial and unsupported keep distinct reasons. Preserve correction/generation/adjustment metadata when supplied; a latest-view contract is not historical point-in-time reconstruction. No visual treatment or current numeric value may override those qualifications.
