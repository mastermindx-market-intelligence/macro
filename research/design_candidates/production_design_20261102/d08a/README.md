**Job:** find a meaningful observation, establish what was actually measured, inspect the corresponding underlying or contract with dated evidence, and return to the exact scan without losing filters or orientation.

**First useful view:** the current selected scan with its source session, population and rank. Default native routing remains the incumbent Tape. Command/Desk remains a deliberate overview; no automatic route migration is proposed. Public Daily Brief remains the dated editorial entry.

Advanced filtering, 30-column Tape CSV, 38-column Screener CSV, local screens, shortlist comparison, Statistics and Prophet lanes survive.

**Useful incomplete-data alternative:** inspect the available source observation, retain its context, see which dependent book or field is missing, and return or select another supported source. No fabricated values or synthetic contract pins.

**Proposed improvements:** exact-observation selection from Tape; explicit root-filter action; stable selection while updates buffer; honest unavailable preset entries; compact phone rows retaining contract identity; receiver-qualified D08B transfer and exact return. These are design obligations on existing owners, not installed product features or a new state service.

**Success measurement plan:** after implementation is separately authorized, observe completion/error rates for the five-step journey, time to first useful row, return restoration failures, accidental filter-versus-inspect clicks and access/error recovery. Use the existing telemetry owner; do not add a parallel analytics collector. No usability or performance success has been measured here.
