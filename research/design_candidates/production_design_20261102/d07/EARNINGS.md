# Earnings, dossiers, and calendars

A reader must be able to answer three different questions. “When is the report?” uses a scheduled event. “What did the issuer report or say?” uses a fiscal-period record. “What happened to this listing's price?” uses dated bars. A date shared by all three is insufficient to join them.

The existing auth owner emits `mdx-auth` on sign-in/sign-out without requiring a page reload. The article module lacks a continuing auth subscription and a response fence for the current account. Same-document sign-in may start one fresh authorized read. A successful response must reconcile the continuation already present before insertion so refresh or auth renewal cannot duplicate facts or receipt rows. Verify the rendered result belongs to the current subject and selected article before showing an unlocked state. These are proposed owner-local repairs.

The private transport authenticates and enforces paid access before opening its store. It verifies a receipted record from the current private generation and caches only the manifest for 30 seconds.
