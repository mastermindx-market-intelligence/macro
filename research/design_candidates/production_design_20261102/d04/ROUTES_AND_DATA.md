## 3. Identity and clocks

Existing symbols and route hashes remain valid aliases. Proposed fixed/group saves need a qualified security/listing identity from the existing security master/owner, not a ticker string alone. Preserve share class, exchange/market, currency and canonical listing. Resolve ambiguity explicitly; do not substitute a stale shared cursor, a similarly named company or a US listing. A theme/subtheme key, curated basket ID and sector taxonomy key identify different objects. A dislocation is keyed by `episode_id` with detector/version/spec hash and session, not by ticker alone. [S07](SOURCE_INDEX.md#s07), [S10](SOURCE_INDEX.md#s10), [S11](SOURCE_INDEX.md#s11)

Required adapter clocks (proposed normalization onto existing producers): `observationSession/asOf`, field-level event/observation time where supplied, `publishedAt`, `retrievedAt`, `membershipAsOf/version`, `definitionVersion`, and `validThrough` only when the producer supplies it. Missing clocks remain null/unknown. File mtime and fetch time are not a financial observation time. Newer HTML does not refresh an old model, classification, membership snapshot or capitalization reference.

Freshness is component-specific. Name the expected eligible exchange session/calendar and cadence when the owner defines them. Do not impose a generic24-hour rule on quarterly fundamentals, nightly scans, delayed quotes and historical membership. Each adapter preserves its actual stale/expired predicates until an owner-approved change is versioned.

## 5. Required comparison envelope — proposed adapter, not a new endpoint

### Confluence exact current field binding

`scripts/build_confluence_screener.py` reads `site/factordata/tech_confluence.json`. `_eligible_long_combos` requires nonempty `active_now` and non-null `h21.wr_mc_test/wr_mc_train`, then sorts descending `rank_score` and selects the first 3. Python's stable sort retains input order for equal keys; the UI must preserve that order. Public context binds `combo_id`, names, structured `legs[]` (`en,zh,tf`), `wr_test_pct`, `wr_train_pct`, `n_test`, `months_test`, `n_train`, `months_train`, `n_fires`, first/last_fire, fires_per_year, edge_test_pp, consistent, rank, is_free, active_count and active_tickers. Rates are source fractions multiplied by100; the UI's `/10` representation is another display conversion, not a different metric. The source description binds the rank to the recent month-collapsed Wilson lower bound minus random-entry baseline at21trading days. Preserve both era sample bases beside the rates.

Only rank1 receives active_tickers in public context. The protected `premiumdata/confluence_screener.json` is `tier_payload.v1`, page `confluence_screener`, required_tier `essential`, and returns combo_id/count/identities for ranks2–3. Hydration must join by combo_id, not row position, and reconcile stale mismatched payloads before revealing identities.

`n_active_total` counts all eligible active combinations rather than securities and not just the displayed three. Both public and hydrated company links use `stocks/<ticker>.html`; Discovery/Advanced use a different `stock.html#ticker` contract.

Root inspected `engine/tech_confluence.py`: a combo fire is the rising edge of the AND of its2–4 D/W legs; forward return uses the next close and source trading-day horizon. The default fire-date split is2018-01-01. Month-collapsed WR is the arithmetic mean of each calendar month's within-month winning-fire proportion, **not** the fraction of months with a binary winning outcome. For example, a month with1/1 wins and another with1/9 wins produce55.56%, not20% pooled wins and not100% months with any win. The Wilson bound is explicitly a ranking heuristic for month-averaged proportions, not a newly validated confidence statement. The older fields are `train`, recent fields are `test`; the current tooltip calling older years an “out-of-sample check” is inconsistent with that producer. Proposed copy: **“Older period (training sample)” / “较早时段（训练样本）”**, **“Recent period (test sample)” / “较近时段（测试样本）”**, with month-mean methodology and sample bases. “Test” is not a claim of untouched prospective validation. Fix copy through the existing owner without silently changing calculations.

Current hydration validates schema/page/array shape but does not establish an artifact-generation join; non-array active_tickers becomes an empty list. This creates distinguishable stale-generation/invalid-payload risks. Proposed adapter must reconcile `combo_id` plus generation before revealing names, and distinguish missing/invalid identities from a verified empty result. [S04](SOURCE_INDEX.md#s04)

Current `raw is None` context sets asof null and zero active count, and several optional numeric fields use zero defaults. This is a **source gap**, not proof that missing data means a verified zero. The future adapter must preserve a source-availability discriminator before a global-zero message can be truthful. Likewise, skipped invalid leg indices require an incomplete-recipe state, not fabricated leg content. These are proposed repairs requiring producer/renderer agreement. [S04](SOURCE_INDEX.md#s04)

Extend existing domain adapters to expose the minimum facts the UI needs. Do not manufacture a universal endpoint or duplicate upstream truth:

Comparisons require compatible universe, definition, unit/currency, horizon and session basis. If a user requests different definitions, show them as explicit side-by-side evidence rather than subtracting unlike values. Preserve a fixed roster and compare the intersection of observed members for the matched statistic. Show full-roster coverage beside it. Group entry/exit from membership is a different change from an observation becoming missing.

For a fixed N-member group with observed advancing A and U unknown, the possible advancing-share range is `[A/N,(A+U)/N]`. This is an identification bound, not a confidence interval or forecast. To compare sessions with missing data, compute the possible change bounds from both sessions' bounds; use the same membership. The matched statistic uses the same observed IDs at both ends and explicitly names its denominator. Preserve the source advance threshold: Macro uses>0.05pp; the Paper example uses>0. They are not interchangeable.

## 7. Cache, correction, security and rendering responsibility

Reuse existing `dataCache`, `flowClientCache`, source abort/generation guards, owner-scoped save client and shared-shell bridge. Avoid parallel reads/subscriptions for hidden panes. Macro heatmap's current read is no-cache with a10-minute refresh timer; Terminal polls and overlays have separate cadences above. On source correction, carry revision metadata, retain prior evidence references when available and label what changed. No market data is relabeled by theme/locale or re-stamped by re-fetch.

Server responsibilities: entitlement filtering and protected identity omission; user ownership; typed input validation; monetary units and source qualification; bounded requests; revision conflict/readback semantics; authoritative saved-object outcomes. Client responsibilities: accessible rendering, staged predicates using the existing grammar, format-at-boundary, field-specific missing states, route/history restoration, and truthful progress. Client hiding is not an access boundary. A stale actor/account switch clears visible private data without destroying the original owner's recoverable request.

No new provider, remote asset, license grant, trade authority, forecast validation or regional parity is inferred. Existing approved rights decisions remain owned by their existing law; this assignment consumes authorized source evidence and proposes original UI integration.
