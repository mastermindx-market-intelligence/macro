The UI must never advertise unbounded historical sessions because this source can supply bounded views.

### IEX chain

[iex_deep_trades.py](https://github.com/mastermindx-market-intelligence/mastermind-terminal/blob/2ded360882b9c721e690907ff363b553781fb920/ingest/iex_deep_trades.py) owns PCAP/transport decoding, order lifecycle, native executions and break identity. Its optional [DepthSampler](https://github.com/mastermindx-market-intelligence/mastermind-terminal/blob/2ded360882b9c721e690907ff363b553781fb920/ingest/iex_depth_replay.py) attaches discrete observations to the existing envelope. Defaults are 5,000 ms sampling, 480 retained frames, 32 levels per side; validated maxima are 60,000 ms, 2,000 frames and 64 levels. It omits older retained observations at the cap and records `samplingTruncated`. Sampling quality changes can occur earlier than the normal interval. The decoder writes a new private output directory with receipts; this is not proof that an approved public publication has occurred.

The shared API reads `MACRO_LIVE_DIR/public/live/large_trades/SYMBOL.json` (default root `/var/lib/macro-live`), rejects symlinks/nonfiles/actual reads over 8 MiB and applies [sourceAdmission](https://github.com/mastermindx-market-intelligence/mastermind-terminal/blob/2ded360882b9c721e690907ff363b553781fb920/terminal/lib/largeTrades/sourceAdmission.ts). Existing deployment/publisher custody must connect admitted output to that path; D08D adds no publisher. [fetchLargeTrades](https://github.com/mastermindx-market-intelligence/mastermind-terminal/blob/2ded360882b9c721e690907ff363b553781fb920/terminal/lib/largeTrades/client.ts) distinguishes signed-out, denied, rate-limited, invalid, unavailable and ready outcomes, and returns `artifactSha256`/`servedAtNs` when ready. [IexDepthReplayView](https://github.com/mastermindx-market-intelligence/mastermind-terminal/blob/2ded360882b9c721e690907ff363b553781fb920/terminal/components/futures/IexDepthReplayView.tsx) currently collapses non-ready outcomes and discards those two evidence fields.

[iexDepthReplay](https://github.com/mastermindx-market-intelligence/mastermind-terminal/blob/2ded360882b9c721e690907ff363b553781fb920/terminal/lib/iexDepthReplay.ts) validates the IEX-only historical contract and restricts executions to the selected session/sequence before the incumbent [Large Trades engine](https://github.com/mastermindx-market-intelligence/mastermind-terminal/blob/2ded360882b9c721e690907ff363b553781fb920/terminal/lib/largeTrades/engine.ts) applies market/knowledge cutoffs and corrections. `visiblePrints` contains all eligible retained prints; the 1,000-marker limit applies to clusters, not that print list. The UI shows the first 64 price rows with an existing disclosure that totals retain all captured executions. This is retained, not misreported as an unexplained truncation defect.
