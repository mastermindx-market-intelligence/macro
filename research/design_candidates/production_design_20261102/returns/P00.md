### Workflow and result semantics

1. Read current protected source and original #1011 carrier. Preserve actual live writers, release holds, explicit refusals and unresolved effects.
2. Inspect current connection/catalog, then read exact file ID. Match returned identity and obtain the applicable file-only guard.
3. Reconcile action permission, published action semantics and target scope before requesting any mutation. Navigation or a context change must never silently trigger a write.
4. For a guarded call, existing source validates caller gates, initial tool qualification, source/target identity, snapshot, file management and token restrictions. The candidate then refreshes/requalifies the server, getter, requested descriptor and actual payload **after** the vendor guard read.
5. Dispatch once. A material schema/identity change or catalog error before dispatch refuses the call and sends no requested effect. Benign description changes or an unrelated blocked tool do not disable compatible work.
6. After a dispatched mutation, retain the existing postread path. APPLIED_RESPONSE_OBSERVED is response/readback evidence, not RIG or production acceptance. New file creation returns RESPONSE_OBSERVED_REQUIRES_TARGET_VERIFICATION; inspect the returned destination ID and verify name/content/identity separately.
7. A lost/error mutation response or unsafe/mismatched postread remains EFFECT_UNKNOWN with retry_allowed=false. Reconcile the original operation through the same carrier; do not retry, rephrase to evade approval, or fall back to another adapter.
8. DOCUMENT_CHANGED requires a fresh read and a new decision about the intended work. It does not authorize automatic replay. Missing identity/access/quota is unknown/refused, never zero, success or inferred entitlement.

Relevant literal states and refusals include OBSERVED, TOOL_SCHEMA_CHANGED, UPSTREAM_SCHEMA_UNREVIEWED, UNREVIEWED_TOOL_ARGUMENTS, PAPER_RICH_TEXT_SCHEMA_REQUIRED, PAPER_LEGACY_TEXT_SCHEMA_REQUIRED, UPSTREAM_UNAVAILABLE, DOCUMENT_CHANGED, FILE_ID_MISMATCH, WRITE_DISABLED and EFFECT_UNKNOWN.
