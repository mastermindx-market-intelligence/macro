## 1. Product and primary job

The shared kit helps an investor compare observations, recognize what they mean, inspect their evidence, and return to the same context without losing selection or confusing unavailable data with a reported zero. The same job appears in Macro participation, Company statements and Options tape. Public editorial needs the same clarity of units, evidence and controls inside a comfortable reading rhythm.

The success journey is: enter the existing route and context; identify the primary question and observation period; compare values in a dense visual object; distinguish sign, unit, zero, absence and data coverage; open evidence for a particular field or row; read the underlying identity, period, source and limitations; close the inspector with context preserved and focus restored when the retiring surface legitimately owns it; optionally act through the existing domain-owned write flow and confirm its actual result. A navigation or context action never silently saves anything.

No product capability is intentionally removed. The proposed examples are contextual component slices, not replacements for complete Macro, Company, Options or editorial workspaces. Domain tabs, historical periods, exports, chart tools, specialist routes and saved objects stay with their current owners. The [capability ledger](CAPABILITY_LEDGER.md) records those retained obligations. The source-backed HTML is a supporting interaction specimen; the static sheets are authored compositions, not browser screenshots or Paper exports.

## 2. Visual hierarchy and archetypes

Use one main analytical or reading object and normally no more than two supporting modules above the fold. This is a hierarchy rule, not permission to delete other tasks. The primary chart/table must remain immediately identifiable; routine source metadata should be legible but quieter than the question and values. Put critical limitations next to the affected answer, not exclusively behind an information icon.

**Analytical workspace:** title/question and compact source receipt; unboxed compact metric strip; local data controls and primary comparison; supporting chart or matrix; evidence beside the comparison when space supports it. Macro sector scanning and Options tape scanning place the table before the secondary chart. Company historical comparison places its compact multi-series history immediately before the raw-period table. Use neutral separators to group related data. Do not wrap every sentence, metric, filter or explanatory paragraph in a card.

**Instrument workspace:** retain instrument identity and current context; place the selected financial or market object first; keep related periods and evidence adjacent; use source-owned local tabs. Do not replace existing charts or historical data with summary prose.

**Reading workspace:** a deliberately limited text measure, strong title/dek, publication metadata, headings/TOC and a comfortable line height. Charts, equations and tables remain in the argument. A callout is one concise caveat or action, not a second full article. Public pages do not inherit investor navigation by default.

The nine governed Paper starters remain retained references for Command, Discovery, Instrument, Regime, Intelligence, Editorial, Monitor, Marketing and Utility. This F02 candidate specifies shared anatomy; it does not collapse those nine jobs into one card-grid page or approve their current compositions.

### 4.1 Density and truncation

Dense mode changes row spacing, not the underlying field set or semantics. Comfortable mode increases breathing room and reading line height. Neither mode drops columns, silently rounds more aggressively, converts a meaningful chart into prose, or removes source access.

The primary name can wrap to two or more lines. Numeric cells stay on one line inside a locally scrollable table. If a secondary identifier is visually truncated, its complete value remains available through an explicit focus/touch action; a browser `title` alone is insufficient. Long hashes, URLs and source keys wrap in inspectors. Critical qualifiers and error recovery copy never ellipsize. Narrow table layouts keep an accessible full-row inspector and a visible local-scroll affordance; sticky columns cannot hide the only evidence action.

For export, preserve the existing raw precision, column meaning, units, record count/scope and date convention. Display formatting does not become the data source. Do not change export behavior in a cosmetic table migration.

### 4.2 Chart grammar

Use explicit units and clock type. Percentage changes, percentage-point changes and basis points cannot share an unlabeled axis. Time spacing must match the domain's actual calendar/session model; a categorical session axis must say so. Bars start at zero unless the chart type and explicit domain justify a different baseline. Lines may use a declared bounded scale; the Macro specimen labels 40–80%. Do not smooth, connect or carry forward a missing observation. Source `lib/illus.py:_clean` currently drops missing values; that is a concrete implementation gap to resolve before claiming gap-preserving rendering.

Labels and direct reading carry the primary distinction; series color is supporting. Use a modest number of meaningful series and differentiate by marker/line style when needed. Show tooltips for convenience, plus a named exact-value table or existing data inspector. Reference series, observed series, forecast/model bands and user annotations remain explicitly different. Crosshair time/replay identity belongs to the existing chart engine.

### 4.3 Icon and effect reconciliation

Reuse the actual Macro icon macro anatomy and Terminal's existing local SVG ownership. A future implementation may reconcile optical sizes and accessible labels, but no screenshot creates a package import. A text label accompanies important mobile actions; 44px is the programme's house target, not the WCAG AA minimum of 24px with applicable exceptions.

**Refraction is not a generic component effect.** The historical full-pane settings treatment was rejected; the narrowly conditioned R3 proposal permits only the top strip, with existing 13 navigation rows and all pane controls/persistence preserved, slow 16-second motion, pause while closed, static reduced-motion treatment and omission in forced colors. Its historical Draft/HOLD is not release proof. New F02 components have no prismatic border, glow, accent rail or animated container edge. See the exact historical source and Paper IDs in the source contract and continuity register.
