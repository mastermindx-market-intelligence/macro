## Proposed component behavior

Capture legitimate focus ownership **before** hiding, detaching, changing inertness or moving the inspector. A later `BODY` active element cannot establish deliberate primary-task focus. The existing inspector owner retains one selected evidence object and one presentation; no second store, global event bus or lifecycle is introduced.

| Trigger and established ownership | Proposed F02 anatomy/accessibility contract | Preserved context |
| --- | --- | --- |
| Passive resize removes dock eligibility; inspector legitimately owns focus | Adapt the **same inspector** to modal. Keep its valid logical control; if that control no longer exists, use the existing named in-inspector fallback. Establish one modal trap, background inertness and active Escape owner coherently. | Exact domain identity, source generation, disclosure and local scroll remain valid. A placement change does not send focus back to the outside trigger. |
| Passive resize removes dock eligibility; user deliberately focused the primary task | Suspend inspector **presentation**, release reserved width and leave valid primary-task focus untouched. Expose an accessible, visible explicit **Reopen evidence** action through the existing trigger. | Retain domain selection and return anchor, primary input/selection/scroll and existing request state. No hidden modal or focused hidden control. Suspension does not discard selected evidence. |
| Width grows or oscillates while presentation is suspended | Stay suspended until explicit reopen. | No surprise opening, navigation preference reset or auto-compact rail. |
| Explicit Reopen evidence | Revalidate identity, access and source generation through incumbent owners, then choose the eligible presentation using measured usable width. | Existing domains own stale, missing, invalidated and denied outcomes. Do not reopen a stale object by position or silently choose another row. |
| Open modal becomes dock eligible | Adapt the same inspector to nonmodal; release its exclusive trap/inertness/scroll lock coherently while retaining a valid visible logical control. | Evidence identity, disclosure and scroll persist; do not restore the outside trigger merely because placement changed. |
| Another modal owns focus, or ownership is unknown | Apply existing shared-layer arbitration and hold the ambiguous automatic transition. | Neither branch may be inferred. No second modal, hidden focus, stale callback, delayed surprise opening or indefinitely invalid-width dock is accepted by this response; the existing owner must qualify this unresolved branch. |
