## Geometry and content decisions

The analytical desktop envelope uses the observed 224px expanded rail and 64px header. With 24px padding on each side, a 1440px canvas leaves 1168px for content. Macro demonstrates a 320px docked inspector and 24px gap, leaving **824px** for the main comparison. These are explicit candidate coordinates, not a frozen F01 shell release.

The 390px Macro frame leaves 358px of content after 16px side padding. The necessary two-dimensional table remains locally bounded; its source control is reachable in the first column. The 320px evidence frame leaves a 280px text measure and uses a 44px close control and 44px return control. The visible focus outline is a legitimate accessibility affordance; containers and selected states use neutral edges/fills.

Borders that identify controls use `#6f6f6f` in dark and `#85877f` in light. Structural dividers remain `#343434` and `#cbccc7`. Other proposed colors and the Macro/Company fixture arrays are read from `../pattern-lab.html` by the generator. Options signed-exposure labels in the state sheet retain the existing Terminal dark semantic colors `#4cc6cc` and `#d896f0`; those are not proposed global aliases.

The Macro pane shows eight of ten fixture rows in a visibly bounded view with continuation copy. Its missing Energy value is a dash with a retained evidence action. The mobile crop similarly discloses three of ten rows. These views do not delete the remaining observations or imply paging implementation.

The Options fixture reconciles to USD 4,544,000, presented as 4.54 USD m in the headline and exactly 2.857/1.687 USD m by expiry. Four of twelve prints have estimated buy side; one has unknown moneyness. These are illustrative fixture quantities, not market totals or production observations.

The Company evidence overlay identifies fiscal years 2024–2026 rather than reusing a market timestamp as the observation period. Dividend change is labeled `0.00 USD/share`; a zero-denominator relative change is not invented. The current source's earlier-period definition warnings and statement currency must survive implementation.

The public editorial sheet uses an original illustrative English excerpt under the existing example article title. It is not a replacement for the authored article. Body-language ownership remains English in the verified source contract; bilingual chrome does not create a translated body or a new language URL. No reading-time claim is made.

## Reproduction and review record

Run `python3 draw_sheets.py` from any working directory with Pillow and the installed Noto Sans/DejaVu fonts. The program reads its sibling `../pattern-lab.html`, draws geometry/text directly, writes vector source and raster plates, and records the exact input HTML SHA-256 in `manifest.json`. English raster text uses installed Noto Sans with DejaVu fallback for mathematical/navigation glyphs; the intended product stack remains the source-mapped Inter-first UI stack. No font binaries are embedded or distributed.

The author visually inspected all four consumer compositions, both mobile frames and the state matrix. The review corrected missing mathematical/arrow glyphs, added the fourth editorial TOC destination heading, made important mobile controls 44px, strengthened neutral control boundaries, and separated positive/negative and buy/sell colors in the semantic examples. The generator reports zero text placements outside the overall canvases. That check is only a drawing-boundary guard; it does not verify browser reflow, screen readers, keyboard behavior, touch behavior, 400% zoom, CJK shaping, native font parity, virtualized lists or real application integration.
