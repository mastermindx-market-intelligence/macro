## 4. Minimal shared presentation/data contract — proposed, not a live schema

The following fields define what a component needs to render truthfully. Existing producers keep their schemas. A consumer-side mapping may supply these roles after its domain owner has identified the actual source field, allowed transformation and unknown case. No central endpoint or universal model is implied.

| Contract area | Required mapping | Rejection / absence rule |
| --- | --- | --- |
| Entity | Existing stable domain key, entity kind, displayed name; listing/symbol/exchange identity when material; source-key namespace if keys can collide | A display ticker or company name alone is not a universal company/listing key. Never relabel old data after region changes. |
| Route | Exact existing route family and supported query/hash state; return destination | Preserve meaningful query bytes, parser rejection, history, hash anchors, focus and scroll. No new route assumed from a component name. |
| Ownership | Immutable account subject for user-owned data; existing guest/access disposition | Email is display only. A context/theme/language switch is not a write command. |
| Value | Raw finite numeric value or typed absence; source field; unit; scale; display precision; raw value available for evidence/export | `0` is a value. `null`, absent field, invalid/nonfinite and not-applicable are different cases. Never turn missing into zero or parse a formatted label as source data. |
| Comparison | Comparable baseline, baseline period/time, method, delta unit, rounding policy; reference to both observations | A signed delta without unit and period is incomplete. Do not compute across currencies, listings, fiscal bases or incompatible snapshots by appearance. |
| Time | Clock kind, exact source value, timezone/basis, observation range if applicable; owner-defined stale policy | Publication, source response, market event, session date, artifact build and UI retrieval clocks cannot substitute for each other. Missing source time means source age unavailable. |
| Evidence | Actual source kind/URL/record identity, citation precision, source status, producer receipt/hash if supplied; derived-versus-reported disclosure | Do not infer a line citation from metadata, a link or a source hash. Do not attribute a cross-event calculation to one current-event source. |
| Coverage | Population, selection universe, measurement window, excluded/unknown counts, completeness status, units of denominators | A sampled or filtered feed is not a market/session denominator. Empty observation is not zero activity. |
| Interaction | Existing callback owner, row/item identity, selected/focused state, keyboard/touch/scroll behavior | No data-fetch, entitlement or save side effect belongs in a color/token component. |
| Mutation | Existing action identity and write owner, request/generation identity where supported, readback evidence, pending/failed/uncertain/saved status | No “Saved” until owner-confirmed success/readback. An expired session or interrupted response can leave outcome uncertain; do not blindly retry. No D23 API invented here. |

### 4.1 Numeric and unit rules

1. **Percent encoding must be explicit.** Existing `finFormat.ts:53–64` multiplies ratios by 100 unless `alreadyPct` is true. Proposed shared callers must declare ratio versus percent-point input. An observed ratio `0.125` formats as `12.5%`; an already-percent `12.5` also formats as `12.5%` only with the explicit flag. A change from 10% to 12% is `+2 pp`, not automatically `+2%`; relative percent change requires a named baseline.
2. **Basis points and money require units.** A 25bp rate move is not a 25% change. Preserve currency ISO code, nominal scale and source precision. `fmtNum` abbreviations K/M/B/T are display transformations only; table/export/evidence retain the underlying value and unit.
3. **Statement and quote currencies remain separate.** `statementCurrencyCode` / `statementCurrencyLabel` retain missing statement currency as unavailable. Do not substitute quote currency, geography or a default USD. `fmtCur` can display `¥` for both CNY/RMB and JPY; qualify with the ISO currency in the relevant header/receipt. [T11]
4. **Signs and nulls are distinct.** Existing formatter outputs use a true minus and a configurable dash for missing/nonfinite values. A compact dash requires adjacent or accessible absence reason; a full metric/state cannot consist only of a dash. `signColor` uses the same neutral color for zero and null, so the label/value contract must carry their difference.
5. **Probability is not generic confidence.** A D08 probability needs its event, horizon, conditioning inputs, model/calibration basis and range encoding. A source-coverage percentage, evidence precision, health status, quality axis, lifecycle stage or signed exposure must not be relabeled as probability/confidence. F02 provides a visual carrier only after the domain supplies a valid semantic contract.
6. **No false precision.** Round only for display; retain sign and explicit rounding policy near comparisons. Suppress negative zero in a future shared formatter only as a documented presentation rule, never by mutating source values. Existing formatters must be assessed by their owner before any implementation change.

### 4.3 State axes and required copy

Keep availability, freshness, completeness, access, selection/focus and mutation outcome independent. The component may combine compatible axes (for example retained data + stale + current acquisition failed) without overwriting the last good value. Copy below is proposed shared vocabulary; source-specific qualified copy takes precedence.

| State | Meaning and minimum treatment | Example EN / ZH |
| --- | --- | --- |
| Loading, no retained data | Skeleton mirrors expected anatomy, marks busy/status, never states empty/zero | “Loading observations…” / “正在加载观测数据…” |
| Empty observation | Successful known scope contained no qualifying observations; state the scope | “No qualifying observations in this window.” / “此窗口内没有符合条件的观测。” |
