# China Information-Edge Implementation Masterplan

> **For agentic workers:** Use the installed `superpowers:subagent-driven-development` or `superpowers:executing-plans` procedure when implementing, subject to the current protected Mastermind Skillpack and approved Subagent Fabric. This document specifies work; it does not dispatch a worker, transfer incumbent custody, or lift a hold.

**Goal:** Finish the existing China estate as a company-centered, source-grounded, point-in-time evidence system that improves discovery, prioritization or post-admission decisions only where that value is demonstrated.

**Architecture:** Existing source owners retain raw payloads, identities, relationships, event truth, outcome grading and publication. Small owner-native read adapters produce typed evidence and a bounded company packet consumed by the existing Hub, Brain, Prophet shadow, Themes, Neural Web and Risk. There is no new universal evidence service or datastore unless an explicit later owner decision establishes a measured need.

**Tech stack:** Existing repository Python, Parquet/JSON owner stores, current source collectors and schedulers, current deterministic rank/grader infrastructure, existing Jinja/web rendering and Mastermind MCP consumers. No new framework, paid data source or control plane is required for the first slice.

**Spec:** [Audit](01_AUDIT.md), [current census](02_CENSUS_AND_GAP_MAP.md), [registers](03_RESEARCH_SOURCE_AND_SIGNAL_REGISTERS.md), [contracts/evaluation](05_CONTRACTS_AND_EVALUATION.md), and [acceptance](07_ACCEPTANCE_AND_TRACEABILITY.md). ## Review focus

Five cross-cutting discriminators must appear in the owning packet's tests: (1) delayed/corrected evidence or a later identity link leaking into an earlier decision; (2) source outage/partial coverage being interpreted as no event or analyst silence; (3) duplicated event/manager/desk observations increasing conviction; (4) an unavailable or oversized packet breaking JSON or causing an unintended decision change; (5) a historical fill/rule/venue mismatch manufacturing apparent alpha. These are release consequences, not optional polish.

## Universal worker execution cycle

- [ ] Re-read current accepted prerequisites, exact writer/path custody and the one packet's scope. Pin source, consumer and tests; report PICKUP_ACK, then START only after admission/gates clear.
- [ ] Write the named discriminating tests below; run the focused suite and retain the expected failure showing the missing behavior, not an unrelated environment failure.
- [ ] Implement the smallest owner-native change. Run focused tests, impacted consumer suites, and the current repository's CI registration/trigger checks. A green unrelated pack is not proof the introduced suite executed.
- [ ] Commit only owned paths; return exact head, source receipts, changed-file list, test commands/results and limits. Independent review binds that immutable semantic head; current integration proof is separate.
- [ ] Use existing release authority for merge/publication; obtain the packet's natural production or actual consumer proof when required. Until then classify BUILT_NOT_PROVEN, not done.
- [ ] Apply the documented rollback/failure behavior; update the existing workstream and close or continue the same carrier explicitly. A worker waiting on review must receive the proper terminal/nonterminal edge.

All tests below are **required future tests**, not results claimed by this audit.
