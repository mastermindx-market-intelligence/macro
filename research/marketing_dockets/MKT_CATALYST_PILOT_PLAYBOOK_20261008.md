## 3. Pilot hypotheses, actual denominators, decision thresholds

These are **pre-registration gates**, not published benchmarks, acceptance guarantees, subscriber-to-click forecasts or proven conversion rates. Production journey first, then credible click numerator. Be explicit about source maturity: a 2026-10-22 report may not contain full 7-day cohorts for Oct 16–22 arrivals; mark those **IMMATURE** rather than fail.

| Metric / denominator | Pilot aspirational hypothesis | Investigate or HOLD | Minimum evidence to interpret |
|---|---|---|---|
| **Attributable landing sessions** / actual unique hosted clicks | Seek **150 genuine tagged unique landings/source** for a directional decision. This is a *measurement target*, not a reach forecast. | **Fewer than 50**: anecdote only; **50–149**: directional, no scaling claim. | Publisher supplies median unique outbound clicks from **last 3 comparable posts** and real placed CTA/reporting period. Never impute from subscribers. |
| **First value rate** / unique eligible landing sessions | **>=60%** see a real supported scan (strategy's visit→intelligence working hypothesis); if user queries unsupported, report them separately. | **<40% with >=150 landings** suggests CTA/result/rights fit failure; triage before more sends. | Real browser renders and source-rights checked; instrumented and deduped. |
| **Explicit submission and verification** / first-value consumers / submissions | Inspect both funnels; **>=70% verified / submitted** is a **new exploratory prior**, not existing company evidence. | **<50% verified / submitted with >=30 submits**: verification UX or quality problem; examine fraud/bounce composition. | Actual mail confirmations and suppression; no private identities in reports. |
| **Qualified activation rate** / unique eligible tagged landing sessions | **>=8% QAL** with **>=150 sessions/source** makes the channel a **candidate to repeat** (NOT statistical proof of superiority). | **<=3% QAL** with **>=150 sessions/source** prompts offer/placement redesign; 3–8% is learn, not pass/fail. | All cohort steps mature for 7 days, paid/source attribution intact; one person one QAL. |
| **High-intent share** / QAL | **>=25% high-intent QAL** (new test prior). | **<10%** with **>=20 matured QAL** suggests shallow giveaway-like signups. | Three *supported* tickers and user-active update/return within 7d. |
| **Second-value actual click-back** / successfully delivered and eligible updates | **>=20% meaningful return** (new prior, *not* tracking pixel open rate). | **<10%** with **>=20 actual delivered consenting QAL updates** suggests weak retention hook. | Receipt, timestamp, eligible user denominator, actual click/visit, no suppressed recipient. |
| **Source breadth** | For first **25**, full pipeline proof; first **100** needs **3 independent sources**. | 25 signed-up email strings or 1 source cannot claim 25 QAL / 100 sources milestone. | Per-person global dedup and independent partner identities; avoid same author counting twice. |
| **Trust and permission harm** | **Zero** unconsented mail, external promotions without approval, rights violations, fabricated signals, privacy leaks. | **Any** verified event => immediate source pause and canonical owner incident review regardless of conversion. | Browser/public proof, rights receipts, native sender logs, exact revocation tests, editor approval and corrections. |

**Calibration example, not forecast:** two actually approved sources x 150 verified landing sessions each x an **assumed** 8% QAL ≈ **24 activated persons**, near but still **below** first-25 milestone. Without host median unique-click evidence, approved calendar and conversion proof, the actual expectation is **UNKNOWN**, not 24. In a small sample, even 8% is noisy; show numerator, denominator, 7-day maturity and a simple interval, never declare a true population conversion rate. If a publisher can drive only 30 unique clicks, an ethical demonstration can still be useful, but **not a scaling conclusion**.

**No-go diagnostics:** high clicks but no first result → product/rights/UX; first result but low opt-in → value/consent proposition; submitted but unverified → verification/deliverability; verified but no scan join → tracking bug, no fabricated QAL; activated but no second value → event/update/delivery gap; good newsletter but too few clicks → distributor reach not proven, do not blame product. Attribution break means **hold conversion claims**, not force-match PII.
