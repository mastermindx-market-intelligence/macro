# A09 join guard — 2026-10-13

SNI-local DRAFT contract review. Identity ids are caller-supplied opaque
strings owned by Stock Identity / Data OS; this lane never mints them.
rank_authority, gate_authority, size_authority, signal_authority,
escalation_authority and trade_authority stay literal false. Fixtures in
the accompanying tests are synthetic. This is a descriptive refusal
contract, not a signal or forecast.

Pinned against BASE `e4c2f672bed06eef3fac0b7bb88d46275a228f28`. Module:
`research/single_name_intelligence/common/sni_join_guard.py`. Tests:
`tests/test_sni_join_guard.py`. Runner: Python 3.

## Summary

Acceptance row A09 records no automated refusal of mismatched joins. The
E1 (reference pack 1) and E2 (reference pack 2) adversarial probes of
2026-10-11 showed owner stores merging or passing cases whose identity,
period, basis, currency, scale, segment scheme, share denominator, counter,
or version did not match. This lane adds an SNI-local DRAFT join-guard
module that consumes owner-supplied fact descriptors and refuses those
joins with named reason codes. Unknown is refused, never assumed equal.
The module does not convert currency, rescale, resolve identity, or emit a
merged record. Every authority flag on every verdict is literal false. A
consumer must call `check_join` before joining; nothing here is wired into
FIF, Capital Structure, Company Event/Earnings, Stock Identity, Data OS,
or qledger/Evaluation.

## What the guard does NOT do

- It is not wired into any owner. FIF, Capital Structure, Company
  Event/Earnings, Stock Identity, Data OS identity, and qledger/Evaluation
  are unchanged. A consumer must call `validate_fact` / `check_join`.
- The owners still pass these cases until a consumer calls the guard, or
  until the owners carry the fields. FIF would need to carry `currency`,
  `source_reported_currency`, `scale`, `segment`, `segment_scheme_version`,
  `period_end`, `period_type`, `basis`, `metric`, and `version` on each
  financial fact. Capital Structure would need to carry `share_denominator`
  and `ads_ratio` on every per-share fact. Company Event/Earnings would need
  to carry `period_end` as a field (not only title prose), `known_at` as
  first-public time, and `version` / `supersedes` on restated events, plus
  `counter_id` on dual-listed event rows so a fold cannot drop a counter.
  Stock Identity / Data OS already own `issuer_id`, `counter_id`, and
  `level`; this guard only compares caller-supplied opaque strings.
- No conversion. Currency mismatch is refused. Scale mismatch is refused.
  There is no FX table and no scale arithmetic in the module. An AST test
  pins the absence of a conversion path.
- No identity resolution. `issuer_id` and `counter_id` are compared with
  exact `==` only. Unknown stays unresolved. The module does not mint,
  derive, or guess an identifier from a ticker, name, code, or CIK.
- It does not fork owners. It is an SNI-local DRAFT contract that consumes
  owner-supplied descriptors.
- It is not a forecast or validation. It is a descriptive refusal contract.
  rank_authority, gate_authority, size_authority, signal_authority,
  escalation_authority and trade_authority are literal false on every
  verdict. `refuse_nonfalse_authority` raises if a caller tries to set any
  of them true.
- No acceptance row moves to DONE. The seat updates the matrix.

## Gaps

- The guard is a library. Owner output on main still exhibits the recorded
  SILENT_JOIN / SPLIT behaviour until a consumer invokes it.
- Several owner stores still omit the fields the guard requires
  (`period_end` on events, `share_denominator` on per-share lines, `version`
  on financials, `segment_scheme_version`, `counter_id` on folded tape
  rows). Missing fields refuse; they are not filled in.
- Restatement ordering is the owner's job. The version rule allows a pair
  only when `supersedes` names the other side's `version`; it does not
  order a restatement chain.
- Probe P7 (source correction) is outside this lane.
- Then-known exclusion of a fact with `known_at` later than `as_of` is
  enforced here as `NOT_KNOWN_AS_OF`. Broader then-known reconstruction
  remains with the study runners.
- This review does not move A09. CI wiring of the new test file is the
  seat's integration step.
