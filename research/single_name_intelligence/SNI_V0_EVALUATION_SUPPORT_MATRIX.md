# SNI V0 — Evaluation support matrix (existing qledger / evaluation owner)

**Status:** V0 DECISION INPUT. This document decides; it implements nothing.
**Owner of the thing measured:** `WS:EVAL-OS-MEASUREMENT-LAW` (`engine/qledger.py` and its test family).
**Evidence base:** macro `origin/main` @ `e44069e306fd` (branched 2026-10-11; the diff from the commission's pin `3f5e0307` over every V0 input path was empty).
**Line numbers** are on that commit. Each proof cites a function, field, schema path or test by name. Every row has one.

## Verdict legend

- **SUPPORTED-AS-IS**: the existing owner already enforces the property, and a named test pins it. SNI adds nothing here.
- **SUPPORTED-WITH-DECLARED-EXTENSION**: the existing owner has the primitive. SNI needs one additive, family-gated change in that owner's module, plus a named test in that owner's test file. The changes are listed in `SNI_V0_EXTENSION_DECISION.md` §3.
- **UNSUPPORTED**: no existing owner can do this today. The row names the blocker and the owner who would have to ratify the missing piece. Nothing in SNI may claim this property until then.

## What this matrix does NOT claim

- It does not claim that return/hit grading is probabilistic forecast support. Rows 4 and 6 become probabilistic support only after the declared scoring extension lands **and** the bridge acceptance in the decision file §5 holds.
