### `engine/prophet_entry_policy.py` (MODIFIED, +100)

Two semantic moves in one commit:

- **Four era-stamped constants** added to the module-level scope (after the existing `SESSION_POLICY_ERA` / `GATE` block): `RISK_POLICY_VERSION = "early-leadership-sector-rotation-risk-atr-v1"`, `RISK_POLICY_ERA = "B4_RISK_ATR_2_0_2026_09_22"`, `RISK_GATE = "risk_ceiling"`, `RISK_ATR_CEILING = 2.0`. These are the only mutable policy constants in the patch — every other value in `_risk_policy_material` is a frozen string, an enum literal, or a None (the explicit `universal_percent_ceiling = None` enforces the no-percent-stop discipline at the provenance layer, not only at the math layer).
- **`_finite_positive_number(value, field)`** — input guard. Refuses booleans (`isinstance(value, bool)` returns True for both `True` and `False`, both rejected — the policy refuses `True/False` as numeric inputs even though `bool` is a subclass of `int` in Python, because the B4 lane treats booleans as truth values not as quantities); refuses non-numeric inputs (raises `EntryPolicyContractError(f"{field} must be numeric")`); refuses non-finite (`math.isfinite` rejects `nan`/`inf`) or non-positive (≤ 0) inputs (raises `EntryPolicyContractError(f"{field} must be finite and > 0")`). The guard applies uniformly to `current_price`, `invalidation_price`, and `atr` — three owner-supplied numeric facts that the lane refuses to guess on.
- **`_risk_policy_material(strategy_definition_id)`** — provenance emitter. Returns a frozen dict that exposes the era metadata into the emitted fact: `schema` (the existing `prophet.entry_policy_fact/v1` schema), `gate = RISK_GATE = "risk_ceiling"`, `strategy_id`, `strategy_definition_id`, `entry_policy_version`, `horizon = "2_15_SESSIONS"`, `horizon_role = "new_entry"`, `scientific_status = "CONTROL_ONLY"`, `authority_tier = "SHADOW_ONLY"`, `risk_policy_version`, `risk_policy_era`, `method = "STRUCTURAL_INVALIDATION_DISTANCE_ATR"`, `risk_atr_ceiling = 2.0`, `threshold_status = "INITIAL_OPERATION_CONSTANT_NOT_CALIBRATED"`, `calibration_requirement = "PROSPECTIVE_OR_OOS_SAME_TAPE_WITH_COSTS"`, `geometry_owner = "incumbent_entry_owner_invalidation"`, `volatility_input = "owner_supplied_atr"`, `universal_percent_ceiling = None`, and the `authority` block (every flag set to False). The dict is content-addressed via SHA-256 in the `policy_receipt`/`fact_receipt` chain, which makes the era metadata durable across the lane's later downstream consumers.
- **`evaluate_risk_ceiling(strategy_definition, current_price, invalidation_price, atr)`** — single-canonical B4 `risk_ceiling` owner. Validates the strategy identity via the existing `validate_strategy_definition()`; coerces the three numeric inputs via `_finite_positive_number` (raises `EntryPolicyContractError` with the field name on any non-numeric / non-finite / non-positive input); computes `risk_distance = price - invalidation` and `risk_atr_raw = risk_distance / atr_value` and `risk_pct_raw = 100.0 * risk_distance / price` (the percent value is a diagnostic, not a gating threshold — the policy deliberately does not compare `risk_pct_raw` against any ceiling); selects one of three verdicts with named reason codes: `FAIL / STRUCTURAL_INVALIDATION_NOT_BELOW_PRICE` when `risk_distance <= 0`, `PASS / STRUCTURAL_RISK_WITHIN_ATR_CEILING` when `risk_atr_raw <= 2.0`, else `FAIL / STRUCTURAL_RISK_ABOVE_ATR_CEILING`. The verdict is symmetric: `risk_distance == 0` (invalidation at price) is FAIL with `STRUCTURAL_INVALIDATION_NOT_BELOW_PRICE`, not a boundary PASS — the patch refuses to treat the stop-touch as a structural-risk-acceptable state. Emits one content-addressed `policy_receipt = "pep:" + sha256(_canonical_json(policy_material))` and one `fact_receipt = "pepf:" + sha256(_canonical_json(payload))` (the policy uses the same `pep:` / `pepf:` prefix family as the sibling `session_eligibility` owner in #7688, but does not introduce a separate `session_receipt` because the `risk_ceiling` fact does not bind a separate calendar/session material — only the policy material and the post-emission payload).
- The function docstring carries the single-canonical-owner intent verbatim: "The policy deliberately avoids a universal percent-of-price stop rule. It measures the incumbent structural invalidation distance in ATR units and applies one era-stamped operation constant. The constant is not a calibrated optimum and cannot establish promotion, sizing, execution or trade authority." — i.e. the policy refuses to claim a calibrated optimum (the threshold_status literal name is the binding contract), refuses to be promoted by the math layer, and refuses to claim sizing/execution/trade authority.
