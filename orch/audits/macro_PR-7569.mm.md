**New engine module — `engine/prophet_entry_availability.py` (+525)**

Deterministic B4 entry-availability evaluator. Module docstring is the architecture-mirror preamble: "Zone/chase/stop geometry remains owned by the incumbent entry owner; callers must supply those facts with a receipt. Missing, stale, ambiguous or unknown required facts fail closed. No favorable score/theme/model input can waive a blocker because such fields are outside the closed input contract."

Public surface:

- `SCHEMA = "prophet.entry_availability/v1"` and `DEFINITION = "availability-v1-2026-08-17"` (frozen, content-addressed)
- `HORIZON = "2_15_SESSIONS"` · `HORIZON_ROLE = "new_entry"` (matches PR #7535 strategy)
- `AVAILABILITY_STATES` frozenset of the seven closed-set states
- Closed enums: `_OWNER_STATUSES` (13 values, exactly mirroring the strategy-definition owner's set), `_PASS_FAIL_UNKNOWN`, `_FRESHNESS`, `_BASIS_STATE`, `_EVENT_STATE`, `_INVALIDATION_STATE`
- Closed input field sets: `_FACT_KEYS` (7), `_QUOTE_KEYS` (5), `_GEOMETRY_KEYS` (7), `_GATE_KEYS` (9), `_METRIC_KEYS` (3)
- `_RFC3339_UTC_RE`, `_DATE_RE`, `_RECEIPT_RE` (sha256: or `<kind>:...` namespace)
- `EntryAvailabilityContractError(ValueError)` — single error type for the closed contract
- Validation helpers: `_canonical_json` (sort_keys=True, separators=(",",":"), ensure_ascii=False, allow_nan=False — same discipline as #7535), `_closed_mapping`, `_text`, `_utc`, `_session`, `_finite_positive`, `_receipt`, `_enum`
- Identity helpers: `_candidate_row` (delegates to `engine.prophet_candidate_state.validate_candidate_state_projection` and then enforces uniqueness of `episode_id` in the canonical B3 projection), `_strategy_identity` (delegates to `engine.prophet_strategy_definition.validate_strategy_definition` + checks `strategy_id`, horizon identity, and `entry_policy_version` — the three things PR #7535 froze)
- Metric derivation: `_metrics` computes `distance_to_zone_pct` (0 if inside zone), `risk_to_invalidation_pct`, `move_since_first_trigger_pct`, `move_since_anchor_pct`, `extension_atr` — all rounded to 6 decimals
- Public function `evaluate_entry_availability(candidate_projection, *, episode_id, strategy_definition, facts) -> dict[str, object]` — runs the closed validation pipeline, walks the deterministic routing tree, and returns the frozen output shape
- Public function `validate_entry_availability(payload)` — closes the output field set, re-binds the strategy identity against `build_early_leadership_sector_rotation_definition()` (so a future strategy mutation cannot mint Availability), enforces `entry_open == (state == "ENTRY_OPEN")`, enforces `ENTRY_OPEN` cannot carry `blockers`, and re-hashes the availability_id from the canonical material

Routing tree (the seven-state closed ladder):

1. **Lifecycle ≠ ACTIVE** → `INVALIDATED` with `EPISODE_NOT_ACTIVE:<state>` blocker
2. **`event_status == RETRACTED`** → `INVALIDATED` with `EVENT_RETRACTED` blocker
4. **`structural_invalidation == BREACHED`** or `price <= invalidation` → `INVALIDATED` with `STRUCTURAL_INVALIDATION_BREACHED` blocker
5. **Unknown inputs** (`!FRESH` quote, `!= RESOLVED` corporate-action basis, `!= PASS` source health, any of `owner_confluence`/`risk_ceiling`/`liquidity_fillability`/`gap_velocity`/`session_eligibility` `UNKNOWN`, `event_status UNKNOWN`, `structural_invalidation UNKNOWN`) → `UNAVAILABLE_DATA` with the named blocker
6. **`price > chase_above`** → `RAN_DONT_CHASE` with `PAST_OWNER_CHASE_BOUNDARY` blocker
7. **`risk_ceiling FAIL`** → `NOT_READY` with `RISK_TO_INVALIDATION_ABOVE_LANE_CEILING`
8. **`liquidity_fillability FAIL`** → `NOT_READY` with `LIQUIDITY_FILLABILITY_FAILED`
9. **`gap_velocity FAIL`** → `NOT_READY` with `GAP_VELOCITY_PROTECTION_FAILED`
10. **`session_eligibility FAIL`** → `NOT_READY` with `SESSION_NOT_ELIGIBLE`
11. **`owner_confluence FAIL`** → `APPROACHING_ENTRY` with `OWNER_CONFLUENCE_NOT_PASSED`
12. **`owner_status` in `{extended, topping, wait_pullback, hold, bounce_wait}`** → `WAIT_PULLBACK` with `OWNER_STATUS_REQUIRES_PULLBACK`
13. **`owner_status` in `{exit, avoid, blocked}`** → `NOT_READY` with `OWNER_STATUS_NOT_ACTIONABLE`
14. **`owner_status` in `{buy_soon, await_confluence, watch}`** → `APPROACHING_ENTRY` with reason `OWNER_STATUS_APPROACHING`
15. **`price < zone_low`** → `APPROACHING_ENTRY` with `CURRENT_PRICE_BELOW_OWNER_ZONE`
16. **`price > zone_high`** → `WAIT_PULLBACK` with `CURRENT_PRICE_ABOVE_OWNER_ZONE`
17. **else** → `ENTRY_OPEN` with the five-pass reasons (`CURRENT_PRICE_INSIDE_OWNER_ZONE`, `OWNER_CONFLUENCE_PASSED`, `RISK_WITHIN_LANE_CEILING`, `LIQUIDITY_FILLABLE`, `FRESH_QUOTE`)

The output is a closed-key dict (`schema`, `definition`, `episode_id`, `candidate_generation_id`, `candidate_state_projection_id`, `security_id`, `identity_epoch`, `strategy_definition_id`, `strategy_id`, `strategy_version`, `horizon`, `horizon_role`, `entry_policy_version`, `evaluated_at`, `market_session`, `state`, `entry_open`, `zone`, `current_price`, `current_price_basis`, `quote_asof`, `quote_age_seconds`, `invalidation`, `distance_to_zone_pct`, `risk_to_invalidation_pct`, `move_since_first_trigger_pct`, `move_since_anchor_pct`, `extension_atr`, `chase_state`, `owner_status`, `blockers`, `reasons`, `source_receipts`, `availability_id`) with the deterministic identity `availability_id = "pea:" + sha256(canonical_json_of_all_other_fields)`. Validators reject any payload whose key set diverges, any strategy-identity drift, any state/enum drift, any `entry_open`/`state` disagreement, and any `ENTRY_OPEN`-with-blockers inconsistency.

The two in-module prose notes are doctrine-correct and reviewer-facing:

- The basis-equality comment (lines around the corporate-action gate) explains why the engine deliberately does NOT require literal `quote.basis_version == geometry.basis_version`: "The incumbent live-price owner deliberately keeps two honest price families: raw vendor prints for the tape and split/dividend-adjusted levels for the armed geometry. Equality is therefore NOT the resolution test. The upstream basis owner must prove the two planes comparable (or fail closed) and reports that verdict through corporate_action_basis. Requiring literal equality here would dark every truthful live read and would pressure an adapter to fabricate an adjusted exchange print." — exactly the no-feedback firewall CLAUDE.md §Epistemics requires.
- The eight `availability_state_drift` cases in `validate_entry_availability` are the V4 architecture-mandated closed-contract discipline — a single state outside the seven-set is a fail-closed `EntryAvailabilityContractError`, never a silent fallback.
