## Diff content (scoped to this PR)

**`terminal/app/observatory.css` (MODIFIED, +43 / −14 around lines 1365–1497)** — the geometry repair:

1. **`.obs-fc-card` becomes `position: relative` (lines 1367–1371)** — adds two new properties (`position: relative` on the base rule, `z-index: 8` on `[data-fc-open="1"]`) so the card itself can host an absolutely-positioned child overlay (`obs-fc-detail`) without leaking into neighbours. The existing `padding`, `cursor`, `display: flex`, `flex-direction: column`, and `gap: 5px` are preserved verbatim.

2. **`.obs-fc-lean` widens to fit the full "Leans buy/sell (approximate)" copy (lines 1409–1414)** — the soft-direction chip changes from `max-width: 56px` to `max-width: 145px; min-width: 0; flex: 0 1 auto`. The chip still has `white-space: nowrap`, `overflow: hidden`, and `text-overflow: ellipsis`, but its own width budget grows enough that the qualification reads in full at all sampled viewports. The dashed border, padding, font, and color tokens (`var(--muted)`, `rgba(255, 255, 255, 0.2)`) are unchanged.

3. **`.obs-fc-line3` becomes a 2-column CSS grid (lines 1454–1458)** — replaces the prior `display: flex; flex-direction: column; align-items: stretch; gap: 5px` with `display: grid; grid-template-columns: minmax(0, 1fr) 32px; align-items: start; gap: 5px 6px; min-width: 0`. The grid creates an explicit 32px slot for the chevron in the second column and a `minmax(0, 1fr)` slot for the meta + badges in the first; `min-width: 0` keeps the first column from forcing its flex children wider than their content.

4. **`.obs-fc-meta` flips wrap behavior (lines 1464–1467)** — `flex-wrap: nowrap; overflow: visible` becomes `flex-wrap: wrap; overflow: hidden; min-width: 0`. The wrap is what allows the meta facts row to wrap inside its own column instead of colliding with the action. `min-width: 0` is consistent with the grid's `minmax(0, 1fr)` slot above.

5. **`.obs-fc-expand-btn` becomes a real in-card 32×32 target (lines 1504–1523)** — replaces the prior `position: absolute; bottom: 8px; right: 10px; background: none; border: none; cursor: pointer; padding: 2px 4px` with `position: static; width: 32px; height: 32px; display: inline-grid; place-items: center; justify-self: end; align-self: start; font: 600 8px/1 var(--font-ui); color: var(--muted); background: rgba(255, 255, 255, 0.025); border: 1px solid rgba(255, 255, 255, 0.08); border-radius: 8px; cursor: pointer; padding: 0; flex: none`. The PR body attests `FeedPane`'s own source comments identified the absolute-positioned button as the retired sticky/unclosable geometry. Two hover/focus-visible states are added: `:hover` and `:focus-visible` both flip color to `var(--text)`, background to `rgba(255, 255, 255, 0.07)`, and border to `rgba(255, 255, 255, 0.16)` — a quiet hover lift without glow (command-center material treatment, consistent with the existing dark theme).

6. **`.obs-fc-detail` becomes an absolute child overlay (lines 1525–1532)** — replaces the prior `margin-top: 4px` with `position: absolute; top: calc(100% + 6px); left: 0; right: 0; z-index: 12; margin-top: 0; padding-top: 10px; border-top: 1px solid rgba(255, 255, 255, 0.07); box-shadow: 0 16px 38px rgba(0, 0, 0, 0.34)`. Combined with `.obs-fc-card`'s new `position: relative` and `[data-fc-open="1"] { z-index: 8 }`, the detail renders in-flow on the open card and overlays the cards below without expanding their grid row (verified by the `offsetTop` assertion in the e2e spec).

7. **`.obs-fc-detail-hd` gains layout (lines 1534–1540)** — `display: flex; align-items: center; justify-content: space-between; gap: 8px; padding: 0 10px` is prepended to the existing `font: 600 11px/1 var(--font-ui); color: var(--text-2); margin-bottom: 7px`. The new layout lets the close control sit on the right of the header row at every viewport width (mirrors the terminal #670 "Close control on its own row at every width" pattern for thesis-notices, applied here to the score-detail header).

8. **No other file in `terminal/app/` is touched. No `terminal/components/` is touched. No `terminal/lib/plainLabels.ts`, `terminal/lib/i18n/`, `terminal/lib/indicator-`, `terminal/lib/suites/`, or `terminal/lib/data/` is touched. No `terminal/docs/` is touched.**
